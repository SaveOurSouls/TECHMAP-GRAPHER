# Источники и воспроизведение

Проверка открытых исходных определений: 2026-09-26.

- [QCAD: metric patterns](https://github.com/qcad/qcad/tree/master/patterns/metric).
- `hatch_sources.json`: 48 выбранных PAT-определений в поле `text`, имена, URL и Git blob SHA.
- `qcad_patterns.json`: снимок ответа GitHub API со всеми 127 файлами папки.
- `catalog.json`: русские описания и ссылки на исходные определения; `source_sha` связывает карточку с точной версией.
- `QCAD-LICENSE.txt` и `QCAD-GPL-3.0.txt`: уведомление и текст лицензии из исходного проекта.

Происхождение геометрии — проект QCAD / соответствующие правообладатели.
Это не оригинальные определения Autodesk и не копии таблиц ISO, DIN или ANSI.
Лицензионное уведомление QCAD указывает GPL version 3 с возможными исключениями;
сфера исключений для этой подборки отдельно не устанавливалась.
При дальнейшем распространении определений сохранять происхождение и применимые
лицензионные условия; не считать их автоматически общественным достоянием.

`hatch_sources.json` содержит машиночитаемый исходник рисунков; генератор,
метаданные и ссылки сохранены для проверки и повторного построения.
Генератор переводит семейства PAT-линий, их сдвиги и интервалы штрихов
в SVG-сегменты. Предварительный масштаб задан в каждой записи и не является
нормативным или физическим размером материала.

## Команды из корня репозитория

Python 3, без установки пакетов и без сети:

```text
python design/hatching_catalog/build_hatching_catalog.py
python design/hatching_catalog/verify_catalog.py
```

Генератор обновляет SVG, HTML, JSON и README. Для PNG требуется Node.js и пакет
`sharp`, доступный стандартному `require` (в том числе через `NODE_PATH`):

```text
node design/hatching_catalog/render_catalog.cjs
```

Готовые PNG уже сохранены. Локальный просмотр не требует сборки:

```text
python -m http.server 8763 --bind 127.0.0.1 --directory design/hatching_catalog
```

Открыть `http://127.0.0.1:8763/catalog.html` или сам `catalog.html` в браузере.
