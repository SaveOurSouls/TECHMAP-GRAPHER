# Варианты ортографической проекции UL1061

Новая итерация по референсам пользователя. Все боковые виды построены как строгая 2D-проекция сверху: параллельные линии по длине, прямоугольный контур оболочки, без перспективы и изометрии.

- [Вариант A — слоистый каталог](./option-a-orthographic-layered.png)
- [Вариант B — плотная инженерная укладка](./option-b-orthographic-dense.png)
- [Вариант C — сравнение оболочек](./option-c-orthographic-sheaths.png)

В поперечных сечениях провода уложены касательно, без перекрытия. Внутри круга показан проводник золотой точкой, цветное кольцо — изоляция; отдельными слоями показаны экран, нейлоновая оплётка и термоусадка.
