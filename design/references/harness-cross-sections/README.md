# Референсы поперечных сечений жгутов UL1061

Три векторно собранных листа в PNG для согласования визуального стандарта:

- [01 — 1–10 проводов](./01-ul1061-1-10.png)
- [02 — 2–5 проводов под нейлоновой оплёткой](./02-ul1061-nylon-braid.png)
- [03 — 2–5 проводов под нейлонкой и термоусадкой](./03-ul1061-nylon-plus-heatshrink.png)

На каждом листе есть поперечное сечение и боковой 2D-вид как условная проекция сверху. В поперечнике все окружности проводов уложены касательно, без наложений; в боковой проекции часть нижних проводов скрыта верхними слоями и подписано, сколько жил видно.

Оболочки полупрозрачные, чтобы читалась укладка. Нейлоновая оплётка показана бирюзовой сеткой, термоусадка — янтарным внешним контуром.

## Диаметры

Использованы ориентировочные наружные диаметры UL1061: 30 AWG — 0,89 мм; 28 AWG — 0,99 мм; 26 AWG — 1,08 мм; 24 AWG — 1,23 мм; 22 AWG — 1,42 мм; 20 AWG — 1,62 мм. Диаметр медного проводника показан отдельно золотой точкой. Точные значения нужно сверить с паспортом выбранного производителя.

Параметры оболочек для референса: нейлоновая оплётка — стенка около 0,30 мм и зазор около 0,50 мм; термоусадка — стенка после усадки около 0,45 мм.

`render-cross-sections.py` — воспроизводимый скрипт построения PNG.
