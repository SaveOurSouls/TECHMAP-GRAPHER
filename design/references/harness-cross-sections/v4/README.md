# Плотная упаковка UL1061

В этой версии геометрия строится как плотная упаковка окружностей:

- соседние окружности касаются;
- пересечений нет;
- внешний контур рассчитывается как минимальная описывающая окружность для выбранной укладки;
- стрелка задаёт направление вида;
- справа остаётся плоская ортогональная проекция без изометрии;
- `packing-metrics.json` содержит AWG-наборы, расчётный внешний диаметр и минимальный зазор.

Файлы:

- `01-packed-reference-bare.png` — без общей оболочки;
- `02-packed-reference-nylon.png` — под полупрозрачной нейлонкой;
- `03-packed-reference-nylon-heatshrink.png` — под нейлонкой и термоусадкой.
