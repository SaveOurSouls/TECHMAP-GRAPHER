# Проекция по первому пересечению луча

Проекция строится из поперечного сечения. Для каждой линии сканирования, перпендикулярной направлению взгляда, луч проходит слева направо и выбирает первый цветной пиксель провода. Все следующие пересечения этого луча отбрасываются. Поэтому боковой вид показывает только ту часть жил, которая реально видна с выбранного направления.

Оболочки рисуются отдельным полупрозрачным слоем поверх проекции и могут визуально складываться с цветом проводов внутри.

Файлы:

- `01-packed-reference-bare.png` — без общей оболочки;
- `02-packed-reference-nylon.png` — полупрозрачная нейлоновая оболочка;
- `03-packed-reference-nylon-heatshrink.png` — нейлонка и термоусадка.

`packing-metrics.json` содержит число видимых сегментов, внешний диаметр плотной упаковки и минимальный зазор между окружностями.
