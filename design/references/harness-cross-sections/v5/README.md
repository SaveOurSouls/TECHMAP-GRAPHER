# Референсы поперечных сечений UL1061

В каталоге лежат три PNG-листа с наборами из 2–5 проводов UL1061 (30–20 AWG):

- `01-max-contact-bare.png` — провода без общей оболочки;
- `02-max-contact-nylon.png` — общая нейлоновая оболочка;
- `03-max-contact-nylon-heatshrink.png` — нейлонка и термоусадка.

Каждая строка показывает один и тот же набор в условном виде сверху и сбоку. Стрелка задаёт направление взгляда. Боковая проекция строится сканированием лучей, перпендикулярных направлению взгляда: для каждого луча используется первое пересечение с цветной окружностью, дальние провода не попадают в этот пиксельный слой. Оболочка наносится отдельным полупрозрачным RGBA-слоем поверх проекции.

Положение проводов строится перебором касательных конфигураций. Сначала выбирается конфигурация с максимальным числом пар касаний, затем — с минимальным радиусом описывающей окружности. Проверка `packing-metrics.json` подтверждает нулевой минимальный зазор и 1/3/5/7 касаний для 2/3/4/5 проводов соответственно.

Исходный скрипт `render-v5.py` воспроизводит все PNG и метрики. Файлы сохранены в RGB PNG после явной альфа-композиции оболочки на белый фон.
