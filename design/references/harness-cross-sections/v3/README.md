# Референсы в стиле пользовательского образца

Изображения повторяют логику приложенного примера:

- стрелка слева задаёт направление вида;
- круг показывает фронтальное поперечное сечение;
- справа — ортогональная проекция сверху без изометрии;
- цветные кольца — изоляция проводов, белые центры — проводник;
- чёрный контур — общая оболочка;
- для нейлонки и термоусадки оболочка показана полупрозрачным цветным слоем.

Файлы:

- `01-reference-style-bare.png` — без общей оболочки;
- `02-reference-style-nylon.png` — полупрозрачная нейлоновая оплётка;
- `03-reference-style-nylon-heatshrink.png` — нейлонка и термоусадка.

Приложенные пользователем картинки использованы только как визуальные референсы композиции и слоёв. Размеры UL1061 остаются ориентировочными и требуют сверки с паспортом конкретного провода.
