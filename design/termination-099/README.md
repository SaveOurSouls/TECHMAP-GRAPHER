# 099 · векторные символы оконцовок

Набор является проектным атласом для будущей связки Э4/Чертежа, а не нормативными УГО и не подтверждает каталожные расшифровки. SVG сделаны воспроизводимым генератором `generate.py`.

## Файлы

- `receptacle-detail.svg` — прямая flat female по историческому C1 `af5ec56d` (головка 7,3/6,6, шейка 2,3) рядом с новым полностью изолированным флажком по C3 `82516bcf`. Открытая металлическая головка относится только к прямой female; флажок имеет самостоятельный цельный Г-корпус.
- `flag-variants.svg` — четыре конструкции флажкового контакта и Э4 каждой: цельная изоляция, открытый обжим, гладкая закрытая трубка, рифлёная закрытая трубка; отдельно синий/жёлтый изолированные корпуса.

- `atlas.svg` — светлый русский атлас 17 семейств: Э4 условный вид и Чертёж боковой/сверху. Высота зависит от числа семейств.
- `profile-detail.svg` — восемь увеличенных профилей по фотографиям от 15.10.2026 и одна форма с красной, синей и жёлтой манжетами; цвет не задаёт сечение.
- `flows.svg` — схемы 2, 3 и 4 проводов на одном наконечнике, гильза 2+2 по краям и универсальная Разделка.
- `dimensions.svg` — проектная шпаргалка полей C1/C2.
- `*-e4.svg`, `*-drawing.svg` — отдельные ассеты. `preparation-*.svg` — восемь вариантов Разделки.
- `manifest.json` — стабильные ID, координаты якорей, роли, pivot, количество электрических точек и оговорки.
- `generate.py` — генератор и встроенная проверка XML/якорей.

## Геометрический контракт

1. У наконечника ровно один якорь `data-role="wire-entry"`; кольцо, вилка, отверстие, pin/socket сочленение и флажковая геометрия не являются дополнительными портами.
2. У гильзы ровно два якоря `anchor-wire-entry-a/b`, строго по краям. УЗ шов показан как операция внутри гильзы.
3. `×2`, `×3`, `×4` — только аннотация нескольких проводов на существующей точке, без клонирования портов.
4. Вращение наконечника выполняется вокруг его якоря; гильза вращается вокруг pivot в середине, два крайних якоря следуют её концам. Индекс соединителя в интеграции должен быть внешней подписью поверх слоёв.
5. В отдельных ассетах ID якорей сохранены. Составные листы не используют повторные ID якорей; `data-role` остаётся для проверки.
6. Размерные поля C1/C2 сохранены как имена: НКИ/НВИ `L/L1/D/B/d1/P/S`; НШВИ `L/L1/C/W/A`. Численные значения и миллиметры в SVG не утверждаются.
7. Универсальная «Разделка» — одна точка на Чертеже и восемь вариантов Э4: без разделки, медь, лужёная медь, pin, socket, pin+seal, socket+seal, lug.
8. Контур Э4 строится теми же путями, что Чертёж: монохромная заливка и сокращённые детали сохраняют силуэт. В Чертежe добавлены умеренные градиенты, рёбра металла, раструб манжеты, открытый штампованный переход и пружинные завальцовки. Толщина основного контура — 0,8 единицы viewBox, деталей — 0,55.
9. У всех четырёх флажков провод входит слева через `(32,50)`, pivot совпадает с этим якорем, ось сочленения направлена вертикально. Приёмное гнездо, окно перемычки и завальцовки не создают второго порта. `flag` сохраняет прежний ID, но теперь обозначает полностью изолированный Г-профиль.

| Стабильный ID | Конструкция |
| --- | --- |
| `flag` | Цельный полупрозрачный Г-образный корпус; металл скрыт внутри, на торце видны завальцовки |
| `flag-bare-open` | Неизолированный открытый обжим: две пары крыльев для проводника и изоляции, крупное окно штампованной перемычки |
| `flag-bare-pressed-smooth` | Неизолированная закрытая гладкая трубка прессовки с двумя диаметрами |
| `flag-bare-pressed-ribbed` | Неизолированная закрытая рифлёная трубка прессовки одного диаметра |

## Оговорки по номенклатуре

`НВШ` сохранён как alias; для визуализации предложена геометрия `pin blade`, расшифровка не утверждается. Каталожный C3 от 14.10 трактуется как маркировка `SC`; соответствие DIN не подтверждается. Цветовые токены обозначают визуальные роли и не являются спецификацией покрытия или материала.

## Проверка

Запустить bundled Python: `...\dependencies\python\python.exe design/termination-099/generate.py`. Генератор печатает число SVG и проверяет, что XML разбирается, а число и координаты якорей совпадают с `manifest.json`; в каждом SVG нет повторных ID. Для визуальной проверки открыть или отрендерить `atlas.svg`, `flag-variants.svg`, `receptacle-detail.svg`, `profile-detail.svg`, `flows.svg` и `dimensions.svg`; вручную проверить русские подписи, совпадение силуэтов Э4/Чертежа, различие четырёх флажков, один якорь наконечника и два крайних якоря гильзы. Растры последней серии проверок находятся вне Git в `artifacts/termination-099-flags/`.
