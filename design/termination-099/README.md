# 099 · векторные символы оконцовок

Набор является проектным атласом для будущей связки Э4/Чертежа, а не нормативными УГО и не подтверждает каталожные расшифровки. SVG сделаны воспроизводимым генератором `generate.py`.

## Файлы

- `atlas.svg` — светлый русский атлас 14 семейств: Э4 условный вид и Чертёж боковой/сверху.
- `flows.svg` — схемы 2, 3 и 4 проводов на одном наконечнике, гильза 2+2 по краям и универсальная Разделка.
- `dimensions.svg` — проектная шпаргалка полей C1/C2.
- `*-e4.svg`, `*-drawing.svg` — отдельные ассеты. `preparation-*.svg` — восемь вариантов Разделки.
- `manifest.json` — стабильные ID, координаты якорей, роли, pivot, количество электрических точек и оговорки.
- `generate.py` — генератор и встроенная проверка XML/якорей.

## Геометрический контракт

1. У наконечника ровно один якорь `data-role="wire-entry"`; кольцо, вилка, отверстие, pin/socket сочленение и флажковая геометрия не являются дополнительными портами.
2. У гильзы ровно два якоря `anchor-wire-entry-a/b`, строго по краям. УЗ шов показан как операция внутри гильзы.
3. `×2`, `×3`, `×4` — только аннотация нескольких проводов на существующей точке, без клонирования портов.
4. Вращение наконечника выполняется вокруг его якоря; гильза вращается вокруг pivot в середине, два крайних якоря следуют её концам. Индекс соединителя в интеграции должен быть внешней подписью поверх слоёв.
5. В отдельных ассетах ID якорей сохранены. Составные atlas/flows/dimensions не используют повторные ID якорей; `data-role` остаётся для проверки.
6. Размерные поля C1/C2 сохранены как имена: НКИ/НВИ `L/L1/D/B/d1/P/S`; НШВИ `L/L1/C/W/A`. Численные значения и миллиметры в SVG не утверждаются.
7. Универсальная «Разделка» — одна точка на Чертеже и восемь вариантов Э4: без разделки, медь, лужёная медь, pin, socket, pin+seal, socket+seal, lug.

## Оговорки по номенклатуре

`НВШ` сохранён как alias; для визуализации предложена геометрия `pin blade`, расшифровка не утверждается. `C3` трактуется как маркировка `SC`; соответствие DIN не подтверждается. Цветовые токены обозначают визуальные роли и не являются спецификацией покрытия или материала.

## Проверка

Запустить bundled Python: `...\dependencies\python\python.exe design/termination-099/generate.py`. Генератор печатает число SVG и проверяет, что XML разбирается, а число и координаты якорей совпадают с `manifest.json`; в каждом SVG нет повторных ID. Для визуальной проверки открыть или отрендерить `atlas.svg`, `flows.svg` и `dimensions.svg`; вручную проверить русские подписи, различимость Э4/Чертежа, один якорь наконечника и два крайних якоря гильзы.
