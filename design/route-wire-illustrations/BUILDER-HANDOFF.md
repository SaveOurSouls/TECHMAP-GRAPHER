# Комплект графики для сборщика справочника «Полуфабрикаты провода»

Запрос владельца: пересобрать графику с исправленным вводом изоляции по последнему C2. Требование REQ-061, карточка 036. Исправление рисунка: коммит `eaa9f45`; общая сборка элементов: `2af8d37`. Комплект содержит графику и её исходник. Полную Windows-сборку приложения выполняет сборщик по `docs/project-workflow.md` основного репозитория.

## Подключение к справочнику

В репозитории подключение уже выполнено в `WireBlankCatalogEditor.tsx`: `WireBlankPreview` вызывает общий модуль; маршрут использует тот же компонент. При переносе в другую рабочую копию сборщик должен включить и это подключение из `2af8d37`, и исправление `eaa9f45`. Копирования одних статических SVG недостаточно для динамического превью.

```js
import { renderWireSvg, renderPartSvg } from "./wire-blank-artwork.mjs";

const svg = renderWireSvg({
  left: row.start,
  right: row.end,
  color: row.color,
  title: row.title,
});
const imageSrc = `data:image/svg+xml;charset=utf-8,${encodeURIComponent(svg)}`;
// Самостоятельный элемент при необходимости:
const terminalSvg = renderPartSvg("terminal", "#26609e");
```

Контракт записи: `sourceId=technology-wire-blanks`, `entityType=wire-blank`; `start` и `end` выбираются независимо из `cut`, `copper`, `tin`, `terminal`, `sealed`, `sealed-pin`; `color` — `#RRGGBB`. Все 36 сочетаний поддерживаются рендерером. 13 файлов — стартовый набор, а не ограничение конфигураций.

Использовать `renderWireSvg` для полной конфигурации. Геометрию из этого модуля не перерисовывать и не дублировать в React, CSS или другом генераторе. Обновлять одновременно исходник, типы, SVG и манифест. Встраивание через `<img>` изолирует ID градиентов; если потребуется несколько inline SVG в одном документе, сборщик должен обеспечить уникальность их ID и ссылок.

`photoDataUrl` имеет приоритет над типовой графикой. Для просмотра обновлённой типовой графики пользователь может выбрать «Вернуть рисунок» в строке с фото. Автоматически удалять фото, пользовательские записи или закреплённые snapshots не требуется. Seed создаёт 13 записей лишь при отсутствии активного справочника; обновление графики не требует сброса базы или изменения ID записей.

## Геометрия и цвет

- Общий `viewBox`: `0 0 1200 240`, ось провода `y=120`. Тело: `x=220…980`, `y=94…146`.
- Порядок: тело, левый конец, правый конец. Отражение правого конца: `translate(1200 0) scale(-1 1)`. Элементы имеют общий холст; отдельно подрезать их прозрачные поля перед совмещением нельзя.
- Изоляция продолжается под первым металлическим обжимом до `x=171.5`, середины зазора `162…181`. Оставшаяся половина зазора показывает медь. Правило уже встроено во все три исполнения терминала и отражается справа.
- Внутри терминала порядок слоёв: медь → изоляция → уплотнитель (если есть) → металл. Обжимы и уплотнитель должны перекрывать изоляцию.
- Параметр `color` красит тело и продолжение изоляции; медь, лужение, металл и уплотнитель сохраняют свои цвета. CSS-переменная внешнего HTML не проходит внутрь SVG, загруженного через `<img>`: для произвольного цвета применять API генератора.
- Прямые торцы резки, меди и лужения сохранены. Координаты символические; производственные размеры берутся из записи маршрута.

## Проверка после распаковки

Из корня комплекта:

```powershell
node design/route-wire-illustrations/verify.mjs
node design/route-wire-illustrations/generate.mjs
node design/route-wire-illustrations/verify.mjs
```

В основном репозитории сборщик проверяет профильные тесты `WireBlankCatalogEditor`, `WireBlankCatalog`, `route-wire-blank`, `route-inline-render`, TypeScript/Vite и `WireBlankCatalogSeedTests`. После упаковки приложения проверить, что в клиентских ресурсах лежат 13 SVG, `manifest.json` и 7 SVG частей; превью справочника и маршрута показывает изоляцию до середины зазора.

По `terminal-detail.png` сравнить оба исполнения: изоляция видна за первым обжимом, далее медь; затем проверить правый конец, смену цвета и сочетание двух разных концов. Ручная приёмка установленного приложения остаётся за сборщиком/владельцем.

IPC/WHMA-A-620E не был доступен для нормативной сверки. Комплект реализует положение изоляции, явно заданное владельцем по C2; соответствие стандарту не заявляется.
