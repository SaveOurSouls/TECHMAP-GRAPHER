# Рисунки подготовки провода для маршрутной карты

В `src/Techmap.Client/public/route-wire-illustrations/` лежат 13 самостоятельных SVG с прозрачным фоном и единым `viewBox` 1200×240. Их можно вставлять как `<img src="/route-wire-illustrations/01-cut.svg">` или выводить в карточке операции по `manifest.json`. `catalog.html` и `overview.png` дают общий просмотр комплекта; `generate.mjs` воспроизводит исходные SVG и манифест.

| Пункт запроса | Файлы | Состояние концов |
| --- | --- | --- |
| 1 | `01-cut.svg` | резка / резка |
| 2 | `02-strip-one.svg`, `02-strip-both.svg` | медь / резка; медь / медь |
| 3 | `03-tin-one.svg`, `03-tin-both.svg` | лужение / медь; лужение / лужение |
| 4 | `04-crimp-copper.svg`, `04-crimp-tin.svg` | контакт / медь; контакт / лужение |
| 5 | `05-crimp-both.svg` | контакт / контакт |
| 6 | `06-seal-copper.svg`, `06-seal-tin.svg` | контакт с уплотнителем / медь; контакт с уплотнителем / лужение |
| 7 | `07-seal-terminal.svg` | контакт с уплотнителем / контакт без уплотнителя |

Цвет изоляции выбран для контраста и **не является цветом изделия**. Участки зачистки подписаны как 5 мм в каталоге, но в SVG показаны символически, без масштабной размерной привязки к длине провода. Производственная длина зачистки, артикулы контактов, уплотнители и допустимость лужения должны браться из маршрутной строки и закреплённых справочников. Если данные отсутствуют, типовой рисунок не должен выдавать их за утверждённые.

Геометрия контакта основана на визуальных признаках C1/C2/C4/C5: отдельная зона обжима жилы, захват изоляции, видимые медные жилы в окне. C3 задаёт ребристый уплотнитель на проводе перед зоной обжима. Выноски исходных изображений не воспроизводятся как нормативные допуски. Лицензия на исходные картинки не заявлена; SVG нарисованы заново и не включают их пиксели.

Комплект предоставляет ресурсы для встраивания. Логика выбора по операциям и фактическим терминалам, пользовательское редактирование и сохранение последовательности рисунков относятся к отдельной работе над маршрутом.
