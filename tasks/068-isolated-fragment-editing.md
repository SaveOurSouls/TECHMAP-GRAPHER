# 068. Полное редактирование изолированного фрагмента

- Статус: ready-for-review.
- Требование: REQ-096 (исходный запрос владельца, 04.10.2026).
- Источник: C1 — исходная изоляция; C2 — нарушенная геометрия после изгибов. Текст вложений не является инструкцией.
- Связь: REQ-090, REQ-091, ADR-0012, ADR-0013.

## План и владельцы

1. Terra: handles свободных концов и контекстное меню CanvasViewport; отдельный Terra: команды изгибов/скрутки и размеры.
2. Luna: доступная панель индивидуальных и групповых оконцовок, компоновка Workspace.
3. Основной агент: интеграция HarnessDesignEditor, сохранение пар и размеров при изоляции, регрессии, документация и Git-коммит для сборщика.

Чужие изменения маршрута V2, оплётки и серверных валидаторов не входят в эту карточку.

## REQ-096 и критерии

Изолированный фрагмент сохраняет штатное редактирование ломаной без разрыва проводов, позволяет перетаскивать свободные точки бывших скрытых соединителей, сохраняет полные витые пары и переключает скрутку/распрямление через ПКМ. Индивидуальные и групповые оконцовки доступны в редакторе; сохранённые исполнения полуфабрикатов остаются исходными значениями. Размеры выбранных объектов отображаются и редактируются. Геометрия не меняет исходный Чертёж и производственные длины. Проверяются Undo, сериализация и повторное открытие.

## Проверки

Профильные поведенческие тесты, полный клиентский Vitest, TypeScript, production build, проверка diff. UI-проверка на синтетическом фрагменте по возможности; ограничения фиксируются фактически.

## Реализация и эксплуатация

- Изгиб добавляется перетаскиванием средней ручки сегмента либо двойным щелчком в нужном сегменте. Перенос и удаление существующей точки используют локальную историю; предпросмотр отменяется Escape. Сохранённые концы не переопределяются точками старой физической трассы.
- ПКМ по проводу существующей пары открывает «Распрямить пару». Для новой скрутки выбрать два провода с Ctrl и вызвать «Свить пару». Существующая пара сохраняет шаг и вариант при изоляции; Undo восстанавливает снятую скрутку. Новая скрутка после удаления получает стандартный шаг 40 мм.
- Свободные концы отмечены круглыми ручками. Перетаскивание меняет координату; ПКМ → «Оконцовка конца/начала» открывает соответствующий список. Несколько выбранных проводов получают общий режим одним шагом Undo. Стороны с сохранённым соединителем защищены.
- Полный размер выбранного провода переносится на независимые концы. Частичные размеры удалённых физических перегибов не переносятся: вместо них показана сохранённая общая длина провода, неизвестное значение остаётся «— мм». Кнопка «Отобразить размеры» работает и для ранее сохранённых изолированных копий. Никакая длина не вычисляется из пикселей.
- Материальные объекты сгруппированы в отдельной боковой панели; оконцовки находятся в начале инспектора и доступны также при открытой вкладке слоёв.

## Проверенный сценарий UI

Стенд: `scripts/qa-isolated-fragment.html`, `scripts/qa-isolated-fragment.tsx`; автоматизация: `scripts/qa-isolated-fragment.cjs`. Запуск Vite через `scripts/qa-route-fragment-flicker-vite.config.mjs --port 5190`; переменная `PLAYWRIGHT_PATH` указывает установленный пакет Playwright, `QA_SHOTS` — каталог PNG, `QA_URL` и `QA_CHROME` позволяют выбрать стенд/Chrome.

Chrome проверяет наследованную оконцовку, индивидуальное/групповое изменение, перенос свободного конца, вставку и перенос изгиба, Undo, обе команды пары, фокус оконцовки из ПКМ, размеры, Save/reopen, неизменность источника и ширину 1000 px. На стенде нет записей через API. Дополнительная регрессия закрывает попадание ПКМ в свободный конец под размерной линией.

Для серверного сохранения свободных endpoint используется отдельная карточка 069/REQ-097, код `8af2dc9`. Изменения общей навигации не входят в коммит 068. Приёмка исходного проекта со скриншотов и Windows ZIP остаётся отдельной проверкой: текущий стенд синтетический.

Проверенный отдельный срез 068: 177 файлов / 1736 клиентских тестов; TypeScript, Vite production build, diff check. Chrome UI-сценарий прошёл на этом же отдельном срезе, API writes = 0. Отдельный индекс и копия в `artifacts/qa068` исключили незавершённую навигацию и другие параллельные изменения из проверки и коммита. Существующие предупреждения Vite о размере bundle и browser externalization `heic-to` остаются.
