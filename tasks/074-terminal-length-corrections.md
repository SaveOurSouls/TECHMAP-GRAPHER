## Результат и границы

У каждого конца выбранного провода в свойствах Чертежа есть кнопки `L+` и `L−`.
Они подставляют значение из столбцов `lengthPlusMm`/`lengthMinusMm` терминала,
подключённого к соответствующему контакту соединителя; `L+` используется при
создании нового соединения как штатное значение. Значение остаётся обычной
редактируемой знаковой поправкой провода.

Длина спецификации, схемы соединений и карты резки продолжает поступать из
одной канонической суммы `lengthMm + endCorrectionFromMm + endCorrectionToMm`
с уже существующим финальным округлением. Кабели, покрытия и свободные концы
не получают неявных терминальных поправок.

## Критерии приёмки

- Для обоих подключённых концов показаны `L+` и `L−`; отсутствующее значение
  терминала не подставляется как ноль.
- Новое соединение использует `L+` соответствующего терминала, а выбор `L−`
  записывает отрицательную поправку. Ручной ввод после этого сохраняется.
- Сценарий 100,1 + 1,25 − 0,35 мм даёт 101,0 мм в спецификации, схеме
  соединений и карте резки при шаге 0,001 мм.
- Значения терминала остаются в snapshot контакта и сохраняются после
  сериализации документа.
