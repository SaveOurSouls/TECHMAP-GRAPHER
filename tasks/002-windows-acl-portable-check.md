# 002. Проверка portable из исходного Windows-пути

- **Статус:** backlog
- **Владелец / чат:** не назначен
- **Источник запроса:** найдено в протоколе `docs/m5-07-acceptance.md`
- **Требования:** REQ-001, REQ-003
- **Владелец файлов:** диагностический протокол; назначить перед началом

## Критерии приёмки

- Повторены семь режимов непосредственно из пути с кириллицей и зафиксирован точный stderr/код завершения.
- Сравнены ACL, временный каталог, антивирус/политика запуска и поведение ASCII-пути.
- Установлена воспроизводимая причина `UnauthorizedAccessException` или честно указано, что причина не найдена. Код менять только при доказанном дефекте и отдельной карточке.
