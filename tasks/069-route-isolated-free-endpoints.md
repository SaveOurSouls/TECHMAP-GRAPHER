# 069. Свободные концы изолированного рисунка не должны отклонять маршрут

- **Статус:** ready-for-review

## Результат и границы

Сохранение производственного маршрута с `isolatedDrawingCopy` и свободным концом провода должно проходить серверную проверку. Синтетический endpoint разрешён только в изолированной копии, только с ID `isolated:<wireId>:<from|to>` для текущего провода и стороны и только с контактом `free`. Обычный чертёж и остальные электрические графы по-прежнему требуют существующий соединитель и контакт. UI, электрические связи, длины и формат основного чертежа не меняются.

## Критерии приёмки

- Изолированная копия с двумя синтетическими свободными концами принимается.
- Неверный ID провода, сторона или контакт `free` отклоняются.
- Обычный дизайн не получает послабления для отсутствующих соединителей.
- Регрессионный тест покрывает принимаемый и отклоняемый варианты.

## Журнал результата

- Диагноз: `route-drawing-copy.ts` создаёт синтетические endpoint IDs без connector shells; ошибка возникает при серверной валидации `isolatedDrawingCopy` во время сохранения маршрута.
- Коммит кода/документации: `0deea63` (`fix(route): validate isolated free endpoints`).
- Проверки и даты: 04.10.2026 — клиентский Vitest 7/7; `git diff --check`; серверный тест заблокирован NU1900.
- Ограничения и открытые вопросы: ручная проверка на пользовательском маршруте и packaged-приложении не входит в автоматический тест.
