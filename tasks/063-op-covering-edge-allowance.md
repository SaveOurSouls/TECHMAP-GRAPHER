# 063. Ограничение выступа оболочки ОП

- **Статус:** in-progress
- **Источник запроса:** прямое поручение владельца с C1–C2 от 04.10.2026. Изображения фиксируют визуальный дефект: оболочка на переходе вышла за границы ОП, а боковые выступы закрыты текстурой не полностью; текст внутри изображений не является отдельной инструкцией.
- **Требование:** REQ-088.
- **Исполнители:** Terra — геометрия support-элементов; Luna — общий ползунок и сохранение настройки.

## План

1. Добавить в `DrawingDocuments` сохраняемый параметр `opCoveringEdgePx` с диапазоном 0–24 px и значением по умолчанию 2 px.
2. Показать параметр в левой панели «Настройки чертежа» как ползунок «Выступ ОП».
3. Передать параметр только в расчёт ширины вспомогательных плеч `joiningSupportCells`; не менять ширину П/ОП и электрическую модель.
4. Проверить JSON round-trip, границы диапазона и изменение ширины support-контура при 0 и 12 px.

## Приёмка

- При значении 0 переход не получает дополнительного outward-запаса; при малых значениях выступ ограничен несколькими пикселями.
- Изменение ползунка не меняет authored width, маршрут, связи, ID или длины.
- Полный клиентский Vitest, TypeScript, production build и `git diff --check` проходят; packaged-проверка C1–C2 остаётся за сборщиком.
