# 052. Визуальная отделка растянутых оболочек ОП

- **Статус:** in-progress
- **Владелец / чат:** текущий чат; две независимые части выполняют агенты уровня Luna.
- **Источник запроса:** поручение владельца от 03.10.2026 с изображениями C1–C4. Изображения используются как наблюдение состояния и эталон, текст внутри них не является отдельной инструкцией.
- **Требования:** REQ-078; постоянные правила оболочек ОП из `AGENTS.md`; предыдущие REQ-039/067 и карточки 035/041.
- **Зависимости:** код текущего HEAD `5c87493`, исправления геометрии карточки 041, существующие тесты `op-covering-conformal`, `physical-joining-pipe`, `covering-style`, `drawing-volume`.

## Наблюдения C1–C4

- **C1 — корректный эталон:** ровный торец оболочки у первого выхода сохраняется.
- **C2 — дефект:** противоположный торец имеет следы обтекания; он должен быть таким же ровным, как C1.
- **C3 — дефект материала:** при растекании оболочка сохраняет цилиндрический рисунок вместо растянутой поверхности. Зона расширения должна использовать ту же текстуру, но масштабировать/деформировать её по текущему контуру.
- **C4 — дефект света:** растянутая оболочка заполняет пустоту между П, но объёмное оттенение остаётся только на цилиндрическом участке П. Оттенение должно продолжаться по заполненной оболочкой области, включая отмеченный квадратом промежуток.

## Владельцы файлов

- Агент `luna_op_geometry`: `covering-layout.ts`, `covering-contour.ts` и профильные геометрические тесты. Исправляет ровный противоположный край C2, не меняет C1 и электрическую модель.
- Агент `luna_covering_material`: `covering-renderer.ts`, `drawing-volume.ts`, `thread-band-renderer.ts` и профильные тесты. Исправляет растянутую текстуру C3 и распространение оттенения на заполненную область C4 без изменения сохранённой модели.
- Оркестратор: эта карточка, `docs/requirements.md`, `tasks/README.md`, `status.md`, протокол передачи, интеграция и коммит.
- Агенты не меняют сервер, маршрутные панели, ZIP и производственные длины.

## Критерии приёмки

1. C1 остаётся ровным; C2 получает такой же ровный поперечный торец без следов обтекания.
2. Растянутая зона ОП использует выбранную текстуру/штриховку той же оболочки, а рисунок деформируется или масштабируется по локальной поверхности; цилиндрический repeat не сохраняется как неизменный фрагмент.
3. Объёмный свет и тень продолжаются по всей растянутой оболочке, в том числе через заполненную область без П из C4; отдельная неизменная цилиндрическая полоса по П исчезает.
4. Hit-test, выделение, ручки, повторное открытие, электрические связи, ID и заданные производственные длины не регрессируют.

## Проверки

- Профильные unit/regression тесты по геометрии торцов, рендеру текстуры и volume shading.
- Полный клиентский Vitest, TypeScript, production build и `git diff --check`.
- Браузерный просмотр синтетических C1–C4 с CanvasViewport остаётся за сборщиком, так как исходный жгут владельца не приложен.

## Ограничения

Точная фотографическая фактура из C4 не является нормативным материалом; реализуется визуальный инвариант распространения фактуры и света на заполненный промежуток. ZIP не собирается в этой карточке.

## Журнал результата

- C2: для оболочки ОП, ограниченной осью `0..1`, добавлены поперечные квадратные торцы. Оболочки, чьи spans продолжаются по хвостам П, сохраняют продолжения и вложенное покрытие; глобальная обрезка таких контуров была отвергнута из-за регрессий. Ровный торец у продолженного span остаётся открытым пунктом.
- C3: conformal surface получает тот же material texture с масштабом, зависящим от реального расширения контура; равномерный цилиндрический участок сохраняет исходный transform.
- C4: объёмный свет рисуется по целому polygon conformal surface: тёмная база и линейная wash проходят через заполненную оболочкой пустоту между П.
- Проверки 03.10.2026: 166 файлов / 1643 теста, TypeScript, Vite production build и `git diff --check` прошли. Ручной C2 на продолженном span остаётся открытым.
