## Критерии

- Первый уровень показывает уникальные `payload.name` («Название»), не типы.
- После выбора названия второй уровень содержит только относящиеся к нему записи и показывает `sourceKey` («Номер»); возврат возвращает список названий.
- После выбора сохраняется точная запись по `recordId` и нормы; в карточке читаются название и номер, а тип операции визуально вторичен.
- Старые сохранённые операции продолжают разбираться без миграции; расчёт не изменён.
