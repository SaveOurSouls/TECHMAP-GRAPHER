## План и приёмка

1. Одна строка на операцию: название/номер, тип, длина, параллельность, нормы, циклы, подготовка, время, выбор ПФ и удаление.
2. Кнопка ПФ открывает список. Назначения предыдущих строк серые, но доступны для повторного выбора; фильтр скрывает ранее занятые кроме уже назначенных текущей строке (чтобы можно было снять выбор). Это безопасная интерпретация: владелец не запрещал повторные операции над одной продукцией.
3. Сохранить двухуровневый выбор БД.ОП, autoassignment одного ПФ, расчёты и обновление после удаления предыдущей операции.
4. TypeScript, полный client test/build, diff-check, browser сценарии назначения/фильтра/удаления, desktop layout.
5. Коммит, push, handoff и coverage. ZIP не запрошен.

## Результат и проверки

Операции вынесены в RouteV3OperationTable: общая сетка из 14 колонок, одна строка на операцию; кнопка ПФ, отдельный dialog с поиском/фильтром и серыми предыдущими назначениями. Статус занятости вычисляется из текущего порядка операций, снимается после удаления предыдущей строки. Escape закрывает только окно ПФ. Старые данные, формулы, двухуровневый БД.ОП и автоматическое назначение одного выхода сохранены.

- Vitest: 195 файлов / 1878 тестов PASS. Первый sandbox-прогон дал ENOENT временных SSR-файлов; повтор вне sandbox PASS.
- TypeScript, Vite production build и diff-check PASS; предупреждения heic-to/размера bundle остаются.
- Playwright Chrome, localhost fixture: 1440×1000 — сетка помещается (1342/1342 px), операции по одной строке; назначения, серые позиции, фильтр, повторный выбор, удаление предыдущей строки, пустой поиск и Escape PASS.
