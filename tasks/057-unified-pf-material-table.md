## Результат и границы

В строке производственного маршрута каждый ПФ показывается одной строкой таблицы: индекс ПФ, общее название объекта, материал, длина, концы, разделка, количество, запас и время. Отдельные повторяющиеся строки параметров убраны. Значения компонентов и расчёт партии сохраняются; модель маршрута, состав и сохранение не меняются. Для сборки остаётся суммарный ввод параметров этапа.

C1 показывает верхнюю таблицу материалов и выделенный красным отдельный блок параметров ПФ. Ожидаемый результат задан текстом владельца: единая таблица, одна строка на ПФ, поля количества, запаса и времени в конце. Надписи внутри изображения не рассматриваются как отдельные инструкции.

## Критерии приёмки

- У каждого компонента объединённого полуфабриката его индекс, объект и три редактируемых параметра находятся в одной строке таблицы.
- Название объекта не повторяется во второй строке; числовые поля связаны с правильным компонентом по `ref`.
- Одиночный ПФ и сборка сохраняют работающий ввод количества, запаса и времени; сводка партии корректна.
- Таблица помещается в колонку задачи без внутренней горизонтальной прокрутки на широком экране.
