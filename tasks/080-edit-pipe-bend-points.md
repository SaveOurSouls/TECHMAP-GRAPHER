## Результат и границы

В C1/C2 и Т-образном ветвлении пользователь может перемещать и удалять точки
изгиба после создания пайпа. Сохраняются геометрическая связность, узлы,
электрические связи, покрытия и производственные длины. Работа не меняет общий
дизайн редактора и не включает ручную packaged-приёмку владельца.

## Критерии приёмки

- Автоматически созданный изгиб после создания пайпа имеет рабочий handle и не
  становится навсегда фиксированным.
- Перемещение точки меняет именно соответствующий bend, без скачка соседних
  участков и без создания дубликата.
- Удаление точки работает для обычного пайпа и Т-ветвления, корректно сохраняет
  оставшийся маршрут и связи.
- Для C1, C2 и T-конфигурации добавление/перемещение/удаление дают один шаг undo.
- Профильные Vitest, TypeScript/Vite и необходимые серверные проверки проходят.

## Follow-up по C1, 06–07.10.2026

По повторному поручению владельца точка №2 оставалась неактивной. Причина —
внешняя станция перехода ОП удалялась ранним выходом для `authoredIndex === -1`,
а при совпадении ручек первый найденный пайп выбирался без сравнения расстояния.
Добавлены явная команда очистки `enterOuter`/`exitOuter`, регрессия перемещения и
удаления станции и выбор ближайшей ручки в CanvasViewport. Электрические связи,
топология и производственные длины не меняются.

В повторной конфигурации с пайпами, подключёнными к одной точке, ручка
автоматического изгиба находилась по исходной ломаной, а рисунок уже использовал
округлённую проекцию оболочки. `projectPipeBundleControls` теперь получает
координату из того же sampled route, который используется при отрисовке; обратное
преобразование сохранено для записи исходной геометрии. Добавлен регресс C1 с
общей точкой и проверкой hit-test положения ручки.
