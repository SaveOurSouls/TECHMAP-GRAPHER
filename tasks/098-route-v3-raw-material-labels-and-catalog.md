## Результат и границы

В сырье C1/C2 подпись провода должна показывать марку, одно исходное сечение и цвет без дубля артикула. Обозначение провода в блоках Route v3 сопровождается кружком цвета; при двухцветной маркировке круг разделён на два цвета. C3/C4: каждый конец провода выводится отдельной строкой `Н: артикул / уплотнитель`, `К: артикул / уплотнитель`; пустой уплотнитель не заменяется тире. C5: выбор БД.ОП вновь открывает категории, затем операции выбранной категории, с возвратом на первый уровень.

Не менять идентичность проводов, электрические связи, производственные длины, расчёт операций, модель сохранения и интерфейс Маршрута v2.

## Владение файлами и план

1. Terra: чистые форматтеры описания сырья, цветов и концов; модельные/форматтерные тесты. Файлы `manufacturing/route-source.ts`, `manufacturing/cut-list-properties.ts`, `manufacturing/wire-display-formatters.ts`, новые профильные модули/тесты. UI-файлы не менять.
2. Luna: двухуровневый chooser БД.ОП и визуальное оформление кружка/двух строк в Route v3. Файлы `manufacturing-v3/RouteV3Graph.tsx`, `manufacturing-v3/route-v3-graph.css`, `manufacturing-v3/RouteV3Panel.tsx`, `manufacturing-v3/route-v3.css`, `manufacturing-v3/route-v3-wire-artwork.tsx`, профильные UI-тесты. Данные форматирования согласовать с Terra.
3. `/root`: реестр, требования, интеграция на границе файлов, полные проверки, QA, commit/push, handoff. Не включать незавершённое изменение реестра карточки 095 в коммит 098.

## Критерии приёмки

- C1/C2: маркировка сырья читается как марка · сечение · цвет, без повторного артикула; исходная единица AWG/мм² сохраняется.
- Одно- и двухцветные провода имеют соответствующий кружок в блоках с их обозначением; неизвестный цвет не подменяется выдуманным.
- C3/C4: начала и концы показываются двумя строками с `Н:` и `К:`; терминал с уплотнителем имеет `/ уплотнитель`, без уплотнителя — только терминал. Ручные виды концов сохраняются.
- C5: первый уровень — категории, второй — операции выбранной категории; возврат работает, выбор операции сохраняет запись и нормы.

## План проверки

Профильные тесты форматтеров и chooser, полный Vitest, TypeScript, Vite build, staged diff-check; рендерная проверка desktop/mobile по доступному браузерному пути.

## Результат

Terra добавил формат сырья с сохранением исходной единицы AWG/мм², перенос второго цвета и нейтральный индикатор для неизвестного цвета; концы унифицированы как `Н/К: артикул / уплотнитель` без пустого разделителя. Luna вернула двухуровневый выбор БД.ОП, подключила формат сырья и одно-/двухцветные кружки во все Route v3-блоки провода, а также раздельные строки концов в составе и preview.

- Кодовые коммиты: `fc09295`, `033e669`, опубликованы в origin.
- Проверки: Vitest 195 файлов / 1877 тестов, TypeScript, Vite build, `git diff --check` — PASS.
- Ограничение: Browser plugin недоступен; локальный Vite/Playwright QA по исходному жгуту и packaged UI остаётся сборщику.

Уточнение владельца от 15.10.2026 заменяет способ группировки БД.ОП: категориями служат значения «Название», а второй уровень показывает «Номер» внутри выбранного названия. Исправление ведётся отдельно в [100](100-route-v3-operation-catalog-name-number.md); прежняя группировка по типу не считается окончательным требованием.
