Новые карточки получают следующий свободный номер `NNN`. Индекс обновляется вместе с карточкой; исполнителей и владельцев файлов назначают до параллельной реализации.

Очередь, зависимости, открытые решения и общие сценарии раздела «Маршрут»:
[управление M5](../docs/m5-route-management.md). Статус `backlog` здесь
означает отсутствие проверенной приёмки соответствующей карточки, а не
отсутствие кода.
