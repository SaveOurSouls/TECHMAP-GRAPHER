# Очередь задач

Это восстановленные долги, а не автоматическое разрешение начать все карточки. Правила ведения: [порядок работы](../docs/project-workflow.md), [шаблон](_template.md). Статус карточки меняется только по фактическому результату.

| ID | Задача | Статус | Следующее действие |
| --- | --- | --- | --- |
| 001 | [Ручная UI-приёмка M5](001-manual-m5-acceptance.md) | backlog | После 007–012 пройти сквозной сценарий по точному ZIP; при новом коде пересобрать пакет. |
| 002 | [Portable из исходного Windows-пути](002-windows-acl-portable-check.md) | backlog | Воспроизвести и диагностировать отказ доступа. |
| 003 | [Сверка исторической документации](003-reconcile-history.md) | backlog | Разделить архивные записи и текущий индекс. |
| 004 | [Производственные XLSX/PDF и M6/M7](004-production-exports.md) | backlog | Согласовать границы с владельцем. |
| 005 | [Интеграционное покрытие](005-integration-coverage.md) | backlog | Выбрать узкий рискованный сценарий. |
| 006 | [Прозрачность и изгибы П/ОП](006-pipe-opacity-and-bends.md) | ready-for-review | Проверить С1–С3 на исходном чертеже; коммит вошёл в пакет `ab40dda`. |
| 007 | [Маршрут в строке и материалы](007-route-inline-and-materials.md) | backlog | Проверить UI и обозначения на реальных данных. |
| 008 | [Живые длины и ревизии маршрута](008-route-live-source-sync.md) | backlog | Проверить два окна и сохранность ручных правок. |
| 009 | [Заготовки и операции](009-route-blanks-operations.md) | backlog | Проверить 1/5 проводов, БД.ОП и БД.ТЕР. |
| 010 | [Рисунок и сборка](010-route-presentation-assembly.md) | backlog | Уточнить порядок рисунков и правило количества, проверить изоляцию. |
| 011 | [Допуск карты резки](011-route-cut-readiness.md) | backlog | Сравнить UI и прямой API после смены длины. |
| 012 | [Фото и перенос проекта](012-route-media-portability.md) | backlog | Проверить restart, экспорт/импорт и ограничения. |

Новые карточки получают следующий свободный номер `NNN`. Индекс обновляется вместе с карточкой; исполнителей и владельцев файлов назначают до параллельной реализации.

Очередь, зависимости, открытые решения и общие сценарии раздела «Маршрут»:
[управление M5](../docs/m5-route-management.md). Статус `backlog` здесь
означает отсутствие проверенной приёмки соответствующей карточки, а не
отсутствие кода.
