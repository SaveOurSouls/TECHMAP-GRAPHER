## Результат и границы

В таблице соединений и спецификации убрана декоративная голубая подсветка
связанных строк. При фокусе марки провода раскрывается полный загруженный
каталог, число марок показывается над списком, а область вариантов всегда
имеет вертикальную прокрутку. Табличные поля растягиваются по своим ячейкам.
Цвет схемы, которого нет среди цветов соответствующей марки в каталоге,
помечается `в базе не найден`.

Поставка ZIP в эту карточку не входит: коммит предназначен для агента,
который собирает следующий Windows x64 пакет.

## Критерии приёмки

- C1: строка таблицы/спецификации не получает голубую заливку при связи с объектом.
- C1: фокус поля «Марка» открывает полный каталог с видимым счётчиком и прокруткой; ввод ограничивает список.
- C2: поля таблицы имеют общую сетку ширины с заголовками и не сжимаются по длине значения.
- C3: неизвестный цвет схемы отображается с текстом `в базе не найден` и остаётся залитым цветом схемы.
