## Границы

Карточки и связи V2 удаляются отдельно и с подтверждением. Инспектор выбранной
карточки показывает таблицу C3 по каждому выбранному полуфабрикату и набор
миниатюр; клик по миниатюре открывает popup, закрываемый вторым кликом в любой
точке. Связь между карточками не переносит и не добавляет refs автоматически:
состав выбирается вручную в целевой карточке.

## Критерии приёмки

- Крестик удаления виден в правом верхнем углу карточки, подтверждение удаляет карточку и её связи.
- Клик по маркеру на стрелке с подтверждением удаляет одну связь.
- Таблица инспектора содержит все refs и колонки C3; пропущенные расчётные значения показываются как `—`.
- Провода и оболочки имеют миниатюры исходного рисунка; сборки используют сохранённую копию или изолированный фрагмент.
- Popup открывается по миниатюре и закрывается кликом в любом месте popup.
- Создание/связывание карточек не добавляет refs; refs появляются только через явный выбор в инспекторе.

## Проверки

- Целевые unit/render tests модели и панели.
- TypeScript, полный клиентский Vitest, Vite production build, `git diff --check`.

## Журнал результата

- Коммит реализации: текущий коммит этой карточки (хеш сообщён в ответе).
- TypeScript: успешно; полный Vitest изолированного среза: 181 файл / 1762 теста; целевые проверки V2: 15 тестов; Vite production build: успешно; git diff --check: успешно.
- Ограничения: данные V2 остаются в localStorage; packaged-версия и исходный жгут владельца не проверялись. Push ранее отклонён автоматической проверкой разрешений; повторная отправка не выполнялась. Известные предупреждения сборки: размер bundle и browser external для heic-to.
- Решение владельца о приёмке: ожидается.

## Фактическая браузерная проверка

На отдельном синтетическом жгуте во встроенном браузере проверены:

- Все 3 провода начальной группы отображаются в миниатюрах и таблице.
- Миниатюры исходного и изолированного фрагмента; открытие popup и закрытие кликом по рисунку/заголовку.
- Отмена удаления карточки и связи; подтверждение удаления связи сохраняет карточки и refs.
- Подтверждение удаления карточки убирает её инцидентные связи и сохраняет соседнюю карточку.
- Зависимая сборка и финал создаются с пустым составом; ручной выбор 2 refs переживает перезагрузку.
- Создание связи не добавляет refs в целевую карточку; цикл отклоняется понятным сообщением.
- Редактор рисунка открывается, создаёт изолированную копию, сохраняет обе версии; повторная загрузка восстанавливает миниатюры.
- После удаления финальной карточки доступно создание новой.
- Счётчик мутаций исходного API остаётся равен 0.

Диагностические файлы и снимок окна находятся в ignored `artifacts/route-v2-qa/`.

Референс HTML подготовлен до внедрения; после внедрения визуально сопоставлен
с карточками и широким модальным окном настроек.
