# 057 — Удаление ПФ и модальное окно операций

## Контракт

- Реализовать REQ-083.
- Сохранять независимые строки ПФ при создании общей операции.
- Разрешить удаление любого этапа маршрута, автоматического или созданного вручную; не оставлять ссылки на удалённый этап.
- Показывать кнопку удаления под номером каждой строки, включая `semiFinished` и `assembly`.
- Убрать выбор режима из строки, оставив «+ Добавить операцию».
- Показывать операции в модальном окне около 75% ширины и высоты экрана, вертикально группируя карточки по категориям.

## Проверки

- Тесты команд объединения и удаления с зависимостями.
- Тесты рендера: крестик удаления, отсутствие режима, dialog/aria-modal и секции категорий.
- Vitest, typecheck, production build и `git diff --check`.
- Ручная проверка UI на 1440, 1000 и 820 px остаётся за сборщиком.
