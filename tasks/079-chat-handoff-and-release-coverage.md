## Результат и границы

Рабочий чат не закрывает задачу без проверок, commit/push и handoff сборщику.
Сборщик проверяет каждый завершённый handoff против конкретного code HEAD до
сборки ZIP. Включение подтверждается ancestry или проверяемым эквивалентом;
исключения имеют явное основание. Управление состоянием чатов Codex и изменение
логики `build-package.ps1` в эту карточку не входят.

## Критерии приёмки

- Координатор регистрирует чат, карточку и владельца файлов до начала работы.
- Handoff требует SHA, PASS-проверки, ограничения и целевой релиз.
- Release coverage блокирует ZIP при незакрытом или неподтверждённом handoff.
- Каждый ZIP связывается с code HEAD, версией, размером и SHA-256.

## План проверки
