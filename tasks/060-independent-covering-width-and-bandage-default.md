## Результат и границы

1. Изменение `width` каждой оболочки ОП не должно менять визуальную ширину, путь или сохранённое значение другой оболочки ОП. Обновление записи и выбор объекта уже изолированы; исправляется только производная геометрия.
2. Верхняя небандажная оболочка ОП отображается с самостоятельным припуском 2%, в том числе при заданной вручную ширине. Нитиевый бандаж сохраняет уже действующий единственный автоматический коэффициент 1.02 без двойного умножения.
3. Электрическая модель, маршруты, привязки, ID, длины и UI выбора оболочки не входят в карточку.

## Критерии приёмки

- После изменения ширины одной оболочки ОП ширина/контур другой оболочки ОП остаются прежними.
- Верхняя небандажная оболочка ОП получает 102% собственной расчётной или заданной ширины; автоширина нитиевого бандажа по-прежнему равна 102% базовой поверхности, без повторного коэффициента на ОП.
- Вложенные оболочки и существующие переходы ОП продолжают проходить регрессионные тесты.
