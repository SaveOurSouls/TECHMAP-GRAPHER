## Результат и границы

1. Изменение `width` оболочки П не должно проходить через автоматическую упаковку ОП и менять ширину независимой оболочки ОП. Обновление записи и выбор объекта уже изолированы; исправляется только производная геометрия.
2. Автоматический (`width = 0`) нитиевый бандаж получает коэффициент 1.02 к рассчитанной поддерживаемой оболочке. Явная ширина не меняется.
3. Электрическая модель, маршруты, привязки, ID, длины и UI выбора оболочки не входят в карточку.

## Критерии приёмки

- После изменения ширины оболочки П ширина/контур оболочки ОП остаются прежними, а оболочка П меняется.
- Автоширина бандажа равна 102% базовой поверхности; заданная пользователем ширина остаётся точной.
- Вложенные оболочки и существующие переходы ОП продолжают проходить регрессионные тесты.
