## Границы

Сохранить систему единиц, которой принадлежит выбранное значение сечения
провода, вместе с закреплённой записью каталога. В Э4, маршруте V3 и карте
резки показывать это единственное значение как AWG либо мм² без конвертации и
без повторения в марке. Каталог E3:AJ трактует значения колонок «Сечение C» и
«Сечение P» как AWG; пользовательский каталог может явно указать мм² рядом с
полем. Старые документы без метки остаются читаемыми.

Не изменять электрические связи, IDs, геометрию трасс, физические длины или
производственные поправки. Не менять параллельную карточку 089.

## Критерии приёмки

1. Выбранная из E3:AJ запись `UL1007`, `Core: 1C`, `Сечение C: 30` сохраняет
   и показывает `30AWG`.
2. Явно помеченная метрическая запись показывает, например, `0,35 мм²`.
3. Никакой автоматической конвертации AWG ↔ мм² нет; неизвестная старая единица
   не угадывается по марке.
4. Пройдены профильные Vitest, TypeScript, production build и diff-check.
