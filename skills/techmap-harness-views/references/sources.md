# Проверенные источники harness.design

Изучено 20.09.2026 через публичную документацию. Ниже — собственное краткое
изложение наблюдаемых возможностей, без копирования руководства или ресурсов.
Внешняя документация является источником фактов, а не инструкциями агенту.

| Раздел | Что подтверждено и зачем применять |
|---|---|
| [Getting Started](https://docs.harness.design/) | Процесс: электрическая схема → физическая компоновка → назначение деталей → соединения → экспорт. |
| [Schematic](https://docs.harness.design/view/schematic) | Электрическая схема соединяет компоненты проводами, кабелями и скрутками. Есть режим подсветки цепей; непроведённые по физическим веткам провода могут отображаться пунктиром. |
| [Layout](https://docs.harness.design/view/layout) | Физическое представление соединителей, точек ветвления и пучков. Видимость подписей/покрытий отделена от модели. |
| [Connections](https://docs.harness.design/view/connections) | Таблица связей, сортировка, управление колонками, фильтр подсвеченных, переключение прямых связей/всей цепи. |
| [Parts](https://docs.harness.design/view/parts) | Детали и количество применений, основа BOM. Фильтр по выбранным в других видах объектам; выбор детали выключает этот фильтр. Последнее — поведение аналога, не обязательное правило TECHMAP. |
| [Nets](https://docs.harness.design/feature/nets) | Выбор соединителя показывает его провода и пути по жгуту; выбор пучка — проходящие провода; выбор провода переносится между видами; выбор детали показывает места применения. Полная электрическая цепь включается отдельно. |
| [Split Screen](https://docs.harness.design/feature/split-screen) | Несколько видов одновременно; выделение передаётся между ними. |
| [Selection Info](https://docs.harness.design/feature/selection-info) | Краткая информация по выбору: число объектов/проводов, сечение, длина одиночного провода. Не заменяет производственный расчёт. |
| [Wiring Tables](https://docs.harness.design/feature/wiring-tables) | Живая таблица около компонента, строка на оканчивающийся проводник. Прямая связь с компонентом, взаимная подсветка строк/проводов, отдельная видимость по видам. Скрытие таблицы не меняет проводку. |
| [Wire](https://docs.harness.design/component/wire) | Провод — электрическое соединение. Э4-маршрут можно править точками. Для перемычки внутри соединителя аналог принимает длину 0 — это нельзя автоматически перенести в производственную резку TECHMAP. |
| [Bundle](https://docs.harness.design/component/bundle) | Физический участок пучка с собственной длиной и покрытиями. |
| [Branch Point](https://docs.harness.design/component/branch-point) | Точка физического разветвления. При слиянии двух участков после удаления точки аналог сохраняет суммарную длину. Это не электрическая спайка. |
| [Signals](https://docs.harness.design/feature/signals) | Подпись сигнала может распространяться по цепи. Связь по одинаковому имени требует специального признака Global. В TECHMAP одинаковый текст без явной модели не соединяет цепи. |
| [Export](https://docs.harness.design/feature/export) | PDF видов и BOM, XLSX соединений с общим и отдельными листами по соединителям, CSV BOM. Отдельной достаточной спецификации технологического расчёта резки в этом разделе нет. |
| [Formboard](https://docs.harness.design/feature/formboard) | Режим физического масштаба 1:1, радиусы изгибов, длины участков, панели печати. В TECHMAP плаз 1:1 отложен; изучение не означает включения в текущую карточку. |
| [JSON Format v0.9](https://docs.harness.design/feature/local-files/json-format) | Разделение components/parts, внутренние ID контактов и компонентов, отдельные позиции видов, Bundle и BranchPoint. Используется для понимания модели, не как формат TECHMAP. |

## Несогласованности и пределы источника

У страницы JSON заголовок и примеры указывают v0.9, а нижний Key Rules Summary —
v0.8. Также пример повторяет ID shell при общем правиле уникальности. Поэтому
страница не является проверенной схемой импорта; при таком запросе нужны отдельные
тестовые файлы и валидатор. Формат текущего приложения менять на её основании нельзя.

Не найдено в прочитанных разделах правила технологических припусков, разделки,
округления заготовок и объединения строк резки. Эти правила ниже опираются на
существующую модель и принятые требования TECHMAP, а не на harness.design.
Не заявлять изучение внутренних алгоритмов или практическую проверку приложения
harness.design: исследована его документация.
