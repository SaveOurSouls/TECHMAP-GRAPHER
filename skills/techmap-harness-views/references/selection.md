# Связанное выделение и подсветка

## Поведение по запросу владельца

| Источник выбора | Набор проводов | Чертёж и таблицы |
|---|---|---|
| Строка одиночного провода в соединениях/резке | Ровно её wireId | Полный физический путь и концы; та же строка в других видах. |
| Строка материального кабеля | memberWireIds указанного cableId | Все его жилы и путь; расход кабеля остаётся один. |
| Агрегированная строка спецификации/резки | Явные ID всех исходных экземпляров | Все применения; сортировка и смена подписи не меняют результат. |
| Соединитель | Провода, оканчивающиеся на его контактах | Их полные пути по всему жгуту до других концов. |
| Физический участок ветки/пучка | Провода, в чьём маршруте есть данный segmentId | Все эти провода целиком, включая продолжение за выбранным участком. |
| Электрический узел | Присоединённые к узлу проводники | Непосредственные провода; при явном режиме цепи — достижимая сеть. |

«Элемент провода» в запросе интерпретирован как физический участок ветки жгута;
если выбран отдельный проводник, выбирается только он, а не все соседние по ветке.

Режим «Вся цепь» расширяет базовые проводники через подтверждённые проводящие узлы
графа. Без него соединитель не включает провода за спайкой, которые не оканчиваются
на нём. Не проходи из одного контакта корпуса в другой без электрической связи.
Для полупроводников и других inline-компонентов нужен явно определённый графовый
контракт; не выводи проводимость по значку. Защита от циклов — visited по ID.

## Состояние и индексы

Один владелец состояния в рабочей области текущего projectId/harnessId:
источник события, выбранные ID, основной объект, режим direct/net.
Предлагаемая модель выделения — UI-состояние, не новая схема файла жгута.

Чистый resolver получает модель и выбор, возвращает наборы связанных wireIds,
componentIds, segmentIds, rowIds и unresolvedIds. Подготовь индексы:

- `(connectorId, contactId) → wireIds`;
- `wireId → ordered segmentIds` и `segmentId → wireIds`;
- `cableId → memberWireIds`;
- `rowId → source object references` с контекстом жгута;
- электрическая смежность по полным ключам концов, включая явные узлы/экранные порты.

Производные множества не должны повторно отправлять событие выбора в другой вид:
иначе получается цикл таблица → холст → таблица. Пересчитывай индексы при изменении
модели, а не на каждый кадр. Сортировка/виртуализация таблицы не меняет ID строки.

Критично: `selectedIds` управляет редактированием; `highlightedIds` лишь объясняет
связи. Не передавай все подсвеченные провода в существующий Delete/drag обработчик.
При удалении объекта, Undo, смене артикула и жгута очищай отсутствующие ID;
при позднем ответе сервера проверь контекст и ревизию.

## Компактный UI

Подсветка — контур/ореол поверх штатного цвета провода; не заменяй цвет материала.
Различай основной выбор и связанные объекты. Не прячь остальную схему по умолчанию.
Показывай число связанных проводов, «Только связанные», явную команду
«Показать на чертеже» и при необходимости режим «Вся цепь». Справка — InfoHint.
Очистка выбора и Escape возвращают обычный вид. Клавиатурный выбор строки и
состояние aria-selected должны работать наравне с мышью.

Для скрытых слоёв не включай видимость и не снимай блокировку автоматически;
сообщай число скрытых связанных объектов. Не телепортируй камеру на каждый клик.

## Проверочные примеры

Минимальный синтетический жгут: W1 = A:1→B:1, W2 = A:2→C:1,
W3 = B:2→C:2. W1 проходит S0,S1; W2 — S0,S2; W3 — S1,S2.
Провода электрически независимы, хотя делят физические участки.

1. Строка W1: подсвечен W1 и S0,S1, но не W2/W3.
2. Соединитель A: W1,W2 и объединение их путей; W3 не подсвечен.
3. Ветка S1: W1,W3 целиком, включая S0 и S2; W2 не подсвечен.
4. Две одинаковые по названию строки с разными ID: выбор не смешивается.
5. Электрическая спайка J соединяет W4/W5/W6: режим цепи доходит до всех;
   соседний геометрически пересекающийся W7 не включается. Цикл завершается.
6. Кабель K с W8,W9: строка резки K подсвечивает обе жилы; одна материальная
   строка и её метраж остаются неизменными.
7. После сортировки, фильтра, смены вида и переименования выбор сохраняет смысл;
   после смены жгута не возникает подсветка одноимённых ID другого контекста.
8. Несохранённая геометрия и устаревшая карта: статус актуальности виден,
   отсутствующий ID не выбирает объект по имени.
9. Выбор соединителя + Delete удаляет только явно выбранные объекты согласно
   штатным правилам команды, а не все объекты ореола; Undo восстанавливает модель.
10. У провода нет физического маршрута: показывается незавершённость, ложная
    трасса и нулевая длина резки не создаются.
11. Проверка 300 проводов: индексы корректны, смена выбора не запускает запись,
    пересчёт трассировки или API-запрос на каждый провод. Числа быстродействия
    записывай как измерение, не обещай 60 FPS без замеров.

Примеры здесь являются критериями будущей реализации, не выполненными тестами.
