## Расхождения документации и кода

1. README содержит исторические даты и формулировки M4, которые не описывают весь текущий M5-срез.
2. Исторические записи иногда называют этап «завершённым», но в том же или более позднем аудите оставляют ручную приёмку; статус должен читаться по последнему протоколу, а не по одной строке.
3. `docs/m5-07-acceptance.md` содержит историю нескольких ZIP одного номера версии; для распространения следует использовать самый верхний пакет от 30.09.2026.
4. Документация описывает будущие XLSX/PDF и M6/M7, тогда как соответствующие окончательные экспортные процессы не являются частью текущего runtime-контракта.
5. Проверка из кириллического пути ограничена ACL/sandbox поведением среды; это не следует интерпретировать как подтверждённую функциональную несовместимость.
