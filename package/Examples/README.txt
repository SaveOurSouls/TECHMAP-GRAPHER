ПРИМЕР СПРАВОЧНИКА XLSX

Файл reference-catalog.xlsx можно сразу проверить в разделе «Справочники».

Настройки:
- идентификатор источника: example-wire-catalog
- лист: Catalog (можно оставить поле пустым)
- строка заголовков: 1
- первая строка данных: 2
- тип записи: wire
- ключевой столбец: RecordKey
- ручное сопоставление: выключено

Первая строка таблицы содержит заголовки. Каждая следующая строка содержит одну
запись. RecordKey — обязательный уникальный текстовый артикул или код. Остальные
столбцы импортируются как характеристики.

Этот файл содержит только синтетические данные для проверки. Он не является
производственной базой проводов.

ПУБЛИЧНАЯ GOOGLE SHEETS (ЭКСПЕРИМЕНТАЛЬНО)

Для известных таблиц можно переключить источник на Google Sheets, выбрать профиль
и вставить публичную ссылку на книгу. Приложение только читает XLSX-экспорт и не
изменяет Google Sheets. Если сеть или доступ недоступны, используйте локальный XLSX:
уже опубликованный справочник остаётся активным.
