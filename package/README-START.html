TECHMAP-GRAPHER

  1. Полностью распакуйте ZIP в новую пустую папку.
  2. Запустите Techmap.Server.exe.
  3. Приложение откроется в установленном браузере.

Интернет, Node.js и установленный .NET для запуска не требуются.

Для проверки импорта откройте папку Examples. В ней находятся готовый файл reference-catalog.xlsx и точные настройки загрузки.

Архив приложения не содержит проекты. Пользовательские данные хранятся отдельно и не заменяются при обновлении программы.
