# M0-04R: переносимый локальный web-хост

Хост на ASP.NET Core обслуживает обычный web-интерфейс на свободном локальном
порту `127.0.0.1` и сам открывает полученный адрес. Пользовательские данные размещаются в
`%LOCALAPPDATA%\TechmapGrapher`, отдельно от опубликованных файлов программы.

Параметр `--data-root=<path>` существует для изолированной проверки, а
`--port=<1..65535>` фиксирует локальный порт для диагностики.
Параметр `--no-browser` не открывает системный браузер. Эксперимент не содержит
SQLite или производственные данные.

Из корня репозитория:

```powershell
powershell -ExecutionPolicy Bypass -File experiments/m0-04/build-package.ps1
build/m0-04/TECHMAP-M0-04/Techmap.Server.exe --no-browser
```

Сборка `win-x64` самодостаточна: .NET включён в ZIP. WebView2 не используется,
интерфейс открывается в установленном системном браузере. Каталог `wwwroot`
содержит тот же web-клиент, который впоследствии обслуживает LAN-сервер.
