# M0-04: минимальный локальный Windows-хост

Хост на ASP.NET Core обслуживает статический веб-интерфейс только на случайном
порту `127.0.0.1`. Пользовательские данные по умолчанию размещаются в
`%LOCALAPPDATA%\TechmapGrapher`, отдельно от опубликованных файлов программы.

Параметр `--data-root=<path>` существует только для изолированной проверки.
Параметр `--no-browser` не открывает системный браузер. Эксперимент не содержит
WebView2 SDK, SQLite, установщик или производственные данные.

Из корня репозитория:

```powershell
powershell -ExecutionPolicy Bypass -File experiments/m0-04/build-package.ps1
build/m0-04/TECHMAP-M0-04/Techmap.Host.exe --no-browser
```

Полученный пакет зависит от установленного .NET 8 ASP.NET Core Runtime. Это
ограничение экспериментальной упаковки; офлайн-установщик V1 должен поставить
нужную среду выполнения и WebView2 либо включить проверяемые prerequisites.
