TECHMAP Portable Web

  1. Полностью распакуйте ZIP в обычную папку.
  2. Запустите Techmap.Server.exe.
  3. Приложение откроется в установленном браузере.

Интернет, Node.js, WebView2 и установленный .NET для запуска не требуются.

Для обновления остановите сервер и распакуйте новую версию в новую пустую папку. Пользовательские данные хранятся отдельно от программы.

Архив приложения не содержит пользовательские проекты. Для их передачи между компьютерами будет использоваться отдельная команда экспорта/импорта с манифестом; она будет реализована в M1.
