# M0-04R: эксперимент локального хранения

Ограниченный стенд проверяет риск потери пользовательских данных при сохранении,
обновлении схемы и восстановлении. Используются только синтетические данные и
встроенные модули Node.js. Это не формат проекта V1 и не готовая база данных.

## Контракт эксперимента

- `program-data` содержит только неизменяемые сведения установленной программы.
- `user-data/projects` содержит проекты как последовательность неизменяемых ревизий.
- `user-data/backups` содержит опубликованные резервные копии с SHA-256 манифестом.
- `user-data/temp` используется для подготовки резервной копии до её публикации.
- Ревизия проекта становится видимой только после полной записи и синхронизации
  временного файла. Публикация не перезаписывает существующую ревизию.
- Перед миграцией автоматически создаётся проверяемая резервная копия. Миграции
  выполняются последовательно над глубокой копией и публикуются только после
  проверки версии, структуры и идентичности проекта.
- Восстановление требует нового идентификатора проекта, сохраняет происхождение и
  никогда не заменяет исходный проект.
- Резервная копия не восстанавливается при несовпадении SHA-256 содержимого проекта
  или несогласованных критичных полях манифеста.

Эксперимент намеренно не выбирает SQLite или web-фреймворк, не реализует
дневное расписание и ротацию копий, архив проекта, вложения, шифрование, сетевой
доступ, упаковку или полноценную миграцию модели. Эти решения остаются M1.

## Запуск

```powershell
node --test experiments/m0-04/storage/storage.test.cjs
node experiments/m0-04/storage/demo.cjs
```

Демонстрация создаёт отдельный временный каталог ОС и выводит пути и результаты.
Она не читает и не изменяет реальные проекты или производственные справочники.
