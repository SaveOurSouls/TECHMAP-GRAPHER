# М4-97 — выноски и управление чертежом

## Первый срез: начальное положение выноски

Для провода, кабеля, пайпа и покрытия выбранная точка теперь находится на 1/5
геометрической длины ломаной. Суммируются длины всех участков; промежуток между
раздельными пролётами покрытия не считается материалом. Приоритет имеет конец
соединителя, при двух соединителях — левый (при равном X верхний). Для пайпа и
покрытия принадлежность определяется узлом конца сегмента. При отсутствии
соединителя выбирается левый конец геометрии.

Точка проецируется на фактический контур материала, затем создаётся кружок.
Существующие выноски, ручной перенос якоря/кружка и повторное добавление позиций
не меняются. Формат документа не расширен. Состав спецификации и длины резки
остаются прежними.

Проверки: TypeScript, 1061/1061 клиентский тест, production build. Шесть новых
регрессий покрывают длину ломаной, раздельные пролёты, обратное направление,
единственный правый соединитель, частичное покрытие, ручное изменение,
идемпотентность и сериализацию. Новый API/браузерный сценарий и ZIP этого этапа
пока не выполнялись; последний portable ZIP — М4-96-r10.

## Осталось по этапу

- Общий радиус скругления, включая ноль.
- Компактные контекстные свойства объектов.
- Подсказки после удержания дольше секунды и скрытие технических списков.
- Сквозная проверка и пакет без пользовательских данных.

М4-98–100 сохраняют весь исходный объём. М4-96 также не объявляется полностью
закрытым: перенос нескольких трасс и браузерная проверка двухопорного snap ещё
требуют аудита. Цель активна.

## Второй срез: масштаб позиционных обозначений

`0.53.0-m4-97-r1`. Ползунок «Позиции» задаёт масштаб 0,25–4× для текущего
документа. Кружок, номер Arial, толщина выноски и точка на контуре меняются сразу;
координаты центров и ручные привязки сохраняются. Геометрия захвата и смещение
при переносе согласованы с масштабом. Новые выноски получают пропорциональные
начальные отступы; существующие не переукладываются. Старый документ без
`leaderScale` отображается с масштабом 1×. Клиент и сервер проверяют диапазон.

Общий контрол ползунков для позиций и толщины проводов завершает жест одним
шагом истории. Потеря фокуса завершает изменение, Escape и отмена указателя
сбрасывают предпросмотр. Справка обоих контролов находится в InfoHint.

Проверки: TypeScript, 1080/1080 клиентских тестов, 825/825 .NET-тестов Release,
production build и self-contained publish. В браузере на синтетическом документе
проверены 0,25× и 4×, drag кружка на (100,70) без сдвига якоря, ползунок до 3,1×
с одним commit. Реальные обработчики отмены проверены тестами; удержание
указателя вместе с Escape в браузере отдельно не воспроизводилось.

API нового EXE: `artifacts/channels-smoke/test-RRVVQm`, сохранение масштаба 2,5×,
выносок, размеров, Э4 и пайпов, полное равенство документа после перезапуска.
Пользовательские проекты не открывались. Пакет содержит только новую клиентскую
сборку, опубликованный сервер, текстуры и ресурсы поставки; `wwwroot` рабочего
дерева не очищался. Манифест проверяет 30 файлов, БД/журналы/резервные копии
в поставку не включены. ZIP также включает исходные изменения М4-96-r11 и
первого среза М4-97. Это промежуточная поставка; оставшиеся пункты выше открыты.

ZIP: `artifacts/m4-97-r1/TECHMAP-GRAPHER-0.53.0-m4-97-r1-win-x64.zip`,
54 387 579 байт, SHA-256
`7590083CDBB198C346789260ADD24F4802B15493431B667F8E024AE8C8358E55`.
