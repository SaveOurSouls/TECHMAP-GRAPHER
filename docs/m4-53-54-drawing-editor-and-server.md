# М4-53–54 — редактор рисунков и устойчивость сессии

Версия `0.43.1-m4-54`, код `9627c3b`, ветка `codex/restore-20260918-0235`.

## Аудит и реализация М4-53

- С1: совпавшая горизонтальная сторона подавляла вертикальную привязку; боковые ручки resize вообще не использовали snap. Теперь стороны сравниваются по двум осям, активное ребро растягивания учитывает поворот фигуры. Противоположная сторона остаётся на месте. Добавлены регрессии касающихся прямоугольников, транспонированного случая и отключённых привязок.
- Фигуры доступны постоянно над переключаемой лентой. Свойства выбранного объекта находятся справа; ширина поля при выборе объекта не меняется. Справка остаётся в InfoHint.
- Фактический стандартный цвет новых фигур `#27445a` добавлен в обе палитры; чёрный также доступен.
- С2: числовые поля генератора, массива, одиночных и общих свойств используют строковый черновик. Пустое значение допустимо во время ввода; Enter/blur применяют допустимое число, недопустимое возвращается к прежнему значению. Escape отменяет ввод. Уже существующие строковые редакторы параметров и количества контактов сохранены.
- Разделы рисунков уже имели отдельные наборы. Эта возможность проверена через API, тесты и интерфейс. В одном наборе можно сохранить несколько объектов; повторное сохранение выделения для того же артикула/раздела заменяет его набор. Модель отдельных именованных наборов внутри одного раздела не добавлялась.
- Найдены два механизма преждевременного завершения: одинаковое имя cookie разных локальных серверов и трактовка разрыва stream как закрытия страницы. Cookie теперь содержит InstanceId; независимый аутентифицированный heartbeat удерживает сервер при обрыве stream. После настоящего закрытия всех страниц прежняя автоматическая остановка сохраняется.
