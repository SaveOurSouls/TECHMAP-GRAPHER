# M4-29 — рисунки по разделам и импорт изображений

Версия `0.35.0-m4-29`, 20.09.2026. Завершает запрос вместе с M4-27 и M4-28.

## Результат

- Поля библиотечной таблицы «Провод», основной/второй цвет и пользовательские
  колонки редактируются, сохраняются в артикул/серию и переносятся на Э4.
  Проверены номер, назначение, тип, цепь, терминал и видимость колонок.
  Исправлена компоновка панели цвета С1; названия «Красный»/«красный» и
  «Чёрный»/«черный» корректно выбираются в списке.
- Угловые ручки пропорционально растягивают выделенные фигуры вместе с точками
  контактов; электрические ID сохраняются. Контакты включаются рамкой или
  добавочным выделением. Есть предпросмотр перемещения точек и Ctrl+Z.
- Переключатель «Раздел рисунка»: Схема Э4 / Чертёж / Маршрут.
  Наборы сохраняются отдельно для артикула либо всей серии, доступны повторное
  открытие кнопкой артикула/«Редактировать» и очистка раздела с подтверждением
  и Undo. Старые общие рисунки копируются в независимые виды при редактировании.
- «Маршрут» показывает назначенные рисунки закреплённых библиотечных версий
  с параметрами выбранного артикула. Полный редактор технологического маршрута
  этим этапом не добавляется.
- PNG/JPG/BMP/SVG/HEIC принимаются через файл, drop на поле и Ctrl+V.
  Преобразование выполняется локально. SVG растрируется; у многоизображенческого
  HEIC берётся первое изображение. Исходный SVG не редактируется как набор фигур.
  Ограничение файла — 10 МиБ; контроль размеров и декодированной памяти.
  Декодер работает отдельным локальным worker без ослабления CSP.
- После импорта объект выделен. «Сохранить» напротив артикула закрепляет
  выделение; «Сохранить для всей серии» закрепляет его за всеми артикулами.
  «Сохранить и выйти» публикует версию. Новые импортированные объекты отменяются
  Ctrl+Z; загрузка ресурса начинает новую историю, чтобы не вернуть старую
  несовместимую оболочку ресурсов.
