# М4-112 — свойства оболочки

Смена типа существующей оболочки теперь проходит через тот же выбор и закрепление
материала, что и создание: настройки чертежа → глобальная библиотека → встроенная
текстура. Геометрия, привязки и длина сохраняются. Ошибка загрузки не изменяет
документ; успешная замена и запись текстуры отменяются одним Undo.

Окно разделено на «Основное», «Оформление», «Привязки». Убраны повторное поле
«Цвет», лишний переключатель списка текстур, постоянные справочные надписи.
Цвет фона остаётся во вкладке оформления. Порядок слоёв и удаление доступны
в компактной нижней строке. Создание защиты собрано в раскрываемом блоке
«Оболочки и ответвление», без повторяющегося слова «Добавить».

Проверено: клиентские тесты, TypeScript, production build; браузерный осмотр
основной вкладки на изолированной синтетической странице. Серверный контракт
не изменён. М4-113 продолжает уточнение владельца: отдельные слои фона и текстуры
для всех материалов и плотные витки нитевого бандажа.
