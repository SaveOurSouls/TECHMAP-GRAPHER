## М4-88 — модель, маршрутизатор и выходы

- `physical-topology-model.ts`: сохраняемые узлы, участки, маршруты и направления.
- `pipe-routing.ts`: чистый вычислитель из координат и направлений; вход —
  явно ручной либо автоматический маршрут. Алгоритм М4-87 перенесён без изменения.
- `physical-ports.ts`: мировые/локальные координаты выходов и разрешение
  направлений узла/контакта с учётом библиотечного рисунка и поворота.
- `physical-geometry.ts`: адаптер модели в вычислитель. Только здесь трактуется
  сочетание bends, snap и сохранённого routing=fixed. Вычисленные точки не
  записываются в исходную модель.

Формат JSON и серверный контракт не менялись. `routing=fixed` пока сохраняется:
даже прямой фрагмент без bends после разбиения должен оставаться прямым.
Его удаление требует отдельной миграции и серверной проверки старых документов.
Реэкспорты сохраняют существующие импорты без дублирования реализации.

Проверки М4-88: TypeScript, 968/968 клиентских тестов, Vite production build,
git diff --check. Дополнительные регрессии проверяют неизменность авторских
точек, фиксированные прямые фрагменты после сериализации, отсутствие записи
вычисленной геометрии и независимость направления от переноса разъёма.

## М4-89 — типизированная сцена пайпов

`physical-scene.ts` строит геометрию, авторские ручки, размерные точки, состав
проводов и направления выходов. `CanvasViewport` читает типизированные поля
`pipe` / `port` вместо разбора JSON из metadata. Эти поля существуют только
в сцене: формат сохранённого проекта не меняется.

Регрессии проверяют разделение вычисленных вершин и авторских ручек,
попадание мышью, состав проводов, направления выходов и неизменность документа.
API smoke приведён к действующему поведению М4-87: редактируется сохранённый
перегиб, автоматический угол не становится ручкой.

Проверки: TypeScript, 970/970 клиентских и 795/795 серверных тестов, production build клиента,
Release publish сервера, API smoke с повторным запуском (ветвления, выходы,
ID проводов, спецификация, редактирование пайпа и общие размеры), проверка
манифеста пакета и `git diff --check`. Браузерная проверка в этом этапе не проводилась.
Vite сообщает о крупном основном чанке; оптимизация загрузки вне этого этапа.
Серверный прогон занял 5 минут 11 секунд; запущенный до появления результата
повтор остановлен как избыточный. Основной прогон завершился без ошибок и пропусков.

Пакет: `artifacts/m4-89/TECHMAP-GRAPHER-0.51.1-m4-89-win-x64.zip`.
