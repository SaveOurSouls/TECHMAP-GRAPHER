## М4-88 — модель, маршрутизатор и выходы

- `physical-topology-model.ts`: сохраняемые узлы, участки, маршруты и направления.
- `pipe-routing.ts`: чистый вычислитель из координат и направлений; вход —
  явно ручной либо автоматический маршрут. Алгоритм М4-87 перенесён без изменения.
- `physical-ports.ts`: мировые/локальные координаты выходов и разрешение
  направлений узла/контакта с учётом библиотечного рисунка и поворота.
- `physical-geometry.ts`: адаптер модели в вычислитель. Только здесь трактуется
  сочетание bends, snap и сохранённого routing=fixed. Вычисленные точки не
  записываются в исходную модель.

Формат JSON и серверный контракт не менялись. `routing=fixed` пока сохраняется:
даже прямой фрагмент без bends после разбиения должен оставаться прямым.
Его удаление требует отдельной миграции и серверной проверки старых документов.
Реэкспорты сохраняют существующие импорты без дублирования реализации.

Проверки М4-88: TypeScript, 968/968 клиентских тестов, Vite production build,
git diff --check. Дополнительные регрессии проверяют неизменность авторских
точек, фиксированные прямые фрагменты после сериализации, отсутствие записи
вычисленной геометрии и независимость направления от переноса разъёма.
