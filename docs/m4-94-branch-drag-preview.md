# М4-94 — drag-preview и присоединение ветви

## Что изменено

- физические точки принудительно помещаются в конец paint/hit-test порядка,
  поэтому перестановка пользовательских слоёв не может спрятать контакт;
- во время протягивания показывается пунктирная линия от исходной точки к курсору
  и к ближайшей точке/пайпу;
- отпускание на точке создаёт обычный участок между двумя узлами;
- отпускание на произвольном внутреннем месте пайпа создаёт устойчивый узел,
  разрезает целевой участок и добавляет ветвь от исходной точки;
- после присоединения вызывается общий маршрутизатор: автоматические маршруты
  выбирают кратчайший путь, ручные назначения сохраняются;
- отменённый или отпущенный мимо цели жест не меняет документ;
- добавлены регрессии для принудительного верхнего порядка и тройного узла
  после присоединения к середине пайпа.

Проверки: TypeScript, 985 клиентских тестов, 806 серверных тестов, сборка клиента
и переносимого сервера. ZIP `artifacts/m4-94/TECHMAP-GRAPHER-0.52.3-m4-94-win-x64.zip`
проверен пакетным валидатором, пользовательские данные исключены.
API smoke расширен сценариями `connectPhysicalNodeToSegment`, удаления и повторного
перезапуска (`nodeToPipeChecked`, `pipeRemovalRestartChecked`). Все прошли.

Браузер: реальный `HarnessEditorWorkspace` и `CanvasViewport` на синтетическом
стенде `.build/m4-94.html`: drag узел–узел даёт 1 пайп / 1 маршрут; drag к середине
даёт 4 узла / 3 пайпа / 3 маршрута; отпускание в пустом месте не меняет счётчики;
удаление ветви даёт 2 пайпа / 1 маршрут; Escape отменяет выбранное начало.
Стенд использует локальные callbacks модели без пользовательского проекта.
Тестовые API-проекты сохранены только под `artifacts/channels-smoke`.

Основной код отправлен `7e1bb85`; последующая проверка добавляет защиту отмены,
миграции предельных порядков слоёв и сохранения независимых узлов при удалении.

## Ограничение

Внутреннее место пайпа выбирается по его текущей экранной геометрии; авторский
перегиб создаётся только в момент подтверждённого отпускания. Данные не меняются
на каждом движении курсора.

Автоматическое обновление кратчайших маршрутов после каждого изменения геометрии,
новые Shift-режимы перемещения, радиусы и ширина относятся к оставшимся этапам.
Общий объём приложенного ТЗ ещё не завершён.
