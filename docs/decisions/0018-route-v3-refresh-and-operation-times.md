# ADR-0018: обновление источника и нормы Route v3

- **Статус:** решение для реализации, ручная приёмка открыта.
- **Источник:** прямое поручение владельца 13.10.2026; REQ-129 / карточка 093.
- **Связанные решения:** ADR-0008, ADR-0016, ADR-0017.

Route v3 читает текущий сохранённый жгут при открытии и после возврата в раздел.
Исходный производственный материал сравнивается по устойчивым ID и смысловым
атрибутам — точкам подключения проводов, покрытиям и их размещению, материалам,
длинам и количеству жгутов. Изменение экранной геометрии при тех же опорных точках
не удаляет ручной граф. Качественное изменение даёт список расхождений; оператор
применяет обновление явно. Рисунки и операции остаются на карточках по ID, а
затронутые строки требуют проверки. Исчезнувший объект не заменяется другим по
совпадению названия. Сохранённый проект с устаревшим source не выдаётся за
актуальный маршрут.

Операция Route v3 выбирается из закреплённого снимка БД.ОП и сохраняет устойчивую
ссылку на запись. Пустая норма остаётся неизвестной (`null`); её нельзя подменять
нулевым временем. Для статичной операции расчётное время одного выполнения в
секундах — время человека плюс дополнительное время. Для погонной —
`feedTimeSecondsPerMeter × lengthMm / 1000 + toolCycleTimeSeconds ×
toolOperationCount + additionalTimeSeconds`. Отдельно показываются машинное и
человеческое время из нормативных полей; итог партии — время операции × количество
партии `N`. Это правило специально для Route v3 по текущему поручению, оно не
переписывает расчёт M1-08 и старый UML-прототип. Величины сопровождаются единицами.

Для подготовленных проводов/оболочек количество партии рассчитывается по объёму
жгутов в проекте и кратности одинаковых экземпляров в одном жгуте. Физические
экземпляры не склеиваются по одному лишь артикулу; кратность отображается при
одинаковом материале и назначении. Для сборки собственное количество на
полуфабрикат и общее количество партии остаются разными полями.
Если карточка резки содержит несколько заготовок, итог времени партии умножается
на количество заготовок в карточке и число жгутов. Время отдельной группы
материалов показывается только когда операция однозначно относится к этой группе;
в остальных случаях итог остаётся общим для карточки.

Реализация ограничена клиентским Route v3/localStorage. Серверный маршрут,
производственные длины, электрические связи и справочник БД.ОП не изменяются.
