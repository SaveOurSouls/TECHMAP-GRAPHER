# ADR-0016: Маршрут v3 сначала сохраняет графические слепки

- **Статус:** принято для карточки 084, 06.10.2026
- **Источник:** прямое поручение владельца, REQ-120
- **Уточняет:** ADR-0012 и ADR-0013; Маршрут v2 остаётся отдельным вариантом

## Решение

Маршрут v3 открывает один локальный редактор `HarnessDesignEditor` на независимой
копии чертежа. В исходной копии все объекты скрыты, но рисуются как фон с
прозрачностью 20%. Команды контекстного меню «Изолировать» и «Сохранить» создают
слепок в отдельной версии локального документа. Сохранение выбранных объектов
снимает их с набора скрытых ID; изоляция создаёт самостоятельный документ с
прямыми концами проводов и сохраняет его материал и геометрию.

Слепки, их устойчивые source refs и результат генерации хранятся в отдельном
ключе `techmap.route-v3.<projectId>.<harnessId>` браузерного хранилища. Исходный
чертёж и данные маршрута v2 не изменяются. Генератор строит DAG в порядке сохранения:
последнее сохранённое состояние каждого компонента становится зависимостью следующего
слепка с этим компонентом. Повторное использование части полуфабриката отклоняется;
равный состав создаёт последовательные стадии. Финал появляется при полном покрытии
материальных refs; производные размеры и метки не блокируют его.

## Последствия

Пользователь может редактировать слепок повторно из галереи, а после генерации
вернуться к ним без потери картинок. Поскольку хранение остаётся локальным
прототипом, синхронизация на сервер и перенос между браузерами не входят в
карточку 084. Наличие только изображения без устойчивого ID не создаёт новый
электрический объект и не меняет производственные длины.
