# ADR-0001: переносимый локальный web-host

- Статус: принято
- Источник: найдено в коде (`Program.cs`, `ServerOptions.cs`, `BrowserLauncher.cs`)
- Связанные требования: REQ-001, REQ-021, REQ-022

## Контекст

Продукт должен работать на рабочем месте без обязательного сетевого сервера и без смешивания программы с пользовательскими данными.

## Решение

Поставлять self-contained win-x64 ASP.NET Core single-file сервер со статическим React-клиентом. Сервер слушает loopback, выбирает порт, поддерживает optional path base и запускает/переиспользует браузерную сессию.

## Последствия

Приложение удобно переносить ZIP-архивом; сетевой доступ ограничен локальным процессом. Для совместной работы нужен отдельный сетевой режим, который текущий контракт не обещает.
