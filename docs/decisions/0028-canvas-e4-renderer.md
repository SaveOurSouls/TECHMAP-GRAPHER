# ADR-0028: рисование Э4 вне CanvasViewport

- Статус: реализовано для проверки владельцем.
- Источник: исходный запрос REQ-158, карточка [123](../../tasks/123-canvas-e4-renderer.md). Выбор блока — техническое решение исполнителя.
- Связанные решения: ADR-0003, ADR-0026, ADR-0027.

## Контекст

После выделения геометрии CanvasViewport содержит 3151 строку. Рисование мостиков, диффпар, узлов и экранов использует только переданный CanvasRenderingContext2D, сцену и функции расчёта. Общий штрих белого провода используется также некоторыми проходами Чертежа: перенос должен сохранить эти вызовы и контрастную обводку.

## Решение

`editor/canvas-e4-renderer.ts` содержит прежние `strokeE4Wire`, `drawE4BridgeCrossings`, `drawE4DifferentialPairs`, `drawE4Junctions`, `drawE4Screens` и внутренние функции/константу белого цвета. Renderer использует геометрию `canvas-e4-scene.ts`, не импортирует CanvasViewport/React и не обращается к глобальному DOM. Контекст предоставляется вызывающим кодом.

CanvasViewport сохраняет все вызовы и их порядок в redrawCanvas, жесты и прочее рисование. Старый публичный `drawE4DifferentialPairs` переэкспортирован из прежнего пути. Общий stroke используется теми же проходами Э4 и Чертежа, без копии реализации. Новых критериев распознавания белого, толщин, цветов, координат или save/restore не вводится.

## Последствия и проверка

CanvasViewport: **3151 → 2923 строки**, на 228 строк короче; renderer — 232 строки. Тело перенесённого блока и весь оставшийся код viewport совпадают с базой после нормализации import/export/EOL. Порядок контактов и индексов поверх overlays остаётся прежним.

Девять новых эталонов Canvas-команд формируются на `8962aef` до переноса. После переноса обновление snapshots запрещено для подтверждения этого refactor-среза. Профиль включает полный redraw, варианты диффпар, белые/цветные штрихи, скрытые слои и прежние geometry/connector-эталоны. Полный клиентский Vitest и TypeScript/Vite обязательны. Ручная пиксельная приёмка, сервер и упаковка не входят в автоматические доказательства этой карточки.
