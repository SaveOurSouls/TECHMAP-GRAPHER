# ADR-0014: Синтетические свободные концы ограничены изолированной копией

- Статус: принято
- Источник: исходный запрос и найдено в коде
- Связанные требования: REQ-097

## Контекст

Изолированный рисунок маршрута намеренно оставляет свободные концы проводов без визуальных соединителей. Клиент хранит такие концы как `isolated:<wireId>:from` или `isolated:<wireId>:to` с контактом `free`. Общая электрическая проверка ранее требовала, чтобы каждый endpoint ссылался на запись `connectors`, поэтому сохранение маршрута периодически показывало ошибку `The endpoint connector does not exist.`.

## Решение

Проверка принимает синтетические endpoint IDs только при валидации `isolatedDrawingCopy`. ID должен совпадать с текущим wire и стороной endpoint, а `contactId` должен быть ровно `free`. Основной дизайн и обычная `drawingCopy` используют строгую проверку существования соединителя и контакта.

## Последствия

Свободные концы сохраняют прежнюю визуальную модель без лишних прямоугольников. Серверный контракт явно ограничивает исключение контекстом изолированной копии; тест проверяет как допустимый, так и изменённый endpoint.
