# ADR-0023: исключение страниц Маршрут и Маршрут v2

- Статус: принято к реализации 16.10.2026 по прямому поручению владельца.
- Требование: REQ-153, карточка 118.
- Уточняет ADR-0007–0010, 0012–0013, 0016: отдельные старые страницы больше не поддерживаются; текущий маршрут — V3.

## Решение

Удалить входы и компоненты старых страниц. Общие рисунки, тип рисунка слепка и используемые V3 стили вынести из V2 в общие производственные модули. Не сохранять V2 как скрытую страницу или зависимость V3. UML получает граф V3 вместо V2. Название существующей страницы «Маршрут v3» сохраняется.

Серверный `manufacturingRoute` и поля независимых графических копий остаются совместимым контрактом чтения существующих проектов и общих производственных функций. Удаление страницы не означает стирание пользовательских данных. Старые localStorage-ключи не читаются как источник текущего UML и не удаляются. Исторические ADR/карточки сохраняются как история; настоящее решение имеет приоритет для навигации и владения общими модулями.

## Последствия и проверка

Навигация жгута содержит Э4, Чертёж, V3 и UML. Проверяются входы из проекта/редактора, импорт UML, чтение V3, рисунки/редактор слепка, отсутствие импортов V2, клиентский набор, TypeScript/Vite и desktop/mobile. Активная карточка 117 не входит в коммит 118; зафиксированный срез проверяется отдельно от общей рабочей копии.
