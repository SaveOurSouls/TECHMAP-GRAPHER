# Архитектурные решения

ADR с номерами `0001`–`0007` восстановлены из кода и истории. [ADR-0008](0008-route-source-synchronization.md) фиксирует действующую в коде политику обновления источника маршрута по последующему поручению владельца. Статус действующего решения описывает реализацию, а не завершённую ручную приёмку.

Для нового решения создать следующий `NNNN-краткое-имя.md`:

```markdown
# ADR-NNNN: название

- Статус: предложено | принято | заменено ADR-NNNN
- Источник: исходный запрос | найдено в коде | предположение
- Связанные требования: REQ-###

## Контекст

Проблема, ограничения и альтернативы.

## Решение

Что выбрано и кем подтверждено.

## Последствия

Что упрощается, что усложняется, как проверяется.
```

Если решение меняется, старый ADR помечается как заменённый со ссылкой на новый. Исторический текст не переписывается так, будто прежнего выбора не было.
