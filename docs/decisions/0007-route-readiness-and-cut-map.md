# ADR-0007: готовность маршрута как gate карты резки

- Статус: принято для M5
- Источник: найдено в коде (`route-cut-readiness.ts`, `HarnessCutListEndpoints.cs`) и `docs/m5-route-plan.md`

## Решение

Подготовка маршрута — единый prerequisite для карты резки. Сервер повторяет проверку; неполные, циклические или устаревшие состояния не принимаются.

## Последствия

UI не может открыть карту обходом readiness, а изменение исходной конструкции отзывает готовность до явной актуализации.
