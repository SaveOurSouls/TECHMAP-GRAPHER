# ADR-0024: схемы заготовки провода в Route v3

- Статус: реализовано для проверки владельцем.
- Источник: REQ-152, карточка 117, поручение 15.10.2026 и уточнение C2 от 16.10.2026.
- Связанные решения: ADR-0018 и ADR-0019.

Схемы публикуются через существующее хранилище снимков справочников под ключом
`technology-wire-preparation-schemes`. Операция хранит снимок выбранной записи
БД.ОП. Пустые шаги допускаются в справочнике как черновик, но запрещены при
построении маршрута. Нормы и конкретные номера операций не выводятся из названия.
24 исходных названия и описания сохранены, включая противоречия исходного текста.
Многострочное описание хранится массивом `descriptionLines`, поскольку общий
канонизатор справочников запрещает управляющие символы в строковых значениях.

Полуфабрикат хранит необязательный `defaultSchemeId`. При первом введении схем
сервер дополняет справочник недостающими неориентированными парами девяти видов
концов, не заменяя существующие записи. Пользовательские удаления и назначения
при следующих запусках сохраняются. Для прежних строк без поля default клиент
предлагает начальное соответствие; явное null означает отсутствие схемы.

Route v3 хранит назначения по wire ID и снимки применённых схем. У каждой схемы
собственная цепочка и колонка: первый этап использует только исходные провода
своей группы, последующие получают результат предыдущего этапа той же схемы.
Между разными схемами генератор связей не создаёт. Общая сборка может получать
результаты нескольких цепочек. Колонка резервируется целиком с учётом размеров
карточек, чтобы короткая соседняя схема не выглядела продолжением длинной.

У каждого этапа отдельные продукты по wire ID и одна операция, назначенная на
эти продукты. Повторное применение заменяет управляемые этапы и переподключает
существующие выходы к конечному этапу соответствующего провода. Выключенные
входы не включаются автоматически. Совпавшие этапы сохраняют рисунок и размер;
при обновлении источника сохраняются также ручные операции. Замена операций
по выбранным схемам требует подтверждения внутри формы. Индивидуальные операции
оконцовки исходного провода заменяются схемой; общий обжим и установка гильзы
остаются отдельными сборочными этапами.

Электрические связи и производственные длины исходного документа не меняются.
Хранение V3 остаётся прежним локальным хранением маршрута; опубликованные
справочники хранятся сервером. Импорт схем — табличная вставка или TSV/TXT с
номерами операций, однозначными среди загруженных БД.ОП.
