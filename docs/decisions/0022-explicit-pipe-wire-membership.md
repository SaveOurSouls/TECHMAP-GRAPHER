# ADR-0022: явное изменение состава проводов П

- Статус: реализовано, карточка108 / REQ-143; приёмка владельцем открыта.
- Источник: прямой запрос владельца 15.10.2026, С1/С2.

Состав физического П вычисляется по `physicalTopology.routes`: один wireId имеет непрерывную последовательность segmentId. Поэтому добавление в выбранный П закрепляет полный маршрут между электрическими концами провода через этот П. Перенос в другой П атомарно исключает исходный участок и назначает маршрут через целевой; если пути нет, документ остаётся прежним.

Исключение хранится в необязательном `PhysicalSegment.excludedWireIds`. Это проектное решение для сохранения явного выбора после автоматического распределения. Список содержит существующие уникальные wireId; клиент и сервер запрещают маршрут исключённого провода через этот участок. Явное повторное добавление снимает ограничение выбранного П. При разделении П ограничение наследуют оба фрагмента, при удалении провода ссылка очищается.

Для поиска пути через выбранный П совместно находятся два непересекающихся плеча; это предотвращает ложный отказ после неудачного жадного выбора первого плеча и маршрут с возвратом по одному и тому же П. Сохраняются допуски проводов на выходах и явно разрешённый транзит через чужие соединители.

Изменение состава не меняет связи Э4, длину резки и геометрию пайпов. Другие закреплённые маршруты сохраняются. Новое подключение Э4 теперь вызывает обновление автоматических физических маршрутов. Изменение ограничений учитывается в серверном fingerprint источника производства. Формат документа остаётся совместим с прежними документами без этого необязательного поля.
