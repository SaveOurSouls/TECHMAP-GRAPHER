# ADR-0012: штатный редактор на независимой копии сборки

- **Статус:** принято для реализации 02.10.2026.
- **Источник:** REQ-062, карточка 038; способ хранения — техническое решение.
- **Уточняет:** ADR-0010 (сценовые overlays сохраняются для совместимости).

## Решение

Использовать `HarnessDesignEditor` с явным локальным режимом. Все геометрические
команды, привязки, размерные инструменты и оформление остаются общими с Чертежом.
Локальный режим не записывает исходный design, серверный или браузерный recovery
журнал и размещения исходного жгута. Справочники и проектные assets читаются в
контексте исходного проекта. Save возвращает копию владельцу маршрутной строки,
Cancel отбрасывает локальную историю.

`presentation.drawingCopy` содержит полный `document` без `manufacturingRoute`
и `hiddenObjectIds`. Скрытие не удаляет объект и не разрушает физические связи.
Копия получает собственную историю, размеры, цвета и параметры текстур.
Ссылки на проектные вложения и immutable библиотечные версии сохраняются.
Превью использует общую сцену из копии с её видимостью.

## Последствия

Размер маршрутного документа увеличивается. Клиент и сервер ограничивают и
проверяют вложенный документ до чтения; рекурсивные маршруты запрещены.
Перебазирование исходных производственных данных не перезаписывает авторскую
копию рисунка. Исходные длины продолжают синхронизироваться в маршрутных
данных отдельно от геометрии рисунка. Старые `drawingObjects` мигрируют при
открытии в доступные поля копии без записи исходника.

Приёмка требует проверки обоих режимов редактора, отсутствия исходных записей,
Save/Cancel, сохранения текстур/размеров и повторного открытия.
