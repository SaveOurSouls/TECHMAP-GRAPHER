# ADR-0002: проект как контейнер независимых жгутов

- Статус: принято
- Источник: найдено в коде и история `64c8a92`

## Решение

Проект группирует жгуты, а design/E4/route documents принадлежат конкретному harness ID. Количество и производственные строки не являются свойством всего проекта.

## Последствия

Копирование и маршрутизация выполняются по проекту и жгуту; UI не должен использовать глобальный singleton document.
