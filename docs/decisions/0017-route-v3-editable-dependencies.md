# ADR-0017: редактируемые зависимости и UML-операции Маршрута v3

- Статус: реализовано для проверки, ручная приёмка открыта.
- Источник: поручение владельца 07.10.2026, REQ-122, карточка 086.
- Дополняет ADR-0016, не изменяет графический редактор слепков.

Граф v3 после генерации становится редактируемым. Карточка хранит собственное
сырьё `rawRefs`, выбранные входящие карточки `inputNodeIds`, размеры, количество,
рисунок и операции общей модели UML. `refs` — вычисленный состав результата.
Удаление зависимости убирает у потомков только унаследованный по ней состав;
явно добавленное сырьё сохраняется. Циклические связи запрещены.

При чтении старого графа исходные накопленные refs разделяются на собственные
и входящие. Только стрелки от групп нарезанных заготовок ограничиваются сохранённым
набором материала: иначе слепок одного провода получил бы всю группу. Зависимости
между сборками передают полный результат, включая последующие изменения состава.

Нижний плюс вставляет одну карточку между родителем и всеми непосредственными
потомками; другие входы потомков сохраняются. Потомки сдвигаются вниз для места
под новую карточку. Это выбранная реализация многовыходной вставки.

Локальное хранение версии 1 расширено необязательными полями. `graphEdited`
предотвращает потерю ручного графа при сохранении слепков. Явная повторная
генерация с подтверждением заменяет ручные карточки, связи и операции.
Серверный контракт, электрическая связность и производственные длины не меняются.
