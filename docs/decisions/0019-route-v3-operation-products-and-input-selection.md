# ADR-0019: продукция операций и выбор входов Route v3

- Статус: решение для реализации, ручная приёмка открыта.
- Источник: прямое поручение владельца от 13.10.2026, C1–C3; REQ-133 / карточка 097.
- Связанные решения: ADR-0018 и ADR-0008.

Операция хранит устойчивые ключи выходных полуфабрикатов, к которым она
применяется. Если карточка имеет один выход, список заполняется автоматически.
Если выходов несколько, оператор назначает их явно; операция с пустым назначением
показывает «Не назначена», время — «Не задано».

Для резки проводов операция хранит положительную целую `parallelCapacity`, по
умолчанию 1. Один производственный цикл обрабатывает до этой ёмкости проводов,
поэтому количество циклов внутри загруженного набора равно `ceil(assignedQuantity × N / parallelCapacity)`.
Время производства использует длину назначенных проводов и наиболее длинный
провод в каждом цикле. Разные наборы производственных параметров образуют разные
режимы; цвет и сечение учитываются, контакты и UUID сами по себе режим не меняют.
Один набор содержит до P вариантов цвета/сечения; одинаковые варианты объединяются. Разные длины и оконцовки формируют отдельные режимы. Это расчётное допущение о возможностях параллельного станка; одинаковые параметры не вызывают повторной подготовки на каждый провод. Начальная переналадка учитывается один раз, последующие переналадки — при смене
режима. Время подготовки берётся из `setupTimeSeconds` записи БД.ОП. Если норма
не задана, итог остаётся неизвестным, а не нулевым.

Стрелка между карточками хранит выбранные входные refs, когда оператор сузил
состав. Без выбора для старых данных сохраняется прежняя семантика полного входа;
для нового multi-output сценария интерфейс показывает отдельные строки каждого
входного полуфабриката. Пересчёт потомков использует эти refs транзитивно, поэтому
удаление стрелки убирает только переданные входы и не затрагивает собственный
сырьевой состав дочерней карточки.

Формат остаётся локальным Route v3/localStorage; серверные маршруты, электрические
связи, производственные длины и Маршрут v2 не изменяются.
