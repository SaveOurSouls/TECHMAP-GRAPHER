# ADR-0006: закреплённые snapshots справочников и шаблонов

- Статус: принято
- Источник: найдено в коде (`ReferenceCatalog*`, `ComponentTemplate*`, pinned snapshot stores)

## Решение

Рабочий жгут ссылается на immutable snapshot с source/key/hash/version. Обновление глобального каталога не переписывает уже закреплённую конструкцию молча.

## Последствия

Проект воспроизводим после импорта и переноса; для осознанного обновления нужен явный rebind/rebase flow.
