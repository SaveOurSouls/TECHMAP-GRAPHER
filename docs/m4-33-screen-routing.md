# M4-33 — экран на смещённых проводах

Версия `0.39.0-m4-33`, 20.09.2026.

## Аудит С1–С3 и изменения

С1/С2: старый расчёт сопоставлял сегменты по номеру изгиба и отдавал
приоритет даже короткому совпавшему участку. Новый общий расчёт
`e4-screen-spans.ts` проходит по всем горизонтальным сечениям маршрутов:
положение определяется по X, высота охватывает провода в этом сечении.
Диапазон 0–100% включает начальные и конечные участки с отступом от таблиц.
Экран остаётся вертикальным на смещениях горизонтального пучка.
Для полностью вертикального пучка без общих горизонтальных участков
сохранён поперечный экран. Отрисовка и электрические порты используют
одну функцию; перетаскивание выбирает положение по продольной координате.

С3: ранее экранируемые провода исключали друг друга из занятых трасс,
а длина вывода экрана влияла на выбор порядка перестроения. Теперь
основные провода учитывают друг друга независимо от наличия экрана.
Выводы экрана строятся после них и не влияют на их препятствия и оценку
маршрута. Перемещение экрана перестраивает только подключённые выводы.

Прямое подключение к контакту компонента использует обычную ортогональную
трассировку с изгибами. Для порта экрана предусмотрен короткий выход 8,
для контакта компонента сохранён выход 24. Это устраняет самопересечение
обязательных выходов у края таблицы. Подключение к точке другого провода
по прежнему требованию остаётся прямым. Пояснения помещены в InfoHint.
