# M4-27 — редактирование библиотечной таблицы

Снята блокировка полей «Провод», основного/второго цвета и дополнительных колонок.
Значения сохраняются в строках артикула или серии и переносятся при размещении Э4.
Пустой цвет соответствует автоматическому режиму. Старые шаблоны совместимы:
новые поля необязательны. Сервер проверяет типы и длины значений.

С1: у панели цвета заданы собственные размеры и отступы select, высота label
и палитры, чтобы общие стили форм не обрезали текст.

Проверки: клиент 817/817, TypeScript, серверные тесты компонентов; регрессия
проверяет значения от таблицы через v5 до размещённого компонента.
Браузер и итоговая сборка входят в общий приёмочный прогон M4-29.

Далее M4-28 — групповое растяжение и контакты; M4-29 — рисунки по разделам,
повторное открытие/удаление наборов и импорт изображений.
