# М4-79: компактная библиотека компонентов по С1–С3

## Оценка и изменения

- **С1.** Типы контактов и совместимые терминалы занимали отдельные полосы на
  всю ширину. Теперь на панели шире 780 px они расположены рядом, с отступами
  8 px. Поиск терминала и ручное добавление находятся в одной строке; лишняя
  вложенная рамка удалена. Уже добавленный тип обозначается нейтральным статусом.
  Флажок стандартного терминала был затронут общим размером текстовых полей:
  правило для него ошибочно указывало на второй столбец, хотя флажок находится
  в третьем. Ячейка получила собственный класс и флажок размером 16×16 px.
- **С2.** Таблицы артикулов и терминалов получили единый стиль: тонкие вертикальные
  и горизонтальные разделители, светлая закреплённая шапка, строки высотой 34 px,
  слабое чередование фона и голубое выделение выбранного артикула. Поля внутри
  ячеек показывают рамку при наведении/фокусе; числовые значения центрированы.
- **С3.** Кнопка выбора, артикул, количества и удаление находятся на одной строке.
  Кнопка больше не переносится над полем артикула. Удаление стало компактным,
  список имеет собственную прокрутку с закреплёнными заголовками.
- **Связанные блоки.** Ввод артикула и добавление стоят рядом; результат проверки
  расположен под ними. Убраны лишние вложенные рамки и конфликтующие старые
  стили. Артикулы остаются слева, предпросмотр Э4 и рисунков — справа. На узкой
  панели сохраняется этот порядок, при необходимости появляется горизонтальная
  прокрутка. Модель данных, связи терминалов и формат хранения не изменены.

## Проверки

Браузерная проверка выполнена на временном стенде с настоящими
`TemplateSeriesPanelV3` и `E4ArticlePreview`, 24 синтетическими артикулами PHR
и тремя терминалами. Пользовательские базы не использовались.

- Панели 1160, 760 и 560 px: размеры и порядок блоков, отсутствие переноса кнопки
  над артикулом, доступность широких таблиц через прокрутку.
- Выбор PHR-4 обновляет предпросмотр справа; изменение количества с 4 на 6
  через Enter создаёт шесть строк в предпросмотре.
- Смена стандартного терминала отражается в контактах предпросмотра.
- Добавление собственного типа «Коаксиальные» и трёх артикулов по шаблону X-XX.
- Переход клавиатурой к последнему артикулу прокручивает таблицу: при scrollTop
  528 px шапка остаётся на верхнем крае контейнера.
- Измеренные размеры: строки обеих таблиц — 34 px; флажок — 16×16 px.

- `pnpm --filter @techmap/client test`: 96 файлов, 913/913 тестов.
- `tsc --noEmit` и Vite production build: успешно.
- `dotnet test Techmap-Grapher.slnx --configuration Release --no-restore`:

  с изолированным окружением .NET внутри каталога артефактов.
- `build-package.ps1 -ArtifactSlice m4-79`: успешно; Release self-contained
  publish, проверка манифеста `verify-package.ps1` и ZIP 51,85 МиБ.
- Запуск готового пакета на отдельной синтетической БД: HTTP 200,
  `runtime-config.json` сообщает версию `0.47.4-m4-79`. Первый запуск ограничен
  ACL песочницы; разрешённый повтор прошёл. Тестовый сервер остановлен.
- `git diff --check`: успешно.

## Поставка и ограничения

Версия `0.47.4-m4-79`. Пакет:
`artifacts/m4-79/TECHMAP-GRAPHER-0.47.4-m4-79-win-x64.zip`.
Снимок: `artifacts/m4-79-library-ui.png`.
Временный стенд, снимок и сборочные файлы исключены из Git.
SHA-256 ZIP: `39E2D49D30E826429A28B6D32912DB44B65CCF9FB2144FAFE9E503453D498012`.

По замечанию о скачивании имя ZIP теперь включает версию из `package/VERSION.json`.
В ссылке для выдачи указывается полное имя файла с расширением `.zip`.
Для уже собранной версии создана побайтово идентичная копия с новым именем;
исходное имя оставлено для ранее выданных ссылок. Проверены синтаксис PowerShell,
имя архива, контрольная сумма и `VERSION.json` внутри ZIP. Фактическое имя,
выбранное диалогом скачивания приложения, этой локальной проверкой не проверяется.

Для больших наборов типов контактов и узких панелей таблица прокручивается
горизонтально. Предупреждение Vite о JS chunks более 500 кБ остаётся.
Следующая карточка не начата; следующий свободный индекс — М4-80.
