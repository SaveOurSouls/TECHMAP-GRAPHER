# М4-91 — явный источник геометрии пайпа

Новый `PhysicalSegment.path` содержит авторские точки и вид пути:

- `routed`: при наличии точек они соединяются напрямую; удаление последней
  возвращает автоматическую трассировку с направлениями выходов.
- `polyline`: заданная ломаная, включая прямой фрагмент без внутренних точек.
  Разбиение пайпа создаёт такие фрагменты и сохраняет исходную геометрию.

Вычисленные углы не попадают в авторские точки. В рабочем клиентском коде
нет `routing=fixed` и верхнеуровневого `bends`; они читаются только кодеком
на границе загрузки. Кодек не изменяет исходный объект и отклоняет смешение
старого и нового форматов. Новый документ записывается только при сохранении.

Сервер принимает оба формата, проверяет точки и вид пути, направления выходов
и принадлежность `contactDirections` контактам разъёма. Проверка размеров
и покрытий использует один метод чтения авторских точек для обоих форматов.
Индексы размерных привязок, ID проводов и маршрутов не меняются.

Версия пакета `0.52.0-m4-91`. Для открытия нового формата необходим этот
клиент/сервер или более новый; старые проекты открываются без предварительного
изменения базы. Пользовательские проекты в проверках не использовались.

Проверки: TypeScript; 980/980 клиентских и 806/806 серверных тестов; production build; публикация
сервера; API smoke с записью старого формата, чтением/миграцией, сохранением нового
и повторным открытием после перезапуска. Покрыты ветвления, обратные маршруты,
общие размеры, поправки длины, спецификация и разделённые полилинии.
