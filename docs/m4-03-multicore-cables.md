# M4-03 — многожильный кабель без дублирования расхода

Дата: 2026-09-17. Статус: в работе.

## Цель

Многожильный кабель является одним физически режущимся материалом и содержит
несколько существующих электрических проводников. Каждый проводник сохраняет
свои конечные точки, цепь, цвет и независимое подключение в Э4. Карта резки
учитывает общий кабель один раз и не создаёт строки сырья для входящих в него жил.

Первый срез не пытается восстановить промышленный состав кабеля из внешней базы:
в доступном источнике отсутствует подтверждённая полная схема проводов и состава
(пробел G06). Пользователь явно формирует состав экземпляра из проводов проекта и
закрепляет опубликованный материал типа `cable`.

## Контракт документа

Документ schemaVersion 1 получает необязательный массив `cables`; отсутствие поля
у старого документа эквивалентно пустому массиву. Экземпляр кабеля содержит:

- уникальный `id`;
- непустой уникальный список `memberWireIds` существующих проводов;
- необязательную неизменяемую `materialBinding`, только с `entityType=cable`;
- `lengthMm`, независимо заданные поправки двух концов и шаг округления резки.

Один провод может принадлежать максимум одному кабелю. Повторные ID кабелей или
жил, неизвестная жила, членство в двух кабелях, неверный тип материала и
некорректные длины отклоняются атомарно. Удаление провода удаляет его ID из
состава; пустой кабель остаётся незавершённым объектом, пока пользователь не
добавит жилу или не удалит его явно.

## Карта резки

Для обычного провода вне кабеля сохраняется поведение M3-11. Для кабеля создаётся
одна строка с закреплённым материалом, длиной резки и общим расходом, умноженным
на количество экземпляров жгута. Входящие жилы не создают самостоятельный расход,
даже если у старого документа на них сохранена привязка материала. Отсутствие
материала и длины выдаёт раздельные предупреждения и делает карту незавершённой.

## Границы первого среза

В срез входят модель, команды состава, строгая клиентская и серверная проверка,
сохранение, undo/redo, карта резки и минимальный интерфейс создания кабеля из
выбранных проводов. Э4 продолжает показывать отдельные электрические жилы.

Не входят автоматический подбор состава по артикулу, пары и внутренние экраны,
ветвление общей оболочки, сложная графика оболочки и разделки, переход сечения и
операции производства. Их следует добавлять следующими карточками после
проверяемого базового цикла.

## Критерии приёмки

1. Из двух и более проводов создаётся кабель, жилы остаются независимо подключены.
2. Один провод нельзя включить во второй кабель.
3. Кабелю назначается только опубликованный материал типа `cable`.
4. Save/reload, undo/redo, copy и export/import сохраняют состав и identity снимка.
5. Карта резки содержит одну строку кабеля и не содержит строки его жил.
6. Количество жгутов умножает расход кабеля ровно один раз.
7. Неизвестная длина оставляет объект сохранённым и выдаёт предупреждение.
8. Старые документы без `cables` открываются без миграции SQLite.
