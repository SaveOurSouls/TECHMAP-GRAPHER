# M2-05/M2-06 — библиотека и первый редактор шаблонов

Дата среза: 2026-09-14.

## Результат

В приложении появился отдельный раздел `Библиотека`. Графический шаблон хранится
отдельно от справочной записи и от будущего экземпляра в проекте. Один шаблон можно
связать с несколькими артикулами через тройку `источник / тип записи / ключ`.

Каждое сохранение существующего шаблона создаёт новую неизменяемую версию. Клиент
передаёт `expectedVersion`, поэтому параллельное редактирование не перезаписывает
чужую версию. Старые версии доступны через API и остаются пригодны для последующего
закрепления экземпляров проекта.

SQLite schema 10 содержит:

- `component_templates` — текущая голова, код, название и состояние удаления;
- `component_template_versions` — неизменяемое каноническое JSON-содержимое и хеш;
- `component_template_article_bindings` — неизменяемые связи версии с артикулами.

Проверка резервной копии контролирует непрерывность версий, согласованность головы,
каноническое содержимое, метаданные, связи и общий хеш версии. Миграция 9→10 создаёт
пустую библиотеку и сохраняет существующие проекты, справочники и схемы жгутов.

Первый рабочий срез M2-06 позволяет создать и повторно открыть шаблон, переключать
обязательные виды `Схема Э4` и `Чертёж`, добавлять дополнительные виды, линии,
прямоугольники, эллипсы, текст и именованные точки контактов. Объекты перемещаются
мышью, их координаты и основные свойства редактируются справа; доступна отмена
последнего изменения через `Ctrl+Z`.

## Архитектурная граница

Справочные характеристики остаются в опубликованных снимках справочников. Шаблон
содержит графику и устойчивые точки связи. Экземпляр в проекте будет хранить ссылку
на точную версию шаблона и свои параметры; новая версия шаблона не должна молча
менять уже размещённый экземпляр.

В текущем срезе ещё нет размещения библиотечного шаблона в Э4 или чертеже. Также
не закончены растровые изображения через CAS, слои, блокировка, группировка,
прозрачность, свободные кривые, замкнутые контуры и повторяемые параметрические
сегменты. Они продолжаются в M2-06–M2-08 поверх уже версионированного формата.

## Проверка

- API создаёт шаблон с двумя связями, создаёт вторую версию и читает первую без
  изменения;
- устаревший `expectedVersion`, дубликат кода и повреждённое содержимое отклоняются;
- schema 9 обновляется до 10 без изменения существующего проекта;
- резервная копия проходит с полной историей шаблона и отклоняет подменённую связь;
- клиентские тесты проверяют модель, API и команды редактора;
- полный .NET-набор и production-сборка клиента выполняются перед упаковкой ZIP.

## Следующий шаг

После пользовательской проверки сохранения и повторного открытия простого шаблона
M2-06 расширяет примитивы и управление слоями. Затем M2-07 добавляет параметры и
повторение контактов серии, а M2-08 связывает точки видов Э4, чертежа и
дополнительных изображений с одним логическим контактом.
