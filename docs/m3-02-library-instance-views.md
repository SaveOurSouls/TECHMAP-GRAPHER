# M3-02 — закреплённые библиотечные виды в жгуте

Дата начала: 2026-09-14.

## Цель

Размещённый библиотечный компонент должен показывать в Э4 и чертеже графику той
версии шаблона, которая была закреплена в проекте при размещении. Новая версия
глобальной библиотеки не должна менять уже сохранённый жгут.

## Часть 1 — контракт чтения

Реализовано чтение активного графа библиотечных компонентов выбранного жгута:

- `GET /api/v1/projects/{projectId}/harnesses/{harnessId}/component-placements`
  возвращает размещения и только используемые ими project-owned снимки;
- каждый снимок содержит точные номер и SHA-256 исходной версии, полный JSON
  представлений, связи артикулов и метаданные PNG;
- одинаковый снимок возвращается один раз, даже если его используют несколько
  размещений;
- содержимое PNG читается через адрес, ограниченный проектом, жгутом, снимком и
  asset; чужой жгут не может получить изображение;
- клиент проверяет идентичность проекта/жгута, связи placement→snapshot,
  уникальность ID, формат содержимого и тип изображения до использования ответа.

Интеграционный тест создаёт версию шаблона с PNG, размещает её в одном жгуте,
публикует более новую глобальную версию и подтверждает, что API продолжает
возвращать закреплённую старую версию. Другой жгут получает пустой граф и `404`
на изображение.

## Часть 2 — редактор жгута

Редактор параллельно загружает документ жгута и граф project-owned снимков. Поздний
ответ ранее открытого жгута отбрасывается; ошибка графа показывается отдельно и не
скрывает сам документ. После нового размещения граф обновляется без перезагрузки.

Для закреплённого варианта артикула в Э4 и чертеже отображаются разные виды его
точной версии: видимые слои, группы, параметры, повторяемые фрагменты, линии,
контуры, прямоугольники, эллипсы, кривые, текст и PNG с заданной обрезкой. PNG
загружается только через ограниченный проектом и жгутом адрес; во время загрузки
или при ошибке остаётся видимая локальная заглушка. Границы графики используются
для выделения, перетаскивания и команды «вписать в экран».

Провод использует материализованную точку нужного логического контакта и её
направление. Повторяемые контакты сопоставляются по occurrence key без сдвига
индексов. Неподключённая точка остаётся недоступной для трассировки и получает
графический знак X. Текущая таблица/коробка остаётся резервным отображением для
свободного компонента, недоступного снимка или вида без пригодной геометрии.
Дополнительные монтажные виды сохраняются в снимке; отдельного рабочего поля для
них в этой карточке нет.

## Проверки

- 470/470 клиентских тестов, TypeScript и production build;
- 610/610 тестов .NET;
- точная версия/артикул, отдельные E4/drawing виды и обновление графа;
- параметры и повторы, PNG crop/loading/error, fallback, hit-test и bounds;
- провод к закреплённой точке в обоих видах и строгий occurrence key;
- серверный тест более новой глобальной версии и доступа к PNG только из своего
  проекта/жгута.

Portable-срез `0.5.0-m3-02` прошёл семь режимов запуска из распакованного ZIP и
M1-15 с обновлением базы до схемы 15, резервной копией, импортом и восстановлением.

`0677F4540FD5DEEFA8F1B78B9C74859C5EA9355E5C32238C2F0AA350E38A824F`.

## Пользовательская проверка

1. В библиотеке создать и опубликовать шаблон с различимой графикой Э4 и чертежа,
   вариантом артикула и точками контактов; при необходимости добавить PNG.
2. Разместить выбранный артикул в жгуте и подключить провод к библиотечной точке.
3. Переключить Э4/чертёж и проверить разные виды, положение провода и выделение по
   фактическим границам графики.
4. Вернуться в проект, снова открыть жгут и убедиться, что вид и соединение
   сохранились.
5. Опубликовать новую версию шаблона: ранее размещённый экземпляр не должен
   измениться.
6. Проверить свободный компонент: он должен оставаться таблицей. При ошибке PNG
   должна появиться локальная заглушка без остановки редактора.

Критерий приёмки: различимая графика Э4 и чертежа одного шаблона появляется в
соответствующих представлениях жгута, провод приходит в связанную библиотечную
точку, результат переживает перезапуск, копирование и export/import, а публикация
новой версии шаблона не меняет экземпляр.
