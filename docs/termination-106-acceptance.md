# Проверка оконцовок 106 — 15.10.2026

REQ-141 уточняет REQ-135 по С1–С4 владельца. Проверяется исправление реализации 104; принятые профили 099 не перерисовываются.

## Причины и исправления

- Production-сервер раздаёт `/assets`, прежний `/termination-symbols` возвращал HTTP 404. Все 62 SVG теперь импортируются Vite как отдельные хешированные assets. Префикс размещения приложения учитывается; серверный контракт не расширен.
- Библиотека: компактное окно до 960 px, сетка рисунков, крупное превью с переключением Э4/Чертёж, поиск, фильтр, цветовые варианты и нижняя панель выбора. Ошибка назначения относится к этому окну, а не копируется из общего сообщения редактора.
- Выбор формы создаёт только предварительный рисунок. Щелчок на поле задаёт координату первого контакта; Escape/отмена ничего не добавляют. Масштаб и положение камеры сохраняются.
- В режиме «Выбор» точка оконцовки служит ручкой переноса. Перекрывающая фигура сохраняет приоритет. Незавершённое соединение сбрасывается при начале размещения и Escape.
- Новый провод/ответвление поступает в команду без предварительного Manhattan-маршрута. Обход препятствий выполняет штатный маршрутизатор; проверка явного недопустимого ручного маршрута сохранена.
- Перенос оконцовки в Э4 перестраивает автоматические линии вместо превращения их в ручные ломаные с диагоналями/пересечениями. ID, концы и заданные длины сохраняются. Размещение на скрытом/заблокированном слое отклоняется с понятным сообщением.

## Как пользоваться

В Э4 или Чертеже откройте слева «Оконцовки» → «Наконечник / гильза из библиотеки», выберите форму/цвет, нажмите «Выбрать», затем щёлкните в нужном месте поля. Для точки разделки есть отдельная кнопка «Разделка». У наконечника один вход, у гильзы два края.

Для переноса включите «Выбор» (V) и перетащите точку/рисунок. Для электрического подключения в Э4 включите «Провод» (W), щёлкните по первому и второму контактам. Перед добавлением следующего провода снимите выделение предыдущего щелчком по пустому полю: щелчок по концу выбранного провода используется для переподключения.

## Границы проверки

Browser редактора использует реальные React-компоненты/команды и синтетический документ с подменой API каталога/сохранения. Production HTTP-раздача рисунков проверена отдельно на настоящем .NET-сервере. Исходный пользовательский жгут и portable ZIP в этой карточке не проверялись. ZIP не заказан; ранее выданный архив не обновлён. Физическая допустимость многопроводного обжима определяется данными артикула, а не самим фактом возможности нарисовать несколько связей.
