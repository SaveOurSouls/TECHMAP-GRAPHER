# M-02 — приёмка сохранности черновика библиотеки

## Browser acceptance

26 сентября 2026 года проверена рабочая сборка `ComponentLibrary` внутри `App` в
Microsoft Edge (Playwright, изолированный браузерный контекст). API шаблонов был
заменён синтетическими маршрутами только внутри тестовой страницы; пользовательские
данные и локальный сервер не изменялись.

Проверены все переходы `open`, `new` и смена раздела с вариантами «Остаться»,
«Сохранить» и «Отбросить». При сохранении существующего шаблона выполнялся `PUT`
серверного draft; запросов публикации не было. После перезагрузки последний локальный
черновик восстанавливался. Ответ конфликта `PUT` оставлял введённый текст в редакторе
и в локальном recovery. Если во время задержанного ACK внести новую правку, она
оставалась dirty и сохранялась следующим запросом. Автосохранение рисунка и числовой
ввод с `blur` также проверены.

Результат: 8 draft PUT, 0 публикаций, 0 созданий, 0 ошибок страницы. Focused client
tests: 387 passed; отдельный browser script был временным и не входит в репозиторий.

## Ограничение

Существующий серверный контракт не создаёт draft для полностью новой, ещё невалидной
серии. До явного «Сохранить новую серию» такие правки защищаются локальным recovery,
который привязан к origin браузера. Серверные drafts уже существующих серий доступны
через API после перезапуска и смены порта.
