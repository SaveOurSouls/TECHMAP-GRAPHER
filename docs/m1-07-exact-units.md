# M1-07 — точные единицы и EX-01

Дата: 2026-09-12. Статус: завершено после M1-06.

## Фактический результат

- `Techmap.Domain`: физическая `Length` хранит неотрицательные целые микрометры,
  `ExactDuration` — неотрицательные целые микросекунды, знаковая
  `LengthCorrection` — отдельные микрометры. Отсутствующее значение выражается
  nullable-типом, а не физическим нулём.
- Фабрики из `decimal` переводят миллиметры/секунды в целые базовые единицы
  точно. Значения точнее 1 мкм/1 мкс отклоняются, а не округляются неявно;
  выход за диапазон `long` отклоняется. `double` в API не используется.
- `CutLengthCalculator` — чистая функция: входные размеры копируются в
  неизменяемый снимок; две поправки концов сохраняются отдельно. Если хотя бы
  один исходный размер неизвестен, итог и расход остаются `null`. Пустой набор
  размеров, неположительный шаг, отрицательный итог и переполнение отклоняются.
- Сумма исходных размеров и обеих поправок вычисляется в целых микрометрах
  с промежуточной `BigInteger`-арифметикой: допустимый конечный результат не
  отклоняется лишь из-за временной суммы за пределами `long`.
  Только итог резки округляется вверх до шага: по умолчанию 1000 мкм (1 мм),
  настраиваемый шаг — положительное целое число микрометров. Исходные размеры
  и поправки не округляются. Расход равен готовой длине резки, если она известна.

## Проверка

`dotnet restore Techmap-Grapher.slnx --locked-mode --runtime win-x64 -p:NuGetAudit=false`,
`dotnet build Techmap-Grapher.slnx --configuration Release --no-restore` и
`dotnet test Techmap-Grapher.slnx --configuration Release --no-restore --no-build`:
Release-сборка без предупреждений; frontend 35/35, .NET 209/209 и регрессия
M0 20/20 прошли. Self-contained ZIP 45,57 МиБ (106,97 МиБ распаковано) прошёл
семь переносимых режимов.

Проверены EX-01 (1000 + 10 + 20 − 2 + 3 = 1031 мм; покрытие оплётки
900 мм + 30 + 20 = 950 мм), раздельность поправок, различие позиций на 1 мм,
округление только итога, неизвестная и нулевая длина, отсутствие расхода для
незавершённой длины, отрицательный итог, переполнение суммы/округления, точность
десятичных единиц и снимок входных размеров.

## Границы

Это расчётные доменные типы, не миграция SQLite: предметных проводов и оплёток
в schema 4 ещё нет, поэтому постоянное хранение их длин и применение калькулятора
к объектам проекта остаётся будущей интеграцией. Нет геометрии, карты резки,
агрегации строк, HTTP API или UI. Тест различия 1 мм проверяет точные результаты;
проверка ключа объединения переносится в карточку реализации карты резки.
Норматив времени EX-02 входит в M1-08.
Следующая карточка основной последовательности — M1-08.
