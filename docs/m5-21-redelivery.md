## Скачивание с сохранением имени

Для локальной выдачи используется `scripts/serve-package-download.mjs`:

```powershell
node scripts/serve-package-download.mjs "<абсолютный путь к версионированному ZIP>"
```

Откройте напечатанный адрес `http://127.0.0.1:<порт>/` в браузере и нажмите
«Скачать ZIP». Адрес скачивания заканчивается полным именем архива;
HTML `download` и HTTP `Content-Disposition` также содержат это же имя с `.zip`.
Передаются исходные байты ZIP, `Content-Type: application/zip` и точный размер.
Сервис слушает только loopback и выдаёт только выбранный архив; после остановки
процесса Node ссылка перестаёт работать. Сам файл сохраняется на диске.

Проверки помощника: `node --check` — PASS; HTTP HEAD/HTML передают полное имя,
расширение и размер; неизвестный URL — 404, POST — 405. После готовности новой
версии отдельно проверяются её HTTP transfer и SHA-256.
