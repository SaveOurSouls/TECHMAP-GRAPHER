# M4-25 — таблица соединений, спецификация и выноски

Спецификация на чертеже содержит пять колонок: Поз., Обозначение, Наименование,
Кол-во, Примечание. Строки агрегируются по закреплённой идентичности источника и
версии; сохраняются все objectIds. Одноимённые материалы разных снимков разделены.
Жилы CableInstance не считаются повторно. Рисунки артикула и графическая оболочка
не создают дополнительного расхода. Защитное покрытие учитывается по своей длине.
Неизвестная длина даёт «—». Количество умножается на число жгутов точной арифметикой.

Таблица соединений выводит те же провода и контакты Э4; цепь и физическая длина
редактируются через общие команды. Строки справа и на поле подсвечивают исходные
экземпляры; фильтр «Только связанные» не меняет полный расход. Таблицы добавляются
из компактной панели и перемещаются за заголовок; значения на них живые.

Выноска хранит objectId, ключ строки, смещение якоря и независимую координату кружка.
Оба конца перетаскиваются. При переносе объекта якорь следует за ним, кружок остаётся.
Номер всегда берётся из текущей позиции BOM; перемещение строки вверх обновляет его.
Потеря объекта/позиции сохраняет выноску с «?» и явной диагностикой. Delete удаляет
выделенную аннотацию, Undo восстанавливает её. Новые optional drawingDocuments
валидируются на клиенте и сервере, старые документы остаются совместимы.

Клиент 810/810; TypeScript/production build прошли. Сервер 729/729.
Регрессии проверяют агрегацию и разделение версий, неизвестные длины, исключение
жил кабеля, перемещение якоря/круга, следование объекту, перенумерацию, Undo и JSON.
API --check-documents с отдельным тестовым жгутом и перезапуском прошёл.
Браузер 1280×720: таблицы видны на поле, щелчок строки подсветил два провода;
круг перенесён с x=232 до 510.635 при неизменном anchorOffset=(10,10); Undo вернул 232.
ZIP artifacts/m4-25/TECHMAP-GRAPHER-win-x64.zip проверен по манифесту после финальной
сборки клиента. Пользовательских данных нет; свой сервер остановлен.
