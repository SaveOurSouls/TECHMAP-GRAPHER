# M4-31 — массив фигур с контактами

Выбранные точки контактов теперь входят в прототип вместе с фигурами. Число
повторов берётся из артикула с учётом числа контактов в элементе; неполный
последний элемент не создаёт лишних электрических контактов. Номера и названия
точек читаются из существующих строк таблицы. Направление обхода и змейка
используют прежние настройки массива. Геометрическое растяжение меняет размер;
количество элементов меняется настройкой массива или выбором артикула.

Проекция привязывает повторные точки к устойчивым seriesRowId, в том числе
при размещении на чертеже. Сервер разрешает отдельные графические массивы
с точками без размножения электрического домена и сохраняет проверку ссылок,
лимитов и номеров. Старые электрические повторы не изменены.

Регрессия: 2 точки в элементе, артикулы на 2 и 5 контактов, неполный элемент,
размещение с пятью уникальными ID и пятью координатами. Клиент 824/824,
TypeScript, серверные валидаторы v2 27/27. Сборка/API/браузер — в M4-32.
