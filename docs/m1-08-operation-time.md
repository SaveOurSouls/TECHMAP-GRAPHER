# M1-08 — норматив времени и EX-02

Дата: 2026-09-12. Статус: завершено после M1-07.

## Фактический результат

- `Techmap.Domain` содержит чистый `OperationTimeCalculator` с разными типами
  входа для погонной и статичной операции. Статичный вход конструктивно не имеет
  длины и времени проката метра.
- Все длительности хранятся как `ExactDuration` в целых микросекундах, длина —
  как `Length` в целых микрометрах. Промежуточные произведения и суммы считаются
  через `BigInteger`; выход за диапазон `long` и непредставимая доля микросекунды
  отклоняются без скрытого округления.
- Для погонной операции применяется
  `Tmachine = L * V + S * K + D`, для статичной — `Tmachine = S * K + D`.
  Длина `L` переводится из микрометров в метры точно; `V` хранит время проката
  одного метра, `S` — время одного действия инструмента, `K` — число действий.
- `Tperson = D + Rwork + Rremove + Rtake`, а итог одного выполнения операции
  равен `Toperation = max(Tmachine, Tperson)`. Дополнительное время `D` входит в
  обе ветви; ветви не складываются.
- Положительный коэффициент повторения `q` применяется один раз после `max`:
  `TimePerWorkpiece = q * Toperation`. Для неотрицательного количества изделий
  `N` трудоёмкость без подготовки равна `Labour = N * q * Toperation`.
- Отсутствующий обязательный операнд хранится как `null` и оставляет зависимый
  результат неполным. Известный ноль остаётся физическим нулём. Вычислимая ветвь
  сохраняется в результате даже при неполной второй ветви.

## Проверка

EX-02 использует 20 мм, 5 с/м, 2 с на действие, `K=2` и `D=1 с`:
`Tmachine=5,1 с`, `Tperson=7 с`, `Toperation=7 с`; при `q=1` и `N=100`
получается 700 человеко-секунд. Сам пример фиксирует полные 7 секунд ручного
времени, но не их разложение: тест условно задаёт 3 с ручной работы, 1 с снятия,
2 с взятия и общее `D=1 с`.

Профильные тесты также проверяют статичную операцию, выбор машинного времени при
его превышении, однократное применение `K`, `q` и `N`, неполные значения и нули,
нулевую партию, отсутствие длины или скорости проката, недопустимый `q=0`,
отрицательные счётчики, переполнение каждой итоговой ветви и непредставимую долю
микросекунды. Итог: профильные Domain-тесты 30/30, все .NET-тесты 221/221,
frontend 35/35, регрессия M0 20/20, Release build без предупреждений.
Self-contained ZIP 45,57 МиБ (106,99 МиБ распаковано) прошёл семь режимов.

Воспроизводимая проверка:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/test-m1-08.ps1
```

## Границы

Калькулятор не читает БД.ОП и ничего не сохраняет в SQLite. В M1-08 не входят
подготовка, сумма нескольких операций блока, эффективный рабочий день, рабочие
места, оборудование, передаточные партии, критический путь, планировщик, API и UI.
Эти правила не дополняются неподтверждёнными формулами. Следующая карточка
основной последовательности — M1-09.
