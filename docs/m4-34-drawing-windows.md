# М4-34 — документы на рабочем поле

Спецификация, соединения и резка открываются в редактируемых окнах поля.
Заголовок перемещает окно в координатах чертежа; закрепление слева/справа/
сверху/снизу сохраняется в документе и не зависит от камеры. Размер окна
изменяется за угол. Тексты спецификации редактируются отдельно от вычисляемого
расхода; количество по-прежнему определяется моделью жгута. Правки соединений
и резки используют общие команды и Undo. Сервер проверяет новые поля.

Проверки: TypeScript, 828 клиентских тестов; 5 API-тестов сохранения,
некорректного закрепления/полей и неизменности ревизии при отказе.
Production build клиента. Полная сборка и браузерная проверка общего сценария
запланированы после М4-36. Пользовательские данные не затрагивались.

Далее М4-35: точки рисунка и контроль контактов; М4-36: привязанные размеры.
