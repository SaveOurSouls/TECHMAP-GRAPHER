## Правило передачи

Перед продолжением читать README, requirements-notes, requirements-audit,
development-plan, этот файл и текущую карточку; проверять git status/diff.
После каждой задачи записывать фактически выполненное, проверки, ограничения,
следующее действие и тематический коммит. Не выдавать критерии будущих тестов
за результаты. Не запускать другие задачи или агентов без разрешения.

Правила трассировки Э4 расширены. Новый ортогональный трассировщик обходит прямоугольники
всех соединителей, сохраняет обязательный прямой выход из контакта, разрешает только
перпендикулярные пересечения разных проводов и запрещает коллинеарное наложение,
нарушение зазора, самопересечение и самоналожение. При переносе таблицы transient-
предпросмотр сразу перемещает единственный экземпляр компонента и пересчитывает
провода без команд в истории; после отпускания мыши записывается одна команда.

Обозначение возвращено в верхнюю полосу, выделено и редактируется там после двойного
щелчка. Артикул расположен в нижней ячейке колонки «№». Ширины колонок вычисляются
из видимого содержимого единообразно для Canvas и HTML, с ограничением чрезмерно
широких значений. Повторяющиеся обозначения сохраняются, конфликтующие таблицы
получают красную отметку, а список ошибок позволяет выбрать и центрировать объект.
Escape действительно отменяет ввод обозначения или артикула. Геометрическая
нормализация выполняется на общей границе API при чтении и сохранении, поэтому
устаревшая автоматическая трасса не попадёт на сервер в обход экрана редактора.
