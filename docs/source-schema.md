# Фактическая схема источника M0-01

Дата проверки: 2026-09-11. Структурная выборка из локальной XLSX-копии.
Контекст, источник, ограничения и решения — [data-contracts.md](data-contracts.md).

## Метод проверки

Строка-кандидат: после заголовка есть непустое сохранённое значение хотя бы
в одном из первых пяти столбцов (для СПР.КАБ — первых четырёх). Это воспроизводимая
эвристика обследования, не готовый фильтр импортёра. Форматированные пустые строки
не считаются записями. Строки с формулами нумерации могут включать заготовки записей.
Ключи сравнивались как текст после обрезки краевых и схлопывания пробелов,
с сохранением регистра. Семантическая тождественность не проверялась.

Числа заполненности включают значения формул, нули и текстовые обозначения.
По ним нельзя заключать, что заполненные данные числовые или корректные.
Заголовки приведены с исходным написанием, переводы строки и лишние пробелы
в них заменены пробелами. Столбцы указаны только для этой версии источника.

## Ограничение результатов

В проверенных ячейках не обнаружены сохранённые ошибки #REF!, #N/A, #VALUE!,
#DIV/0!, #NAME?, #NUM!, #NULL!. Отсутствие этих ошибок не подтверждает
пересчёт, свежесть, формулы Google Sheets, корректность физических норм или
наличие всех требуемых полей. Программы станков и внешние инструкции не исполнялись.
