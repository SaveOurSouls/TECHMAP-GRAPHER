# 099. Многопроводные оконцовки: Э4 → Чертёж → Маршрут V3

Дата: 14.10.2026. Статус: проект решения для рассмотрения; приложение пока не изменено.
Основание: исходное поручение владельца, REQ-135, [карточка 099](../../tasks/099-multi-wire-termination-design.md).

## Предлагаемый результат

Провод остаётся отдельным объектом со своими материалом, цветом, сечением, длиной и двумя концами. Контакт может принимать несколько концов проводов. Общая оконцовка объединяет выбранные концы в один физический результат: один контакт с общим обжимом либо одну соединительную гильзу с обжимом/УЗ сваркой. Обработка каждого провода и операция общего соединения учитываются раздельно.

У наконечника ровно одна точка подключения проводов. Отверстие кольца, прорезь вилки и стыковочная часть pin/socket — элементы изображения, не дополнительные порты. У гильзы ровно две точки A/B на краях; на каждой допустим список концов проводов. Число точек не задаёт предельное число проводов. Возможность изобразить 3/4+ проводов не означает подтверждённую технологическую совместимость конкретного артикула.

Связность, способ соединения и физическая укладка — три независимых аспекта. Общий контакт электрически связывает присоединённые проводники; технология общего обжима задаётся явно. Скрутка связывает физические участки проводов и не создаёт электрический контакт. Гильза имеет внутреннюю проводящую связь A↔B, определённую типом компонента, а не совпадением координат.

Изображения используются как референсы; текст внутри них не является отдельным поручением. Числа из снимков не превращаются в подтверждённую базу производителя. НВШ сохраняется как пользовательское название/alias; предложенную форму следует привязать к конкретной каталожной позиции при наполнении библиотеки.

## Библиотека

Добавить категорию «Оконцовки» с сериями НКИ, НШВИ (включая НШВИ-2), НВШ, НВИ, DIN и отдельную категорию «Соединительные гильзы». Общая карточка: производитель, серия, артикул, описание, тип, источник/версия, материал и покрытие, изоляция/цвет, номинальный ток при наличии, допустимый проводник/класс жилы, сечение с исходной единицей, диаметр изоляции, длина зачистки, L+/L−, инструмент/матрица и подтверждённые сочетания проводов. Неизвестное значение — пустое/null, не ноль.

| Семейство | Параметры чертежа из референса | Дополнительные условия |
| --- | --- | --- |
| НКИ / НВИ | L, L1, D, B, d1, P, S (мм) | Диапазон мм², цвет изоляции, ток; размер крепления не электрический порт |
| НШВИ / НШВИ-2 | L, L1, ØC, ØW, A (мм) | Для двойного исполнения хранить «2 × сечение» и условия пары, не подменять суммарным одиночным номиналом |
| DIN / SC | d2, d, D, B, E, L (мм) | Назначение размеров по схеме изготовителя; standard отдельно от торгового названия |
| НВШ, pin/socket, плоские, флажковые | Параметры соответствующего профиля и стыковочной части | Alias, форма, пол и артикул — разные поля |
| Гильзы | L, внешний/внутренний диаметры, вставка на A/B | Условия каждой стороны и общий процесс соединения |

`maxWireCount` недостаточно: сочетания 2×0,5 и 1×1,0 могут иметь одинаковую площадь, но разные условия обжима. Нужны число, диапазоны каждого проводника, подтверждённые комбинации, ограничения общей площади и тип процесса. Для AWG нельзя складывать номера; единицы источника сохраняются, сопоставление возможно только по явным каталожным данным. Итог проверки: «совместимо», «несовместимо», «нет данных». Последний не считать автоматическим успехом.

## Исполнения флажкового — уточнение 15.10.2026

Флажковое исполнение делится на цельное изолированное (`flag`, новые C3/верх C5), неизолированное с открытыми обжимными лепестками (`flag-bare-open`, новые C1/C2), неизолированные трубчатые опрессовочные — гладкое (`flag-bare-pressed-smooth`) и рифлёное (`flag-bare-pressed-ribbed`, низ C5). Эти имена задают варианты рисунков, а не четыре новых технологических процесса. Изоляция, форма входа, профиль рисунка и назначенная операция должны храниться раздельно; форму нельзя использовать для автоматического выбора инструмента, нормы или допустимого числа проводов. Каждое исполнение имеет один проводной якорь; открытое окно перемычки, приёмное гнездо и пары лепестков не создают дополнительных контактов. Синий/жёлтый — варианты цвета одного изолированного профиля.

## Сценарии Э4

1. **Отдельный наконечник.** «Добавить → Оконцовка → Наконечник», выбор серии/артикула, размещение одного порта. Первый и последующие провода подключаются к той же точке. Инспектор показывает список проводов; свойства каждого редактируются индивидуально.
2. **Контакт соединителя.** Повторное подключение к занятому контакту добавляет провод. В строке контакта появляется «Проводов: 2» с раскрытием списка, вместо перезаписи цвета/марки предыдущего провода. В группе выбирается «Общий обжим», участники и назначенный терминал; кратность «двойной/тройной/четверной» выводится из состава, не независимый переключатель с противоречащим числом.
3. **Гильза.** Разместить компонент с A/B, подключить любое предусмотренное моделью число проводов на обе стороны. Выбрать технологию «Обжим гильзы» или «УЗ сварка на гильзе», артикул и технологическую карту. При обжиме двух сторон могут требоваться два выполнения/несколько ходов инструмента; система не фиксирует один цикл только потому, что материал один.
4. **Разделка.** «Добавить → Разделка». В Э4 — компактный символ окончания с названием режима, на Чертеже — точка с индексом/выноской. Все варианты ниже задают свойства конца, а не копию провода.

| Режим «Разделка» | Данные / поведение |
| --- | --- |
| Без разделки | Конец в изоляции, нет неявной зачистки или терминала |
| Медь | Зачистка с длиной; нет неявного соединения нескольких оголённых концов |
| Медь с лужением | Зачистка + лужение, известные нормы по источнику |
| Терминал pin | Пол pin, закреплённый артикул терминала |
| Терминал socket | Пол socket, закреплённый артикул терминала |
| Терминал pin с уплотнителем | Pin + совместимый уплотнитель и его размещение |
| Терминал socket с уплотнителем | Socket + совместимый уплотнитель и его размещение |
| Наконечник | Выбор НКИ/НШВИ/НВШ/НВИ/DIN и других форм из библиотеки |

Для «медь», «лужение», «без разделки» одно свободное окончание относится к одному wire/end; несколько свободных концов рядом не объединяются электрически. Для общего терминала группа явно объединяет участников. Переключение общей группы на свободные концы предлагает разделить её атомарной командой; не оставляет скрытый общий электрический узел.

## Чертёж и свивка

Размещение компонента Э4 автоматически создаёт связанный экземпляр на Чертеже с тем же ID. Координаты видов независимы; новая позиция помещается в область неразмещённых объектов до выбора места, существующая авторская укладка сохраняется. Изменение артикула/состава в любом виде меняет общую модель через одну команду. «Разделка» остаётся точкой даже при выборе наконечника; библиотечный рисунок виден в инспекторе/выноске. Самостоятельно размещённый наконечник и гильза показываются своим библиотечным рисунком.

Команда «Свить» доступна для двух и более проводов общего контакта. Пользователь выбирает общий физический участок, шаг и направление, отступы до концов. Скрутка может занимать только общую трассу; на развилке заканчивается либо продолжается выбранным подмножеством через отдельный участок. Если общей трассы нет, сначала её задают. Электрическая цепь, базовые длины и поправки не изменяются автоматически; технологический припуск задаётся отдельно и явно. Существующая дифференциальная пара остаётся парой из двух проводов: группу 3/4+ нельзя записывать в её tuple. Библиотечные кривые допустимы, физическая трасса остаётся ломаной по правилам проекта.

## Маршрут V3 и расчёты

Пример: W1/W2/W3 входят в один наконечник T1. Карточки подготовки сохраняют три заготовки с собственной резкой и зачисткой. Карточка сборки получает эти три входа и один T1. Операция «Общий обжим T1» относится к группе, а не копируется на каждый вход. На 10 одинаковых жгутов это 30 заготовок, 10 наконечников и 10 групповых выполнений **если техкарта задаёт одно выполнение на группу**. Норма/число ходов берутся из технологии; отсутствие нормы не равно нулевому времени.

Для гильзы 2+2 в BOM одна гильза, четыре провода и требуемые индивидуальные уплотнители/защита. Обжим стороны A и стороны B — отдельные назначения либо одна операция с явно заданным количеством выполнений. УЗ сварка не является меткой внешнего вида: хранит метод, рецепт/источник и состав сварного пакета. Защита после сварки — отдельный материал и операция, если назначены.

Готовый сборочный слепок рисует общий наконечник один раз с несколькими входящими проводами. Подготовительный рисунок отдельного провода показывает состояние до общей операции и ссылку «в общий обжим T1», не создаёт ещё один готовый терминал/расход. Ручной вид сохраняется как переопределение изображения; он не меняет материал/тип/состав. После правки Э4/Чертежа Route V3 показывает расхождения и обновляется с существующим явным подтверждением (REQ-129). «Автоматически» означает согласованную проекцию общих данных, а не молчаливое перезаписывание технологического маршрута.

## Проверка готового внедрения

Матрица минимальных сценариев: отдельный терминал/контакт соединителя × 1/2/3/4/5 проводов; гильза 1+1/2+1/2+2/3+2, пустая сторона; 8 режимов Разделки; общий обжим и УЗ; pin/socket и варианты уплотнения; одинаковые/разные сечения; AWG/мм²/неизвестная единица; удаление/перепривязка/undo/redo; поворот 0/90/180/270; save/reload/export/import и старая схема; свивка 2/3/4 на общем участке и развилке; Route V3 refresh и ручные рисунки; BOM/операции на 1 и 10 изделий. Неизвестная совместимость и незавершённая технологическая карта показывают незавершённость вместо «готово».

Особые регрессии: разные контакты соединителя не замыкаются; удаление провода не удаляет остальные члены; переназначение одного конца не переносит артикул на посторонний контакт; общий наконечник не дублируется в спецификации, выходных ПФ и времени; размер символа не меняет резку. Сервер должен отклонять те же невалидные ссылки и дубли membership, что клиент.

## Участники и ограничения результата 099

Sol выполняет архитектуру и подготовку рисунков; Luna — независимую проверку. Terra недоступна среди моделей сессии, поэтому её роль сложной архитектуры выполняет Sol с высоким уровнем рассуждения. Никакой агент Terra фактически не запускался.

Проверки этого среза подтверждают документацию, геометрию/якоря SVG и визуальную читаемость после рендера. Они не подтверждают реализацию функций в приложении. Каталожные данные НВШ/DIN и технология многопроводного обжима/УЗ уточняются по конкретным артикулам при наполнении библиотеки; проектирование не блокируется.
