# М4-99-r2–r4 — объёмный свет и переходы

В чертеже добавлен переключатель «Объёмный свет», сохранённый в
`drawingDocuments.volumeShading` с клиентской и серверной проверкой типа.
В r4 свет рисуется вложенными полосами вдоль пути пайпа/провода и по локальным
сечениям покрытия: края темнее, середина светлее. Ширина полос относительная.
Выключение сохраняет исходные цвета и геометрию. При отсутствии флага свет
включён; старые документы визуально меняются.

В r3 добавлены близкие контрольные сечения термоусадки около выходов пайпа
(параметры 0 и 1). Вне пайпа ширина основы равна ширине пучка. Это частичная
реализация Z-переходов: границы нижележащих покрытий и другие типы оболочек
ещё не получили гарантированные парные переходы. Проверка r3 лишь считала
короткие участки и не доказывала правильный профиль; в r4 она удалена.

Проверки r4: 1148 клиентских тестов, TypeScript/build, self-contained publish;
857 серверных Release-тестов прошли на серверном коде r2 (после него сервер
не менялся). API нового EXE с перезапуском, копированием и экспортом/импортом:
`artifacts/channels-smoke/test-2uRCLt`. Все 7 portable-режимов прошли.
Эти API-сценарии пока не проверяют сохранение именно флага volumeShading.
Браузерная проверка относится к слоям/импорту r1; визуальная проверка света
r4 и его переключателя ещё нужна. Полная цель и М4-99 не закрыты.

ZIP r4: `artifacts/m4-99-r4/TECHMAP-GRAPHER-0.55.0-m4-99-r4-win-x64.zip`,
54 402 249 байт, 30 файлов, без пользовательских данных.
SHA-256: `580F231B7EE449C6AEE24D996D4010BF17F8849B86B4FD11FFF0416BF7970B7F`.

Далее: браузерная проверка света/выключения; API и негативные проверки флага;
строгая геометрическая регрессия переходов на границах нижележащих покрытий;
М4-100 (объединённые оболочки) и незакрытые остатки М4-96.
