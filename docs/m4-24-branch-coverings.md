# M4-24 — оболочки и библиотечная защита по ветвям

Оболочка хранит интервалы по стабильным segmentId, ширину условного изображения,
цвет и отдельную физическую длину. Защитный материал закрепляется по sourceId,
snapshotId, SHA-256, recordId и sourceKey. Графическая оболочка без материала
не создаёт CableInstance и не удваивает расход кабеля.

В панели «Оболочки и защита» создаётся полоса по выбранным участкам; Ctrl/Shift
в списке ветвей добавляет участки к выбору. Начало/конец каждого участка задаются
процентами его текущей длины. Материал назначается двойным щелчком в «Защита»:
записи типа protective-covering из опубликованного technology-database. Они
создаются или импортируются через существующий универсальный справочник.

Полоса повторяет ломаную с соединением прямых участков, имеет торцевые границы.
Раздельные ветви рисуются отдельными путями без ложной перемычки. Перенос узлов
перестраивает покрытие, разветвление распределяет интервалы по новым участкам,
удаление участка снимает лишь относящиеся к нему интервалы. Выбор оболочки
подсвечивает её провода, сохраняя отдельное редактируемое выделение.

Клиент 805/805; тесты проверяют обрезку через перегиб, перенос, интервал после
разветвления, сериализацию, принадлежность проводов и неверные данные. Сервер
проверяет ссылки, интервалы, длины, ширину и закреплённые идентификаторы.
Сервер 726/726; production build, манифест и API --check-coverings с публикацией
тестового материала, проверкой интервалов и перезапуском прошли. Дополнительная
регрессия на один selectable object с раздельными путями также прошла (итого 806).
Браузер 1280×720: видна полоса на перегибах, выбор оплётки подсвечивает два провода;
начало покрытия изменено на 50%, проверена геометрия, затем выполнен Undo.
ZIP artifacts/m4-24/TECHMAP-GRAPHER-win-x64.zip проверен по манифесту после финальной
пересборки клиента, пользовательские данные отсутствуют. Тестовый сервер остановлен.
