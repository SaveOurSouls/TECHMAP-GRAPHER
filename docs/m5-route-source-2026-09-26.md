ТЗ на разработку
модуля Маршрутная карта


Модуль базируется на основе Чертежа. Его смысл в том, чтобы разбить чертеж на этапы, изготавливающие отдельные полуфабрикаты, и далее шаг за шагом собирать целиком весь жгут. Скрывая или показывая совокупность элементов на чертеже, можно показать монтажнику что он должен получить на текущем этапе. В последствии из этого сформировть UML схему, которая в дальнейшем ляжет в другую систему планирования производства.


Основные функции
1. 1 строка - это один полуфабрикат или несколько полуфабрикатов, если операция позволяет их производительно и одновременно. Например нарезка проводов разного цвета. Есть станок с 1 фидером, а есть с 5 и более. А для монтажных работ - это просто набор из нескольких операций БД.ОП с опяснениями. Строка содержит операцию, комментарии технолога и рисунок, А также дополнтиельные фото подгруженные методом dragnplay
2. В Маршрут переносится созданный чертеж изначально полностью скрытый. Скрытый - это прозрачность на 10-50%. Для создания отдельных полуфабрикатов я могу изолировать набор комплектующих. Напримимер в исхоном чертеже идет ветвь провода с изгибами. Для конкретного полуфабриката мне нужно просто сделать его прямым, при этом все размерные характеристики берутся из чертежа. И возможность редактировать изолированный объект сохраняется также как и для основного чертежа. Есть кнопка редактировать, отккрывается окно редактирования именно для этого изолированного объекта. Сохраняется автоматически через 1 секунду после окончания действий По кнопке выйти окно закрывается.
3. Для отдельных операций вроде нарезки провода или нарезки термотрубок, нейлонок и других составляющих оболочек, требуется вывести только эту комплектующую вне рамок чертежа
   1. ввиду того, что мы знаем какой она должна быть длинной, список комплектующих может заранее подготовлен, а оператору остается выбрать из БД.ОП только нужные операции, необходимые для этого


Описание процедуры:
1. Изначально в строках генерируются все оболочки и провода. Для проводов я могу назначить только резку, резку с разделкой одного или двух концов, резку сразу с обжимом, лужением или только разделкой одного или двух концов. Количество и другая важная информация. Терминалы берутся автоматически из тех контактов, к которым они прикреплены. Покаывается рисунок полуфабриката. Впоследствии для каждого терминала будет свой стилистический рисунок в профиль. Сейчас можно взять шаблонный, который обжимается на провод. Рисунок сохраняется все атрибуты провода: длина, марка и сечение провода, цвет, разделка концов. требования к разделке определяет установленный терминал и данные находятся в БД.ТЕР
2. Я могу выбрать операции и объединить их для оперций, где производится 5 проводов одновременно разного цвета. В этом смысле остается набор операций, а картинки как бы следуюют друг по другом. 
3. Подготовка нарезки оболочек и формирует на этом этапе карту резки. Без этой подготовки, карта резки считается впредь недоступной из други мест
4. Далее монтажные операции. Находится первая строчка для монтажных и сборочных работ. Как и ранее Указываю название полуфабриката, операции в него входящие, количество берется автоматически, из чертежа достаю изолированные объекты
5. Так происходит до тех пор, пока оператор не посчитает работу законеченной и не нажет кнопку - Закончить
