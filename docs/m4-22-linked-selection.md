# M4-22 — связанное выделение проводов

20.09.2026. Версия `0.30.0-m4-22`. Завершено.
Карточка — первый шаг поручения завершить M4-22–M4-26.

## Изменения

- Чистый индекс и resolver связывают провода, контакты, соединители, электрические
  узлы и строки кабелей по ID. Режим «Вся цепь» проходит по электрическому графу;
  общая геометрия, корпус соединителя и экранирующая оболочка не замыкают жилы.
- Отдельный золотистый ореол показывает связанные провода в Э4 и Чертёже.
  Редактируемый набор не расширяется: Delete и перемещение получают прежний выбор.
- В инспекторе показаны число проводов, режим цепи, переход на Чертёж и сброс.
  Скрытые слои остаются скрытыми; их связанные провода подсчитываются отдельно.
- Карта резки доступна в инспекторе и считается из текущего документа. Пометка
  сообщает о несохранённых изменениях. Кнопка строки показывает провод/жилы кабеля,
  фильтр оставляет только связанные строки. Кабель учитывается одной заготовкой.
- Карта на странице жгута также открывает нужные провода на Чертёже; передаваемая
  ссылка проверяется по projectId/harnessId, отсутствующий ID не заменяется именем.
- Центрирование выполняется явным действием, смена выбора сама камеру не двигает.
  Escape/«Сброс» очищают выбор и подсветку. Справка — InfoHint.

Новая модель файла не вводилась; выделение является состоянием интерфейса.
Физическая топология веток остаётся предметом M4-23.
