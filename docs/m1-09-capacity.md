# M1-09 — независимые рабочие места и EX-03

Дата: 2026-09-12. Статус: завершено после M1-08.

## Фактический результат

- `CapacityCalculator` равномерно распределяет `N` целых полуфабрикатов по `p`
  доступным полным независимым одинаковым рабочим местам. Первые `N mod p` мест
  получают на одно изделие больше; порядок стабилен, разница загрузки не больше 1.
- Длительность занятого места равна `P + n_i*C`. Пустое место имеет известную
  нулевую длительность и не получает подготовку. Длительность блока — максимум,
  трудоёмкость с подготовкой — сумма длительностей мест.
- Распределение хранится максимум двумя компактными группами равной загрузки,
  поэтому число мест до `long.MaxValue` не приводит к массиву такого размера.
- Время считается целыми микросекундами с промежуточной `BigInteger`-арифметикой.
  Переполнение длительности места или общей трудоёмкости отклоняется.
- Неизвестные `N`/`p` оставляют распределение `null`; при известных счётчиках и
  неизвестном `P`/`C` загрузка известна, а время остаётся `null`. Нули не теряются.
  `p=0` означает отсутствие доступного полного места и отклоняется.

`C` соответствует `TimePerWorkpiece` M1-08, уже включающему `q`. Передавать
`OperationTime` при `q>1` или `Labour`, уже включающий партию, нельзя.

## Проверка

EX-03: `N=11`, `p=2`, `C=60 с`, `P=120 с` даёт 6/5 изделий, 480/420 с,
длительность блока 480 с и трудоёмкость 900 человеко-секунд.

Профильные тесты проверяют одно место, лишние и пустые места без подготовки,
пустую партию, стабильность, недоступный комплект, nullable/ноль, границы `long`
и независимые переполнения. Итог: Domain 40/40, все .NET-тесты 231/231,
frontend 35/35, регрессия M0 20/20, Release build без предупреждений.
Self-contained ZIP 45,58 МиБ (107 МиБ распаковано) прошёл семь режимов.
Воспроизводимая проверка:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/test-m1-09.ps1
```

## Границы

Калькулятор не определяет доступность оборудования и не читает БД.ОБ. Не входят
неодинаковые места, граф, передаточные партии, очереди и резервирование станков,
критический путь, эффективные дни, календарь, SQLite, API и UI. Следующая карточка
основной последовательности — M1-10.
