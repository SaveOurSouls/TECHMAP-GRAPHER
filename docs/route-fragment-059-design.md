# План 059: независимый изолированный фрагмент и свободный конец провода

## Контракт

Текущая `presentation.drawingCopy` — полноценная редактируемая копия исходного чертежа. Новая операция создаёт рядом отдельное поле `presentation.isolatedDrawingCopy`: только выбранные материалы, независимые точки и обычные wire-геометрии. Поля `manufacturingRoute`, `physicalTopology`, pipe routes, physical nodes и связи с исходными соединителями в этот фрагмент не переносятся; провода получают синтетические endpoint IDs и `drawingEndpoints`. Сохранение изолированного фрагмента не переписывает `drawingCopy` исходной копии.

## UI

В режиме «Изменить фрагмент» действие «Создать изолированный фрагмент» доступно для материального выделения. После создания редактор переключается на новую локальную копию, где можно двигать вершины и линии штатными инструментами. Название и статус копии показываются в шапке; отмена возвращает к исходной копии без записи.

Для каждого свободного конца выбранного провода используется `drawingEndStyles` с режимами `cut`, `copper`, `tin`, `terminal`, `sealed`, `sealed-pin` из каталога полуфабрикатов провода. Это визуальный snapshot режима, не электрическая связь и не операция разделки; он сохраняется в изолированном документе и восстанавливается при повторном открытии. Существующий `WireEndStripProfiles` для коаксиальной разделки продолжает работать отдельно.

## Геометрия

Каждый выбранный провод получает две независимые конечные точки в `drawingEndpoints` и внутренние точки `drawingRoute`; если маршрут был физическим, отображаемая polyline материализуется в эту обычную геометрию один раз. Никакие route steps, pipe handles, physical nodes или исходные connector endpoint references не остаются в изолированном документе.
