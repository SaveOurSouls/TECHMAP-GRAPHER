# Каталог проводов Google Sheets

Источник: [лист «Провода»](https://docs.google.com/spreadsheets/d/1CywbVLHdLh2wO1-N2IkDdjfSMYtofsHPz-KnniQCjGg/edit?gid=122798924#gid=122798924).
Профиль `technology.wires` импортирует заголовки строки 3 и данные со строки 4 только в столбцах `E:AJ`.
Лист определяется по `E3 = Марка`; служебные столбцы `A:D` и расчёты после `AJ` не попадают в каталог.

Каждая исходная строка с маркой сохраняется отдельно. Повторные марки получают внутренний ключ варианта, но в редактируемой таблице показывается сама марка; строки идут в порядке листа. Повторные заголовки сохраняются как отдельные поля с буквой столбца (`Жесткость [T]`, `Применение [AB]`).

| Столбец | Поле | Назначение |
| --- | --- | --- |
| E | Марка | Марка провода |
| F | Core | Число/тип жил первой группы |
| G | Сечение C | Сечение первой группы |
| H | Pair | Число/тип второй группы |
| I | Сечение P | Сечение второй группы |
| J:AJ | Заголовки источника | Цвет, характеристики, применение и прочие свойства |

В опубликованном справочнике `F`, `G`, `H` и `I` остаются отдельными значениями. Редакторы при выборе материала показывают `FxG | HxI`, если заполнены обе группы. Для `1C` без второй группы показывается только `G`; код `1C` сохраняется, а подсказка поясняет, что это монтажный многожильный провод. Марка и сечение заполняют отдельные поля редактора; привязка сохраняет точный ID записи опубликованной версии.

Приложение содержит начальный каталог из 260 строк E3:AJ, импортированный 27.09.2026. При запуске он автоматически публикуется в локальную базу, если активного `technology-wires` ещё нет. Поэтому «Провода» доступны в «Справочниках» и при выборе материала в Э4 сразу, в том числе в новом пустом хранилище и без сети. Уже опубликованный пользовательский каталог не заменяется; повторный запуск сохраняет ID версии и записей.

Для получения последующих изменений источника используйте «Подключить базу проводов» и выполните синхронизацию из Google Sheets. Начальный каталог включён в сборку как сжатый ресурс `WireCatalogE3Aj.json.gz`; каждое поле и исходная строка сохраняют происхождение. Таблица соответствий AWG и диаметров больше не предлагается как справочник; старые снимки можно открыть только для совместимости и они не используются для выбора материала.
