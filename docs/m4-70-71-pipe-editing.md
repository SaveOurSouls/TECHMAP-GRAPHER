# М4-70–71: редактирование пайпов и навигация

Запрос 22.09.2026, С1–С3: плохо видимые точки, новые перегибы превращают пайп в петли, неясные стрелки справа; автоматические выходы соединителей, создание между двумя узлами и просмотр проводов по Shift+клику.

## М4-70 — реализация

- Выбор пайпа имеет приоритет над нарисованными внутри жилами и защитой. Управляющие точки рисуются последними поверх проводов: 5 px для перегибов, 6 px для узлов независимо от масштаба.
- Новая точка вставляется в ближайшую ветвь существующего пайпа, вместо дописывания после всех перегибов. Редактируются только исходные точки; вспомогательные вершины привязки 15° не превращаются в сохранённые перегибы. Двойной клик по ручке удаляет её, перетаскивание обновляет общий пайп и жилы в preview; завершение движения — одна команда Undo.
- При открытии чертежа для соединителя без выхода создаётся один устойчивый узел. Уже созданные выходы, дополнительные выходы и маршруты сохраняются. Автоинициализация не повторяется после Undo в этой сессии редактора.
- Выбрать два узла с Ctrl/Shift, нажать правой кнопкой по одному → «Пайп между двумя узлами». Новый пайп выбран сразу; повторная команда для той же пары выбирает существующий. Автоматическое распределение проводов использует прежние правила Э4, ручные маршруты сохраняются.
- Первая панель справа — таблица «Пайп / Откуда / Куда / Жилы». Строка выбирает пайп; выбор пайпа выделяет строку. Дополнительные поля компактны; создание по спискам и ручное назначение маршрута свёрнуты. Вместо неясных стрелок ручное направление подписано исходным узлом.
- Shift+клик по пайпу открывает таблицу только проводов, назначенных ему по ID маршрута, с цветами и возможностью подсветить один провод. Сама подсветка не изменяет документ.

## М4-71 — проверки и поставка

- TypeScript, 903 теста клиента (95 файлов), production client build проходят. Четыре новые регрессии: идемпотентные выходы, вставка в ближайший участок, неизменность электрических проводов при изменении пайпа, приоритет попадания и состав жил.
- Self-contained Release publish сервера и проверка манифеста проходят. Серверный код/схема данных не менялись; полный серверный набор уже проверен в М4-69 и повторно не запускался.
- API `test-harness-channels.mjs` расширен редактированием перегибов и выходами: сохранение/чтение/перезапуск, идентичность проводов и маршрутов, ветвление, несколько выходов и спецификация проходят на окончательной сборке.
- Браузер на отдельном CHANNELS-TEST: выбор S5 из таблицы; двойной клик вставил перегиб перед старым; перенос изменил пайп вместе с синей жилой; Shift+клик показал W3; выбор двух узлов с Ctrl и контекстная команда создали S6, подсветили строку и распределили провод. Пользовательские проекты не открывались и не удалялись.
- Версия `0.46.0-m4-71`, schema 20. ZIP `artifacts/m4-71/TECHMAP-GRAPHER-win-x64.zip` без пользовательских и синтетических данных. SHA-256 `DB2D50616048EC3ECC6B71ECC8644F4528A4676F347BFEECEFCF82E479BDB27D`.

Длины в мм и электрическая связность не зависят от перемещения пайпа. Пересечение пайпов само по себе не создаёт ветвления. Защита доступна через контекстное меню и свою панель; выбор на общем контуре отдаётся пайпу. Следующий свободный индекс — М4-72.
