# М4-104 — сохранение разрывов скрытых участков

Версия `0.57.3-m4-104`, 25.09.2026.

участки маршрута видимы. Если средний пайп помечен `showWires=false`, видимые
края остаются отдельными и не создают искусственную линию через скрытый участок.

  контекста у видимых краёв;

- браузер `http://127.0.0.1:64603/` на синтетическом проекте с общей оболочкой
  и скрытым участком показывает только разрешённые видимые части;
- verify-package и семь portable-режимов прошли.
