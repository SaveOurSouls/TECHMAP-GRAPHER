# М4-98 — материалы, текстуры и штриховки

## Первый срез: стиль отдельной оболочки

Версия `0.54.0-m4-98-r1`. `PhysicalCovering.style` сохраняет необязательные
параметры текстуры, её масштаба/поворота, штриховки, её цвета/шага/поворота и
цвета контура. Существующее `color` остаётся цветом фона. Старые документы
сохраняют прежний вид: текстура по типу оболочки, масштаб 1, без штриховки.
Технологическая длина, интервалы, размеры пайпа и проводники не меняются.

В свойствах по правому клику добавлен сворачиваемый раздел «Текстура и
штриховка». Доступны существующие встроенные текстуры резины, ткани, металла,
автоматический выбор и отключение. Масштаб — 0,1–10, поворот — −180…180°.
Штриховки: параллельная, перекрёстная, точки; шаг 1–100, поворот −180…180°.
Фон, штриховка и контур имеют независимые цвета со стандартной палитрой.
Справка — InfoHint. Валидные числовые изменения отображаются сразу; пустой
промежуточный ввод допускается до Enter/blur.

Рендерер повторяет текстуру и штриховку внутри фактического контура оболочки,
включая дугу. Узоры ориентированы в координатах листа. Штриховка использует
повторяющуюся плитку и ограниченный кэш, поэтому её стоимость не растёт
пропорционально числу штрихов на длинном пайпе. Цвет выделения временно
заменяет цвет контура, сохранённый цвет остаётся неизменным. URL встроенных
текстур учитывает `<base>` приложения при запуске с URL-префиксом.

## Остаток после первого среза (история)

М4-98 не завершён: нужна таблица материалов/текстур в общих настройках, загрузка
изображений и drag-and-drop, предпочтительная текстура и материал для каждого
типа оболочки, раскрытие полного списка в свойствах. Текущий выбор использует
встроенные файлы; он не является импортом пользовательских текстур. Привязка
материала к спецификации сохраняет прежнюю модель закреплённого справочника.

М4-99: слои рисунок/провода/контакты, строго белый фон растров, отключаемый
объёмный свет, парные Z-переходы покрытий. М4-100: объединение пайпов/оболочек
под общей подвижной оболочкой, плоская/круговая упаковка, итоговый сквозной аудит.
Остатки М4-96 (несколько трасс при переносе и браузерная проверка двухопорной
привязки), сопряжения отдельных пайпов у общего узла также остаются открытыми.

## Второй срез: таблица материалов и вложения проекта

Версия `0.54.1-m4-98-r2`. Кнопка «Материалы» в общих настройках чертежа
открывает таблицу шести типов оболочек. В строке выбираются предпочтительная
текстура и закреплённый материал из справочника защиты. В контекстных свойствах
сначала доступна предпочтительная текстура; «Все текстуры» раскрывает список.
Новые оболочки получают материал и текстуру при создании. Изменение предпочтений
не перепривязывает размещённые материалы; текстура «По типу» следует настройке.

PNG/JPG/BMP/SVG/HEIC проходят существующий нормализатор в PNG. Файл можно
выбрать или перетащить в строку типа. Во вложении проекта хранится изображение
с назначением `covering-texture`, в документе — имя и SHA-256. В текущем проекте
URL разрешается через список вложений по хешу; идентификаторы вложений после
копирования/импорта могут измениться. Данные PNG не расходуют лимит 1 МиБ
документа. Убрать из списка можно только неиспользуемую текстуру; само вложение
сохраняется. Недоступный файл обозначается в таблице. Настройки общие для
текущего чертежа, не являются настройками всех проектов приложения.

Проверки: 1139/1139 клиентских тестов, TypeScript/build, 857/857 .NET-тестов
Release и self-contained publish. Регрессии проверяют наследование и сохранение
материала, спецификацию, обработчик drag-and-drop и выбора файла, валидацию,
CSRF и актуальную ревизию загрузки, конфликт без перезаписи.

В браузере синтетической сцены проверены загрузка SVG через file chooser,
миниатюра, выбор текстуры для оплётки и её отрисовка на изгибе, раскрытие полного
списка. HTTP-каталог в этой Vite-сцене отсутствует (404); выбор реального
справочного материала в браузере здесь не подтверждён. Нормализатор изображения
и компонент настроек использованы настоящие, загрузка во вложения проверена API.
API готового EXE подтвердил PNG-вложение, перезапуск, копирование, реальный
экспорт и импорт проекта: библиотека и байты изображения совпали.
Артефакты: `artifacts/channels-smoke/test-CeQB3W`.

## Завершающий аудит М4-98

На отдельной копии готового EXE с новым синтетическим хранилищем опубликован
справочник `technology-database` с двумя материалами `protective-covering`.
В браузере выбран TEST-HS-1 для оплётки; по правому клику на пайп создана
оплётка. Материал автоматически появился в строке спецификации и сохранился
после перезагрузки страницы и повторного открытия чертежа. Read-only API
подтвердил совпадение sourceId/snapshotId/snapshotSha256/recordId/entityType/
sourceKey между опубликованной записью, предпочтением и новой оболочкой.
Проверка использовала существующий пакет r2; исходный код и ZIP не менялись.
Пользовательские проекты не использовались.

М4-98 завершён. М4-99–100, остатки М4-96 и сопряжения пайпов у общих узлов
сохраняются. Общий итоговый аудит всех требований остаётся в М4-100.
