# М4-81 · Очистка рисунков без восстановления исходника

Исправлен сценарий из C1: удаление старого рисунка больше не оставляет артикул
назначенным на неполный генератор. Очистка создаёт явную пустую привязку и
сохраняет электрическую таблицу. Вкладка «Артикулы» предлагает область очистки:
выбранный артикул или вся серия.

После очистки можно сразу добавить примитив, контакт или изображение. Сохранение
пустого поля разрешено; если выделение отсутствует, сохраняется весь открытый вид.
При выборочной очистке общий вид отделяется в дополнительный вид, поэтому соседние
артикулы и другие разделы рисунка не меняются. Удаление последнего периода/контакта
исходника также отсоединяет назначения генератора и оставляет обычное редактируемое
пустое поле. Таблица соединений и привязки контактов остаются источником
электрических данных.

Проверки: 931 клиентский тест, 777 серверных тестов, TypeScript и production build;
браузерный сценарий подтвердил очистку PHR-2, повторное рисование, очистку всей
серии, отмену Ctrl+Z и загрузку PNG после очистки.

Готовый пакет прошёл API smoke на отдельной временной базе: сохранение пустого
артикула, повторное открытие после перезапуска, сохранение новой фигуры, добавление
PNG, второй перезапуск и сравнение электрической таблицы. HTTP 200, версия
`0.48.1-m4-81`; манифест и контрольные суммы проверены. Общие контактные массивы
и фигуры с электрической привязкой по-прежнему проверяются на полноту; обычная
иллюстрация может не иметь контактных точек.
