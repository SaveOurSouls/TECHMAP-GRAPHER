# M4-86 · Кнопки документов жгута

Версия среза: `0.51.0-m4-86`.

Навигационный блок документов жгута больше не требует сначала выбирать вкладку,
а затем нажимать отдельную кнопку открытия. Элементы «Схема Э4», «Чертёж» и
«Маршрут» представлены самостоятельными кнопками с пиктограммами листа,
описанием и состоянием. Один клик по Э4 или Чертежу сразу открывает редактор;
один клик по Маршруту сразу переключает просмотр маршрута.

Проверки: `pnpm --filter @techmap/client typecheck`, 959 клиентских тестов,
production build и `scripts/build-package.ps1 -ArtifactSlice m4-86`.
