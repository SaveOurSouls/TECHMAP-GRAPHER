# М4-82 · База проводов и две колонки Э4

Версия `0.49.0-m4-82` подключает предоставленную Google Sheets через профиль
`technology.wires` / источник `technology-wires`. В разделе «Справочники» выберите
Google Sheets → «Подключить базу проводов» → загрузку. Кнопка подставляет ссылку
пользователя и выбирает только профиль проводов. Для офлайн-импорта той же книги
доступен профиль «Провода — все колонки строки 3» в режиме XLSX.

Лист определяется по сочетанию заголовков строки 3: Марка, Core, Сечение C,
Pair, Сечение P. На исходной книге от 23 сентября 2026 найден лист «Провода»:
260 строк с маркой, 32 колонки диапазона E:AJ. Строки без марки (памятки и прочие
служебные записи) пропускаются с предупреждением; пустые ячейки сохраняются.
Повторные заголовки не теряются: вторые «Жесткость» и «Применение» доступны как
«Жесткость [T]» и «Применение [AB]». Значения формул берутся из сохранённого
результата XLSX. Шесть исходных `#REF!` в расчётах цены сохранены текстом с
адресными предупреждениями. Формулы в приложении не вычисляются.

Строки-разделители вроде «Монтажный провод», «Высокотемпературный провод»,
«Силиконовый провод» и «Видео кабель» публикуются как записи категории: их
текст переносится в столбец «Категория», а «Марка» очищается. Они не считаются
проводами и не появляются в выпадающих списках Э4 и материалов. Для обычных
строк текущая группа доступна в поле «Категория группы» и участвует в фильтрах;
исходная колонка «Категория» сохраняется.

В таблице компонента Э4 «Провод» разделён на «Марка» и «Сечение»:

- `Core = 1C` / `1С`: только значение «Сечение C», например `30` или `0,35`.
- Остальные варианты: `Core x Сечение C / Pair x Сечение P`, например
  `4C x 24 / 1E x 28`. Если одна часть отсутствует, лишний разделитель не выводится.
- Марка берётся из «Марка». Единицы измерения и обозначения групп не угадываются.

Поиск по опубликованной базе работает прямо в ячейке «Марка» как на схеме,
так и в библиотеке. Полный снимок каталога используется для зависимых списков:
выбор марки оставляет только её комплексные сечения, а выбор сечения оставляет
только марки, у которых есть такая запись. Выбор варианта одновременно заполняет
обе колонки.
Подсказка показывает артикул, цвет, производителя и категорию; поиск учитывает
все импортированные характеристики. Ручной ввод и отмена сохраняются.
При недоступной базе показано понятное сообщение и встроенные варианты. Профиль
`technology-awg-reference` удалён из списка новых импортов; чтение старых
публикаций сохранено только для обратной совместимости.

Новые поля сохраняются в серии, локальных переопределениях артикула, размещённом
компоненте и документе проекта. Старое поле `wire` остаётся носителем марки,
добавлено необязательное `wireSection`. Старые строки не разбираются эвристически:
прежнее значение остаётся целиком, сечение пустое. При расширении старой таблицы
с контактами справа её положение корректируется так, чтобы сохранить координаты
контактов и ручные маршруты. Повторное открытие больше не сдвигает таблицу.

Проверки: 940 клиентских тестов, 782 серверных теста, TypeScript и production build.
Первый полный прогон превысил бюджет нагрузочного поиска (115 мс при пороге
100 мс); отдельный повтор и итоговый полный прогон прошли без ослабления порогов.
Браузер подтвердил поиск, выбор одиночного и комбинированного сечения, совместную
отмену двух значений, сообщение о незагруженной базе и встроенные варианты.

Готовый пакет прошёл API smoke на отдельной временной базе: импорт контрольной
книги, импорт реальной книги пользователя, непосредственную синхронизацию по
Google Sheets, поиск UL2919, публикацию компонента с отдельным сечением, перезапуск
и проверку сохранённых 260 строк / 46 колонок и преднастройки сечения.
Манифест и контрольные суммы пакета проверены.

## Доработка импорта и назначения материала

Актуальный профиль `technology.wires` находит лист по заголовку `Марка` в
ячейке E3. Поля `Core`, `Сечение C`, `Pair` и `Сечение P` используются для
ограничения вариантов сечения в Э4, если они присутствуют, но их отсутствие
не блокирует импорт. Все подписанные столбцы строки 3 сохраняются, а строки с
одинаковой маркой получают разные идентификаторы записей.

Выбор опубликованного варианта марки и сечения в Э4 закрепляет на контакте
точную версию записи базы проводов. Подключённый провод получает эту запись
как материал; новый провод наследует материал от контакта. Ручной ввод марки
или смена сечения без подходящей записи снимают прежнюю привязку. Цвет из
выбранной записи заполняет отдельное поле «Цвет» и передаётся проводу; если
цвета в записи нет, уже заданное значение сохраняется.

Для ранее сохранённых библиотечных значений редактор также ищет точную
однозначную запись в активном каталоге. При совпадении одинаковых марки и
сечения учитывается цвет; если вариант остаётся неоднозначным, привязка не
назначается автоматически. Марка, сечение и материал синхронизируются между
двумя контактами одного прямого провода. Ветви через электрический узел
остаются самостоятельными проводниками.
