# М4-35 — контакты рисунка

При наличии рисунка чертежа исчезают резервные точки старой таблицы. Геометрия
контактов пересчитывается из того же закреплённого снимка и артикула, что фигуры.
Отсутствующие точки диагностируются. Версия библиотеки сама не подменяется.

Сохранение проверяет контактные строки выбранного артикула с развёрткой массивов.
Общий выход пучка сохраняется в наборе рисунка только для Чертежа. Все контакты
получают эту графическую точку, сохраняя отдельные электрические ID. Пустой
набор означает удаление рисунка. Старые наборы без target читаются для совместимости.

Проверки: TypeScript, 828 клиентских тестов (включая массив A5 и общий выход),
12 серверных проверок v5; production build клиента. Полный пакет и сквозная
проверка после М4-36. Пользовательские проекты не изменялись.
