# М4-36 — размеры и длины на чертеже

Добавлены три компактные кнопки: горизонтальный, вертикальный и свободный (выровненный) размер. Оператор выбирает конец или перегиб провода, затем вторую точку; свободная линия параллельна участку. Значение вводится в миллиметрах.

Общий размер между концами задаёт длину. Без него суммируются только неперекрывающиеся участки полного маршрута; пропуск сохраняет null. Изменение маршрута снимает старую привязку. Ручной ввод длины блокируется, пока провод измерен размерами. Старый автоматический размер сохраняется только для обратной совместимости документов без новых размеров.

Проверки: TypeScript, 829 клиентских тестов, серверные тесты документов и v5, Release-сборка. Пользовательские проекты не изменялись.
