# M4-114 · управление линиями, размерами и общими оболочками

В редакторе чертежа линия позиций может быть горизонтальной, вертикальной или
диагональной. Её концы перемещаются независимо, а позиции перераспределяются
по параметру линии. Нижняя панель содержит общий ползунок размера размерных
обозначений и настройку минимального перекрытия новой оболочки.

При добавлении оболочки поверх существующей оболочки по выбранной точке новый
интервал занимает 5% длины нижней оболочки, но не меньше 100 px по умолчанию.
Минимум можно изменить в нижней панели; если доступный участок короче, берётся
весь доступный участок. Сохранённые границы и якоря исходной оболочки не
изменяются.

Для общей оболочки группы переходные ручки объединены: по одной на каждый
выход из оболочки. Перемещение ручки изменяет общую длину перехода и общий
поперечный изгиб всех входящих пайпов. Вложенная короткая оболочка использует
переход своей поддерживающей группы и не создаёт второй набор управляющих
точек. Объёмное оформление доступно для плотного пайпа более чем с тремя
проводами и для групп пайпов/оболочек; переключатель применяется ко всем
проводам, пайпам и покрытиям чертежа.

Проверки: клиентский typecheck и полный набор клиентских тестов.
