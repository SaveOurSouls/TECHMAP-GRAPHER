## Изменения

Рисунок сборки открывается в настоящем `HarnessDesignEditor.localCopy`.
Геометрия, изгибы, Ctrl/Shift-привязки, размеры, цвета, текстуры, слои и
видимость используют те же команды и рендерер, что Чертёж. Сохраняется
`presentation.drawingCopy.document` без вложенного маршрута и hidden IDs.
Save обновляет презентацию строки, Cancel отбрасывает правки. Превью содержит
только фрагмент; фон редактора регулируется 0–100%. Производственные данные
из исходника продолжают синхронизироваться отдельно.

Копия ограничена 1 MiB; общий документ и recovery — 16 MiB. SQLite schema v23
меняет CHECK таблицы, сохраняет данные/ревизии и trigger новых жгутов.
`package/VERSION.json.storage.schema` согласован с кодом. Рекурсивный маршрут
запрещён, применяются клиентская и серверная проверки содержимого/сложности.

## Ограничения приёмки

- Исходный пользовательский жгут не использовался в browser QA. Отдельный
  drag с Ctrl/Shift и внешние assets в этой фикстуре не проверялись; общие
  команды покрыты клиентским прогоном.
- Новые библиотечные соединители, добавленные только в копию, догружают
  опубликованную версию по binding. При переносе им нужна эта версия библиотеки;
  исходные закреплённые project snapshots продолжают работать автономно.
- Часть старой overlay-геометрии не переносится точно: перед сохранением есть
  предупреждение, Cancel сохраняет старый рисунок.
- Копия не имеет отдельного recovery. Встроенные/закреплённые текстуры сохранены;
  новый внешний материал без закреплённой текстуры автоматически не загружается.

## Поручение сборщику

Дождаться всех включаемых соседних задач и проверить ancestry этого коммита.
Сверить последнюю выданную версию с `0.63.18-m5-07-review`; для нового кодового
среза повысить appVersion, зафиксировать и отправить версионный коммит.
Собрать штатным `scripts/build-package.ps1` из определённого HEAD, проверить
манифест и все семь portable-режимов (включая обновление schema22→23), записать
байты/SHA-256 и исходный кодовый commit. Имя ZIP должно включать appVersion.
ZIP остаётся вне Git; после проверки фиксируется только протокол поставки.
Этот документ подтверждает передачу кода, а не готовность ZIP или приёмку владельцем.
