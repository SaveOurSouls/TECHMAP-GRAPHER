## Правила после изменения

- Обычный перенос тянет соседние плечи и сохраняет прямые участки; Shift адаптирует геометрию локально. В ортогональном режиме свободные диагонали не возникают при этих жестах. Явный режим 30° сохраняется.
- Выходы из контактов сохраняются. При коротком выходе локальный изгиб не должен возвращаться за обязательный прямой участок.
- Промежуточная ручка не разрывает свивку; каждый общий горизонтальный участок получает мотив. Вертикальные участки остаются обычными проводами, таблицы обрезают область декорации.
- T-узлы следуют своим носителям с сохранением ID. Деформация и добавленные углы учитываются при переносе координаты узла. После схлопывания участка узел остаётся на своём проводе.
- При перемещении таблицы проверяются затронутые проводники и связанные ветви. Для ранее прямой группы быстрый ограниченный разнос новых изгибов предшествует общему поиску пути; при необходимости используется первый валидный результат поиска.
- Связи, концы, ID, заданные длины и физическая топология от редактирования геометрии Э4 не меняются.

Это уточнение старых правил карточки 022: требование ортогональности ранее оставалось открытым для `edit-e4-bend`. Архитектура общей модели ADR-0003/0004 не меняется.

## Ограничения и поставка

- Пользовательский исходный жгут, desktop portable и ZIP не проверялись; ZIP не заказывался и здесь не собирался.
