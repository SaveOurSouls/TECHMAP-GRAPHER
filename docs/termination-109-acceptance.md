# 109 — библиотека оконцовок и генерация серий

Дата: 15.10.2026. Требование REQ-144; статус после публикации и handoff — ready-for-review, приёмка владельцем открыта.

## Проверенный результат

- Начальный экран → «Библиотека» → «Библиотека оконцовок». Постоянный пункт назначения, без команды удаления; библиотека соединителей сохранена отдельным пунктом.
- Одна страница всех серий, отдельная таблица каждой серии. Одна строка на артикул: форма/рисунок, артикул, наименование, производитель, исполнение/цвет, материал/изоляция, все размеры семейства, ток, зачистка/поправки, диапазоны количества/сечения проводников, комбинации, материалы жил, подтверждение/источник условий, источник данных и примечание. Широкая строка прокручивается внутри таблицы.
- «Генерировать серию»: название, производитель, форма, шаблон артикула с `{n}`, начальный номер/шаг/разрядность и количество 1–200. Сначала формируется редактируемая таблица, затем серия сохраняется целиком. Существующая серия дополняется той же генерацией. Размеры и условия не выводятся из порядкового номера или цвета.
- Независимые ID серий сохраняют отдельные таблицы одинаковой формы/производителя. Редактирование не меняет порядок серий, ID старых строк и их принадлежность.
- Старые локальные записи доступны без миграционной перезаписи; принятие в серию сохраняет record ID. Метаданные и строки пишутся атомарно в прежний localStorage key. Конкурентное изменение серии, повреждённое хранилище, повторяющийся артикул и ошибка квоты не перезаписывают исходные данные.
- В Э4/Чертеже окно выбора содержит только поиск, фильтр, просмотр таблиц/рисунков и выбор готовой записи. Прежняя форма одиночного артикула удалена. Свойства размещённой оконцовки, общего наконечника и индивидуального терминала показываются по закреплённому payload, без каталожного редактирования. Свободный ввод нового артикула уплотнителя из инспектора заменён просмотром. Настройки обозначения, подготовки концов и операций экземпляра остаются доступными.
