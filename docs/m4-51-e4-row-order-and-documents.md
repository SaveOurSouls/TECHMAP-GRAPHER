# M4-51/52 — строки Э4 и документы по разделам

Срез продолжен с ветки `codex/restore-20260918-0235` после M4-50.

## Реализовано

- Привязка при перемещении табличного компонента Э4 использует первую строку перемещаемого компонента и ближайшую строку любого другого компонента. Направляющая и итоговый сдвиг используют одну и ту же пару строк.
- В редакторе Э4 у строк появились стрелки вверх/вниз. Перестановка хранится в `schematic.rowOrder`, не меняет `contact.id`, номер, значения, чертёжные координаты или концы проводов. Роуты перестраиваются; временная коллизия не блокирует следующую перестановку и остаётся диагностикой.
- Валидация клиента, сохранения, импорта и экспорта принимает только уникальные существующие ID контактов в `rowOrder`.
- Резка и разделка отображаются только в Чертеже. Э4 получает отдельное окно таблицы соединений. Маршрут показывает read-only таблицу соединений из того же документа.
- Внешние пояснения оставлены в `InfoHint`; интерфейс сохраняет компактные окна и кнопки на поле.
