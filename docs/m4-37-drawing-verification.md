# М4-37 — итоговая проверка чертежа

Версия `0.40.0-m4-37`. М4-34–М4-36 реализованы; М4-37 проверяет общий сценарий.

## Результат

- Спецификация, соединения и схема резки открываются в окнах на поле. Окна
  перемещаются за заголовок, меняют размер и закрепляются у краёв. Закрепление,
  положение, тексты спецификации сохраняются в документе; расход остаётся
  вычисляемым. Правки соединений и резки используют общие команды жгута.
- Рисунок выбранного артикула и провода используют его контактные точки.
  Резервные точки старой таблицы не дорисовываются рядом с рисунком.
  При сохранении проверяется соответствие строкам артикула, включая массивы.
  Один общий графический контакт допустим только в чертеже: электрические ID
  остаются раздельными. Старые наборы без target читаются для совместимости;
  недостающие точки требуют исправления и обновления закреплённого компонента.
- Горизонтальный, вертикальный и свободный размеры создаются между точками
  одного провода. Свободная линия параллельна соединяющей точки прямой.
  Оператор задаёт миллиметры. Общий размер задаёт полную длину; без него
  суммируются непересекающиеся участки, полностью покрывающие маршрут.
  Пропуск оставляет длину неизвестной. Изменение состава маршрута снимает
  устаревшие привязки. Ctrl+Z возвращает размеры и расчёт вместе.

## Проверки

- TypeScript и production build клиента; Release build сервера.
- 832/832 клиентских, 746/746 серверных тестов. Первый повтор полного прогона
  был прерван; в итог засчитан только последующий успешный полный прогон.
- API итогового EXE: размещение v5 с совпадением template/version/hash/article,
  массив на 12 контактов, общий выход с раздельными ID, отказ для общего выхода
  в Э4 и отсутствующих контактов, таблицы и физические маршруты, схема резки.
- Размеры 100,125 + 200,125 дают 300,25 мм и заготовку 301 мм. Несогласованная
  длина отклоняется без изменения ревизии. Частичное измерение сохраняет null.
  После перезапуска проверены все сохранённые значения.
- Браузер: широкие окна и поля ввода, кнопки размеров, отображение привязанных
  линий, ввод 125,5 мм, смена выделения без потери второго размера 200,125 мм.
  Найдено и исправлено стирание значения при автофокусе: нет пользовательского
  ввода — нет записи. Нативное перетаскивание каждого типа окна отдельно в
  браузере не автоматизировалось; координаты и закрепление покрыты тестами.
- ZIP: verify-package, манифест SHA-256, отсутствие БД, журналов и data/backups.
  Пользовательские проекты не использовались для проверок и не удалялись.

## Операционное замечание

При повторном прогоне ошибочно использовано завершение процессов по общему
имени Techmap.Server вместо собственного PID; это могло закрыть открытый
экземпляр приложения. Пользователь уведомлён. Файлы проектов не удалялись.
Последующие остановки выполнялись только по сохранённому PID тестового процесса.
