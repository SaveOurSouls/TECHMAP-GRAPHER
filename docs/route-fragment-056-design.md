# Редактор фрагмента сборки: план 056

## Контракт

`RouteAssemblyDrawing` передаёт локальную копию документа в штатный `HarnessDesignEditor`. Исходный Чертёж не переписывается. Изоляция хранит набор скрытых ID в `presentation.drawingCopy.hiddenObjectIds` и видимость слоёв в документе копии. Таким образом цепочка «Чертёж → фрагмент → изолированный фрагмент» сохраняет полную геометрию внутри копии для возврата и дальнейшего редактирования.

## Наблюдение C1

На скриншоте C1 в строках списка объектов видны отдельные кнопки «Изолировать». Список смешивает материальные объекты и служебную геометрию (пример: «Выход»). По тексту владельца изоляция должна вызываться на холсте через ПКМ после группового выбора, а список должен стать отдельной панелью материальных компонентов.

## Разделение интерфейса

- Холст: выбор нескольких объектов и контекстное действие «Изолировать». Команда скрывает всё, кроме выделенного набора, ставит прозрачность фонового исходника в 0%, не удаляет объекты и не переключает инструмент редактирования.
- Для выбранного провода остаются связанные П/ОП по `pipe.wireIds` и их узлы по `fromNodeId`/`toNodeId`; для оболочки — сегменты её spans, переданные в сцену как `supportSegmentIds`; для соединителя — его точка «Выход» по `port.connectorId`. Посторонние сегменты, узлы и размеры скрываются вместе с прочими объектами. Служебное выделение без материала не даёт команду изоляции.
- Панель материальных объектов: соединители, провода, оболочки и маркировка. Она показывает и позволяет выбирать/управлять видимостью элементов по устойчивому ID без собственных кнопок изоляции.
- Слои и физическая структура: размеры, соединительные точки и выходы, П и ОП остаются доступными в штатной панели. Они не входят в список материалов или подсчёт спецификационных позиций.

## Проверка

Профильные тесты контекстного меню, классификации объектов и изоляции; полный клиентский Vitest, TypeScript, Vite build и просмотр рабочей/узкой ширины. Сохранить независимость исходного документа и возможность продолжать править изгибы/точки после изоляции.

Автоматические проверки: 167 файлов и 1653 теста Vitest, `tsc --noEmit`, Vite production build и `git diff --check` прошли. Проверка в упакованном приложении на пользовательском жгуте остаётся ручной.
