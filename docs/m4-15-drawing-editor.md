# M4-15 — редактор рисунков библиотеки

20.09.2026, ветка `codex/restore-20260918-0235`, версия `0.25.0-m4-15`.
Карточка приоритетно заменяет ранее запланированную скрутку: основание — семь
замечаний владельца к графическому редактору. Скрутка остаётся последующей карточкой.

## Аудит и план карточки

1. Устранить ограничение маркеров размера нулевым углом и единичным масштабом.
   Перевести перемещение указателя в локальные координаты фигуры; сохранить
   противоположный угол. Добавить маркер вращения с единым центром preview/команды.
2. Добавить независимые привязки к углам, контурам и касательным окружностей,
   цветовые пресеты и штриховки с шагом/углом.
3. Сохранить выбранные объекты для артикула через серверный черновик;
   связать рисованные контакты со стабильными строками таблицы Э4.
4. Проверить геометрию, контракты, размещение, браузер и переносимый пакет.

## Результат

- Размер прямоугольника, эллипса и изображения меняется после произвольного
  поворота/масштаба. Вершины линий и контуров остаются доступны. Поворот выполняется
  вокруг центра локальных геометрических границ; границы Безье учитывают экстремумы.
- Привязки имеют три отдельных переключателя. Касательные концов линий вычисляются
  аналитически; прямая сторона может сдвигаться до касания окружности. Контуры групп
  учитывают их преобразования. Допуск зависит от экранного масштаба.
- Палитра заливки совпадает с палитрой линии. Пять графических мотивов: параллельные,
  перекрёстные, парные линии, точки, кладка. Шаг 2–100, угол −360…360. Параметры
  проверяются клиентом/сервером, сохраняются и рисуются SVG/Canvas.
- Это общий набор мотивов технической штриховки, а не сертифицированная библиотека
  обозначений материалов DIN/ГОСТ. Смысл материала выбирает автор документа.
- Вторая правая колонка содержит артикулы и кнопки «Сохранить». Кнопка сохраняет
  выбранные фигуры/контакты в черновик сервера; «Сохранить и выйти» публикует версию.
  Группы включаются целиком. Фигуры общие: их правка отражается в использующих их
  наборах. Старые версии без `articleDrawings` показывают общий рисунок.
- Контакт можно переместить мышью. Новая точка берётся из следующей свободной строки
  таблицы. Для старых точек предусмотрен выбор строки №. `drawingContactBindings`
  хранит логический ID и `seriesRowId`: номер, название, цепь, тип и стандартный
  терминал поступают из таблицы выбранного артикула. Привязка переживает сохранение
  и размещение; графические точки не подменяют электрические строки.
- История до 100 изменений включает рисунки артикулов и связи контактов. Настройки
  массивов свёрнуты; справка размещена в InfoHint.

## Границы

Касательные поддерживаются для окружностей, не произвольных эллипсов. Контуры
Безье/эллипсов для привязок аппроксимируются; точный центр поворота Безье вычисляется
по экстремумам. Электрические параметры передаются существующему общему контакту
проекта; отдельный новый редактор схемы резки в эту карточку не входит.
Пользовательские проекты не открывались и не удалялись.
