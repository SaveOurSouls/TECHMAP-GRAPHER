Дата: 2026-09-11. Этап M0. Зависимость: принятый план M0–M9.
Статус: эксперимент выполнен. Это технический стенд, не итоговый интерфейс системы.
Исходная точка Git: d88d8b5. Коммит результата определяется по истории этого файла.

## Цель и границы

Проверить возможность рисовать повторяемый узор материала вдоль прямых участков
и заданных изгибов, менять покрытие, сохранять ручное положение при отключении
привязки. Исходные правила: разделы геометрии и аксессуаров в requirements-notes.md,
A01 в requirements-audit.md. Физические характеристики принадлежат базе,
рисунок и его визуальные параметры — утилите.

Входит один синтетический пример с тремя видами материала, тремя вариантами
направляющей и контролируемыми параметрами. Не входят полный редактор примитивов,
сохранение проекта, библиотечные растровые текстуры, подключение БД, автоохват пучка,
Э4, произвольная топология, экспорт документов, расчёт физического радиуса и миграции.
Схемы хранения приложения не создавались и не менялись.

## Проверенный подход

Направляющая состоит из прямых и круговых сопряжений. Радиус в условных единицах
ограничен длинами прилегающих сегментов, поэтому скругление не поглощает весь
короткий сегмент. Длина направляющей измеряется по дискретизированной геометрии
только для распределения рисунка. Материальные миллиметры из неё не вычисляются.

Для точки с координатами «расстояние вдоль / смещение поперёк» вычисляются
положение и нормаль направляющей. Сетчатый узор строится повторениями вдоль неё,
а ребра гофры — поперечными линиями. Масштаб меняет шаг повторений, покрытие
меняет их количество. Объём показан градацией яркости по ширине.
Материал сначала рисуется в отдельный слой Canvas, затем применяется общая
прозрачность: пересекающиеся элементы узора не накапливают прозрачность независимо.

При отключении привязки сохраняется геометрия материала. Изменение провода
перестаёт менять эту геометрию; материал перемещается мышью или стрелками.
Повторная привязка возвращает материал на текущую направляющую. Отключение
геометрической привязки не отменяет обязательную расчётную длину.

## Выполненные проверки

| Проверка | Результат |
|---|---|
| Прямая с промежуточной точкой | Координата поперёк постоянна, длина точна |
| Поворот 90° | Длина совпадает с аналитической суммой прямых и дуги с допуском 0,05 усл. ед. |
| Область изгиба | Удалённые прямые участки сохраняют положение |
| Оба направления поворота | Конечные координаты смещений, возрастающая координата длины |
| Слишком большой радиус | Ограничен соседними сегментами, конечные точки сохранены |
| Нулевой радиус | Явно определяется острый угол |
| Запрос точки за концами | Возвращается соответствующий конец |
| Совпавшие точки, разворот 180°, нечисловые значения | Явная ошибка геометрии, не NaN в последующей отрисовке |
| Тесный изгиб вне покрытия | Не вызывает предупреждение для материала на прямом участке |
| Отвязка и выпрямление провода в браузере | Оплётка сохраняет прежний изгиб, расход 0,95 м не меняется |
| Перемещение мышью и стрелкой | Материал движется независимо от провода |
| Пустая длина в браузере | Предупреждение и «Не включён» в расходе; возврат 950 даёт 0,95 м |
| Прозрачность и масштаб | При 90% материал прозрачен; увеличение шага уменьшает число повторов |
| Тесный изгиб при покрытии | Предупреждение вместо молчаливого объявления рисунка корректным |

Девять автоматических тестов геометрии проходят. Проверки UI выполнены через
отдельную временную вкладку; пользовательский пример не сбрасывался.
Обнаруженное смещение при фокусировке мышью устранено запретом автоматической
прокрутки при фокусе. Исправлены доступные имена ползунков и толщина контура XS3.

## Вывод и ограничения

Подход подходит для продолжения исследования: на одном образце узор повторяется
вдоль заданной формы, а привязка отделена от ручного размещения и расхода.
M0-05 выбрал собственный Canvas 2D renderer; SVG/WebGL остаются отложенными
вариантами только при фактическом ограничении Canvas на нагрузке M3/M4.

При радиусе не больше половины ширины внутренняя сторона оболочки схлопывается
или пересекается. Стенд показывает предупреждение и сохраняет редактирование.
Произвольные самопересечения и пересечения разных оболочек не диагностируются.
Алгоритм нормалей использует отрезки дискретизации: качество на большом увеличении
и способ сглаживания ещё требуют проверки.

В этой версии текстура процедурная; перенос реальных картинок из базы на изгиб
ещё не проверен. Направление меняет расположение светлых/тёмных диагоналей сетки;
для симметричных поперечных рёбер гофры разворот визуально неотличим.
Границы покрытия заданы в процентах условной направляющей, не являются физическими
размерами проекта. Ручное смещение ограничено полем образца. Автоохват диаметра,
редактирование каждой точки отвязанного контура и полноценная размерная вёрстка
не реализованы. Canvas имеет фиксированное разрешение 1000×600; печать не проверялась.

Сохранения/восстановления состояния нет. Это не проверка производительности
300 проводов, точности раскроя или полноты конструкции жгута. Конфликтующие
автоматические состояния и базовые справочники остаются задачами следующих этапов.

Следующая карточка M0-03: поиск на синтетической базе из десятков тысяч записей
и замер нагруженного холста. Результаты должны содержать условия, размеры выборки
и измерения, а не обещание быстродействия всей системы.
