# М4-101 — угловые ограничения связанных трасс

Версия 0.57.0-m4-101, 25.09.2026.

Перенос узла или соединителя вычисляет ограничения по подключённым пайпам и
устойчивым ID их концов. Посторонние узлы не влияют на угол. Режим carry
переносит ближайшие плечи, Shift сохраняет промежуточные точки. Для исходной
прямой виртуальные плечи одинаковы в preview и сохраняемой модели.

Поиск пересечений семейств направлений 15° проверяет все изменяемые плечи.
Если общего решения нет, сохраняется исходное положение. Свободный режим
не ограничивает координаты. Ранее свободные углы внутри переносимой жёсткой
группы сохраняются; это не нормализация всего документа.

Сцена передаёт исходные редактируемые точки отдельно от проекции общей
оболочки. Углы переноса узла/соединителя считаются в системе сохраняемой модели.
Формат документа, электрические ID и серверная модель не менялись.
