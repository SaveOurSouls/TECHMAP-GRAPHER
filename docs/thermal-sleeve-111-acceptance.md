## Наблюдение и исправление

C1: короткая термотрубка не охватывает часть проводов у общей точки выхода
соединителя. C2: общий вид жгута, дающий контекст того же узла. Текст внутри
изображений не использовался как инструкция. Исходный документ жгута не передан;
точная сохранённая конфигурация по скриншотам не устанавливалась.

Воспроизведён сценарий с семью проводами двух П, использующих один ID точки
выхода. Ранее оболочка П строилась по его оси и собственным проводам; подходы
проводов второго П оставались снаружи. Регрессия на старом расчёте обнаруживает
неохваченные участки.

Теперь термотрубка, пересекающая общий выход соединителя, получает дополнительные
опоры по видимым подходам всех проводов этого выхода: учитываются диаметр,
скругления, направление маршрута и касательная соседнего участка П. Опоры
ограничиваются плоскостями торцов перед объединением с основным контуром,
а ручки торцов используют фактические кромки. Близкий выход с другим ID
не включается по совпадению координат. Трубка внутри П и существующий расчёт
оболочек ОП сохраняют своё поведение.

Изменяется только производная геометрия сцены. Провода не назначаются другому П;
электрические концы, маршруты, ID, записи оболочек и производственные длины
не изменяются. Формат хранения и серверный контракт прежние.
