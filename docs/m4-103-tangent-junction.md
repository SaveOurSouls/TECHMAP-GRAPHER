# М4-103 — касательное сопряжение отдельных участков

Версия `0.57.2-m4-103`, 25.09.2026.

Маршрут провода по нескольким физическим участкам теперь передаёт соседние
точки каждой части в renderer. Участки остаются отдельными массивами, поэтому
цвет, скрытие и ширина каждого участка сохраняются. В общей узловой точке
renderer получает предыдущую и следующую опоры; при радиусе больше нуля строится
касательная дуга. При радиусе 0 остаётся острый полилинейный угол. Электрическая
топология, измеренные длины и авторские точки не меняются.

Проверки:

- 1250 клиентских тестов, TypeScript, production build;
- регрессия проверяет 4 независимых части маршрута, общие точки, обратные
  направления и наличие дуги при радиусе 18;
- API итогового EXE `artifacts/channels-smoke/test-y4NdAV` прошёл;
- браузер итогового пакета `http://127.0.0.1:62810/`: радиус 18 включён,
  в общей оболочке визуально видны сглаженные переходы, автосохранение подтверждено
  API ревизией 2 и `drawingDocuments.bendRadius=18`;
- verify-package и 7 portable-режимов прошли.
