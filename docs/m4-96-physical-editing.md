# М4-96 — редактирование перегибов, первый проверенный срез

Версия 0.52.5-m4-96. Этап продолжается, весь объём ТЗ не завершён.

## Выполнено для чертежа

- Вычисленные перегибы пайпа видны до первого редактирования. Один клик по
  полупрозрачной середине участка вставляет точку; перетаскивание сразу меняет её.
- Первый перенос закрепляет видимую геометрию. Обычное перемещение переносит
  соседние внутренние плечи, Shift меняет только выбранную точку. Для выхода
  разъёма переносится ближайшее плечо. Выпрямившиеся точки объединяются.
- Привязки 0/45/90° сопровождаются направляющей; остаётся шаг 15° и свободный режим.
- Команды модели общие для preview и сохранения. Escape, отмена указателя и
  смена инструмента сбрасывают preview. Выбор объекта больше не отменяет drag.
- Изменение графа, геометрии и общих размеров обновляет автоматические маршруты
  проводов; ручные назначения сохраняются. Полные заданные размеры используются
  как длины рёбер. Неизвестные длины оцениваются по масштабу известных участков
  только для поиска пути, в производственные длины эта оценка не записывается.
- При вставке/удалении точек пересчитываются индексы размеров и границ оболочек.
  Потерявшие опору размеры удаляются, оболочки сохраняют относительную границу.

## Второй срез: размеры вычисленных углов

Версия 0.52.5-m4-96-r2. Инструмент размера выбирает все видимые углы автоматического
пайпа. Одна команда закрепляет геометрию и добавляет размер; Undo возвращает
автоматический путь. Привязки прежних размеров и оболочек сохраняются. Заблокированные
слои и устаревшее число точек отклоняются без частичного изменения модели.

TypeScript, 1015/1015 клиентских тестов, production build; браузером проверена
постановка размера между двумя автоматическими углами. API сохраняет такой размер
и читает его после перезапуска: artifacts/channels-smoke/test-GrflQR, все флаги true.
Сервер не изменён, использован проверенный self-contained publish первого среза.

ZIP: artifacts/m4-96-r2/TECHMAP-GRAPHER-0.52.5-m4-96-r2-win-x64.zip,

## Остаток М4-96

- Перенос новой механики в Э4 с сохранением электрических связей и правил экранов.

  для вычисленных углов используется инструмент размера (D).
