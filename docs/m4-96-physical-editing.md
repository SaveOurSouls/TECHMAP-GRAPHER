# М4-96 — редактирование перегибов, первый проверенный срез

Версия 0.52.5-m4-96. Этап продолжается, весь объём ТЗ не завершён.

## Выполнено для чертежа

- Вычисленные перегибы пайпа видны до первого редактирования. Один клик по
  полупрозрачной середине участка вставляет точку; перетаскивание сразу меняет её.
- Первый перенос закрепляет видимую геометрию. Обычное перемещение переносит
  соседние внутренние плечи, Shift меняет только выбранную точку. Для выхода
  разъёма переносится ближайшее плечо. Выпрямившиеся точки объединяются.
- Привязки 0/45/90° сопровождаются направляющей; остаётся шаг 15° и свободный режим.
- Команды модели общие для preview и сохранения. Escape, отмена указателя и
  смена инструмента сбрасывают preview. Выбор объекта больше не отменяет drag.
- Изменение графа, геометрии и общих размеров обновляет автоматические маршруты
  проводов; ручные назначения сохраняются. Полные заданные размеры используются
  как длины рёбер. Неизвестные длины оцениваются по масштабу известных участков
  только для поиска пути, в производственные длины эта оценка не записывается.
- При вставке/удалении точек пересчитываются индексы размеров и границ оболочек.
  Потерявшие опору размеры удаляются, оболочки сохраняют относительную границу.

## Пятый срез: следование узлов и зависимых ветвей

Версия 0.52.5-m4-96-r5. Для редактируемого маршрута Э4 сохраняется исходная
геометрия до упрощения: перенос узла определяется параметром его исходного
сегмента и не затрагивает посторонние пересечения. Если узел принадлежит ветви,
его новые опоры и положение передаются в зависимый маршрут, после чего ветвь
перестраивается общим `rerouteWireE4ThroughJunctions` в той же команде. Для
экрана сохраняется специальное правило прямого отвода; диагональный участок
носителя теперь учитывается при поиске точки пересечения. Перенос двух концов,
имеющих общее плечо, применяет его дельту один раз; несовместимые карты владельцев
отклоняются явно и не дают частичной записи.

Добавлены регрессии для наклонного носителя с узлом, следования ветви, сохранения
экранного отвода, общего плеча и исключения несвязанных пересечений. Проверены
TypeScript, 1030/1030 клиентских тестов и production build. API smoke с
перезапуском сохраняет узел и оба маршрута: `artifacts/channels-smoke/test-balfK4`.
Серверный код не менялся; используется publish с ранее подтверждёнными 815/815
серверными тестами. В браузере проверены выключение шага 15°, перенос угла с
обновлением узла ветви и отсутствие изменения при переносе тела провода.

ZIP без пользовательских данных:
`artifacts/m4-96-r5/TECHMAP-GRAPHER-0.52.5-m4-96-r5-win-x64.zip`, 54 571 297 байт,
SHA-256 `F0BBA8C0EE0675B52E9B3695E020344A3DC37EF1E7AE29E1835FE2B721372F94`.

Ограничения среза: реальный модификатор Shift и отмена во время pointer-drag не
подтверждены автоматизированным браузерным жестом; конфликт двух разных карт
владельцев общего узла намеренно возвращает ошибку; прямое перемещение узла без
ручки маршрута требует отдельного UI-аудита. Эти ограничения не скрываются под
декоративным preview.

## Третий срез: точки Э4 и проверка плеч

Версия 0.52.5-m4-96-r3. Выделенный провод Э4 показывает углы и полупрозрачные
середины. Один клик вставляет точку. Перенос использует общую команду для preview
и фиксации; carry сдвигает соседние точки, Shift сохраняет дальние точки.
Слой wires блокирует редактирование; прямой отвод экрана к узлу не получает изгибы.
Коллинеарная точка внутри выхода контакта не сокращает гарантированный прямой
участок: обе проверки учитывают весь непрерывный прямой выход.

Это промежуточная интеграция: Э4 пока достраивает диагональные плечи ортогональными
участками. Подбор локальных Г/Z-плеч предотвращает самопересечение старого поиска
через обязательные точки. Свободные/15° сегменты, перенесённые векторы соединителя
и замена прежнего перемещения тела провода ещё не завершены. Не считать этот срез
полным выполнением новой механики Э4.

Исправлено непосредственное перетаскивание середины пайпа: обычный режим переносит
прилегающие внутренние точки, Shift вставляет и двигает только новую точку.

Проверки: TypeScript, 1020/1020 клиентских тестов и production build. Браузер:
на реальном HarnessEditorWorkspace вставлена точка Э4 и перенесены её плечи.
API итогового пакета, коллинеарная точка внутри выхода и повторное чтение после
перезапуска: artifacts/channels-smoke/test-7U8lf6, все флаги true. Серверный код
не менялся, используется publish с 815/815 серверными тестами первого среза.

## Четвёртый срез: свободные плечи Э4

Версия 0.52.5-m4-96-r4. Ручные перегибы теперь сохраняют наклонные плечи,
ортогональная достройка удалена. Геометрия пересечений, наложений, параллельного
зазора, расстояния до углов и попадания в прямоугольное препятствие обобщена на
произвольные сегменты. Автоматический поиск остаётся ортогональным, но учитывает
наклонные ручные провода как занятые маршруты. Мостики поворачиваются вдоль
верхнего провода, нижний провод восстанавливается по его фактическому направлению.
Hit-test подключения к линии учитывает диагонали; электрическое касание проверяется
по общей геометрии. Диагонали больше не считаются вертикальными участками экрана.

Новый перенос соединителя carry переносит ближайшее плечо; Shift оставляет дальние
точки и меняет подход к контакту. Гарантированный прямой выход сохранён. Preview
редактора использует ту же команду, что фиксация, вместо старой временной геометрии.
Переключатель «Шаг 15°» доступен также в Э4; выключение разрешает свободный угол.

Проверки: TypeScript, 1025/1025 клиентских тестов, production build. Новые регрессии
проверяют диагональные препятствия/зазоры/самопересечения, автопоиск среди диагоналей,
мостик и выбор диагонали, точное сохранение ручных точек, carry/Shift соединителя.
В браузере проверено перетаскивание середины с выключенным шагом: наклонные плечи
появились без ортогональных вставок. API финального пакета сохраняет наклонный путь
и читает его после перезапуска: artifacts/channels-smoke/test-PosVgz, все флаги true.
Серверный код не менялся; используется ранее проверенный publish (815 тестов).

ZIP: artifacts/m4-96-r4/TECHMAP-GRAPHER-0.52.5-m4-96-r4-win-x64.zip,

Пользовательских данных нет.

Остаток М4-96: совместное перемещение электрических узлов с ручными плечами,

## Седьмой срез: единое положение общего узла

Версия 0.52.5-m4-96-r7. Положение T-узла определяется носителем, а не ветвью,
заканчивающейся в нём. При нескольких перемещаемых носителях приоритет имеет
первый по сохранённому порядку wireIds узла; результат не зависит от порядка
wires в документе. Остальные пути присоединяются к этому положению в той же
транзакции. Валидная деформация сохраняет дальние авторские углы; повторный
поиск используется только при коллизии или нарушении связности. Заблокированный
слой зависимой ветви по-прежнему отклоняет операцию целиком.

Пять новых регрессий проверяют согласование двух носителей, T-ветвь того же
соединителя в carry/Shift, независимость от порядка проводов, сохранение дальних
авторских углов. Проверены связность, отсутствие диагностик, parse и Undo.
1041/1041 клиентских тестов, TypeScript и production build прошли. API сценарий
расширен двумя носителями общего узла; сохранение и перезапуск прошли:
artifacts/channels-smoke/test-ZRY2Wh. Сервер не менялся, использован прежний publish
(815 серверных тестов). Новая геометрия этого среза проверена командами и API;
новый браузерный сценарий для конфликта двух носителей не запускался.
