# М4-50 — подсказки поверх всех панелей

С1: подсказка размеров обрезалась границами панели свойств. Общий InfoHint
ранее использовал абсолютное позиционирование внутри контейнера; z-index не
позволял выйти из overflow/stacking context. Все справочные подсказки приложения
используют этот компонент, отдельных компонентов tooltip аудит не обнаружил.

InfoHint теперь открывает native popover в верхнем слое браузера. Он не
обрезается overflow, transform и isolation предков и отображается поверх
модальных диалогов. Положение рассчитывается относительно кнопки с отступом
от экрана; снизу при нехватке места подсказка открывается сверху. Длинный текст
получает внутреннюю прокрутку. Поддержаны наведение, фокус клавиатуры, клик,
Escape, закрытие снаружи, перемещение при прокрутке и resize; одновременно
открывается одна подсказка. Ссылка aria-describedby сохранена.

Изменены: `src/Techmap.Client/src/InfoHint.tsx`, `styles.css`, добавлены
`InfoHint.test.ts`; версия `package/VERSION.json` — `0.42.1-m4-50`.
Обновлены план, состояние и этот протокол. Предыдущие изменения генератора
сохранены. Коммит и push не выполнялись по правилам текущей задачи.

Проверки:
- 867/867 клиентских тестов; TypeScript --noEmit; production Vite build.
- Браузер при 1280×720: обрезающий контейнер с transform/isolation и соседняя
  панель z-index 999999; подсказка полностью видна и первая в elementFromPoint.
  Нижний правый угол, Escape и открытие над native modal dialog также проверены.
- Win-x64 publish и verify-package. Серверный код не менялся; ранее выполненный
  полный набор 756/756 не запускался повторно для этой клиентской правки.
- ZIP без пользовательских данных:
  `artifacts/m4-50-hints/TECHMAP-GRAPHER-win-x64.zip`.

Используется Popover API современных Chromium/Firefox/Safari; комплектный
актуальный браузер поддерживает его. Временная диагностическая страница удалена.
