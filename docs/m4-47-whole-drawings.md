# М4-47 — цельные рисунки Э4 и возврат из редактора

С1: `projectE4DrawingCompanions` создавал отдельное размещение, рамку,
масштаб и линию к таблице для каждого корневого примитива. Теперь набор
несгруппированных фигур, включая фигуры на разных слоях, размещается целиком.
Если набор состоит из явно заданных групп или изображений, каждый такой объект
остаётся отдельным цельным рисунком. Для нескольких векторных рисунков нужно
сгруппировать фигуры каждого рисунка. Формат шаблона и электрические связи не менялись.

Старые смещения отдельных примитивов не применяются к собранному рисунку:
он возвращается к согласованной геометрии над таблицей. Новые перемещение,
масштаб и видимость сохраняются по ID вида; старые записи не удаляются.

С2: вход в редактор доступен после выбора или создания сохранённой серии.
Инструкция создания серии находится в InfoHint. Кнопка «В библиотеку» закрывает
редактор независимо от валидации сохранения, сохраняя текущие изменения в памяти.
«Сохранить и выйти» по-прежнему публикует версию перед выходом.

## Проверки

- Клиент: 849/849 тестов; TypeScript; production build.
- Сервер: 753/753 теста; Release publish win-x64.
- Регрессии: фигуры на разных слоях перемещаются и масштабируются целиком;
  старые разрозненные offsets не разрывают рисунок; две группы имеют независимые
  размещения; кнопка входа без серии отключена, возврат присутствует.
- Браузер, отдельная база `artifacts/m4-47-ui-data`: вход без серии отключён;
  создание серии, вход, добавление фигур, сохранение и выход; возврат без
  публикации и повторное открытие с сохранением фигур.
- API готового пакета: публикация шаблона, размещение по preview.libraryBinding,
  совпадение templateId/version/hash/article, рисунки по разделам.
  Дополнительный сценарий `.build/m4-47-composite-api.mjs` создаёт две
  несгруппированные фигуры Э4 и проверяет один рисунок с двумя командами
  из сохранённого снимка. Основа сценария — текущий test-library-placement.mjs;
  его прежние незакоммиченные изменения не редактировались.
  Повторный запуск прошёл с `restartChecked: true` на базе
  `artifacts/library-placement-smoke/test-44i4oj`.
- `verify-package`: 39 файлов. ZIP 53,46 МиБ, без пользовательских данных:
  `artifacts/m4-47/TECHMAP-GRAPHER-win-x64.zip`.
  SHA-256: `4E8B9732507936387AFD397D5DE43BA43EBCB63A3D5BF99DF5458A7FD745069E`.

Первый ограниченный запуск сервера встретил Windows ACL UnauthorizedAccessException;
изолированный запуск вне sandbox прошёл. Установленные клиентские инструменты
запускались напрямую: pnpm предлагал переустановку node_modules. Пакет собран
штатным сценарием с пропуском уже выполненного клиентского блока.
Пользовательские проекты не открывались и не удалялись.

Этот исторический протокол ранее получил номер М4-47. По уточнению пользователя
генератор из М4-46 выполняется под исходными номерами М4-47–49, без сдвига.
Результат: [m4-47-49-series-drawing-generator.md](m4-47-49-series-drawing-generator.md).
Создан локальный коммит `a6736c7`, включающий также сохранённые изменения
предыдущего среза. Это ошибочное применение прежнего разрешения: последние
переданные в задачу правила требуют отдельного поручения координатора.
Push не выполнялся. Эта корректировка отчёта оставлена в рабочем дереве.
