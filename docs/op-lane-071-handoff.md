## Что исправлено

`joiningPipePacking` больше не выбирает положение lane только по среднему offset
двух концов. Для текущего состава проверяются варианты порядка у начала и конца
ОП; выбирается вариант с минимальным числом инверсий. Это сохраняет близкий
порядок П при переходе к общей оси и не создаёт лишних перекрёстных плеч.

`unprojectPipeBundlePoint` распознаёт ОП как отдельный объект. При установке
оболочки координата не трактуется как authored point исходного П, поэтому
`standardCovering` может создать span на `joiningPipe` и пройти обычную
валидацию/повторное открытие.
