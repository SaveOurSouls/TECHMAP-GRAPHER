# М4-60–63 — спецификация и физические каналы жгута

Задание владельца: спецификация учитывает предметные объекты чертежа и дополнительные материалы без графики; допустим тип без артикула. Канал — физический путь проводов Э4, защита назначается на него; Т-ответвления и несколько выходов соединителя не создают электрических соединений.

## План
- М4-60: абстрактные и дополнительные позиции спецификации, количество и единицы, назначение каталога позже; учёт неназначенной защиты.
- М4-61: каналы, оформление, проводники цветами Э4, контекстная защита.
- М4-62: Т-ветвление в произвольной точке и несколько выходов одного соединителя, маршруты по Э4.
- М4-63: регрессии, API, браузер, сборки и чистый ZIP.

М4-60: реализованы дополнительные позиции, изображения на поле с перемещением/удалением, ручное обозначение и закреплённая идентичность записи каталога. При скрытии изображения расход остаётся. Количество задаётся на жгут, единицы шт./м/г/кг/л. Неизвестное количество остаётся null. Рисунки/размеры/подписи не создают дополнительный расход.

Проверки М4-60: TypeScript, 893/893 клиентских тестов, production build, Release build, 75/75 HarnessDesignApiTests. Сквозная проверка всего сценария следует в М4-63.

М4-61: ширина/цвет канала, отдельные цветные полосы проводников Э4, скрытие проводников без изменения трасс, привязка канала к позиции спецификации и контекстные пять видов защиты. Проверки: TypeScript, 895/895 клиентских тестов, Vite/Release build, 75/75 API-тестов.

М4-62: Т-ответвление по правому клику с сохранением маршрутов и интервалов покрытия; свободный конец достраивается к выходу списком или инструментом W между узлами. Разъём поддерживает несколько выходов с выбором проводов. Автоматический поиск кратчайших каналов не меняет Э4 и сохраняет вручную закреплённые пути, кроме явно исключённых оператором выходов. Проверки: 897/897 клиентских тестов, TypeScript/Vite/Release build; 79/79 API-тестов, включая двойной выход и ограничения проводов.
