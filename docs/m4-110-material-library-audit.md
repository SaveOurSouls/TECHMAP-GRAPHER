# М4-110 — итоговая проверка библиотеки материалов

Версия `0.60.0-m4-110`, схема SQLite 21. Глобальный раздел «Материалы» добавлен
в корневое меню. Редактирование в таблице: название, основной тип оболочки,
PNG/SVG, контур, поворот, масштаб и тональная окраска. Есть создание,
сохранение, отмена и удаление с подтверждением.

Записи и исходные PNG входят в резервную копию SQLite. Операции защищены
версией записи; назначение типа снимает его с предыдущего материала атомарно.
Текстура новой оболочки закрепляется во вложениях проекта, параметры — в style.
Обновление или удаление общей записи не меняет существующие оболочки.
Локальное предпочтение чертежа имеет приоритет над общим. Undo возвращает
оболочку и список текстур одним шагом, вложение остаётся для Redo.

## Границы

Начальные текстуры — собственные плоские повторяемые узоры по C1; объёмные
рисунки сохранены как будущий референс. Чёрный/белый оставляют диапазон
светотени для читаемой фактуры. SVG после загрузки хранится как PNG;
обратного редактирования исходного SVG нет. Изображения до 10 МиБ,
до 1000 материалов. Существующие явно назначенные локальные предпочтения
не заменяются глобальными. Большие библиотеки до предельного объёма не
проверялись нагрузочным тестом. Обновление базы создаёт штатную резервную
копию; старый исполняемый файл со схемой 20 не открывает новую схему 21.

Пользовательские проекты не открывались и не удалялись. Следующая новая
карточка продолжает индекс М4-111; дополнительные функции в этот срез не входят.
