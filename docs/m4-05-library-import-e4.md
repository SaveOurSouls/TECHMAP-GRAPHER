## Исправления

- Google Sheets: `gid` обозначает выбранную вкладку и больше не передаётся в XLSX
  экспорт всей книги. Источник имеет одну идентичность при переключении вкладок.
  Имена листов сохранённой публичной книги проверены непосредственно в workbook.xml.
- Пины: отдельные количества групп формируют электрические строки без графических
  прототипов. Ввод фиксируется по Enter/потере фокуса; временно пустое поле не
  обнуляет таблицу и не уничтожает правки строк. При переключении артикулов
  значения редактируемых ячеек обновляются.
- Предпросмотр использует тот же E4ConnectorInspector, что основной редактор.
  Сторона контактов, видимость колонок и дополнительные поля сохраняются в
  необязательном e4Presentation формата v5 и применяются при новом размещении.
  Подсказки в изменённой панели серии вынесены в InfoHint.
- Привязка запроса строится из preview.libraryBinding. Источник и тип артикула
  нормализуются так же, как серверный индекс: ручной `БД.СОЕД` соответствует
  `бд.соед`. Та же нормализация применена при проверке закреплённых видов.
- Аудит перезапуска выявил устаревший список допустимых схем в проверке резервной
  копии/старта: снимки v5 ошибочно отвергались. Список исправлен, добавлены проверки
  backup для размещённых v3/v4/v5.
