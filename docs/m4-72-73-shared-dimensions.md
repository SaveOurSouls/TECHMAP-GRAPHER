# М4-72–73: общие размеры пайпов

## Результат

Размер на чертеже можно поставить по двум узлам или перегибам физического пайпа.
Размер хранится с устойчивым `segmentId` и применяется ко всем проводам, чьи
маршруты проходят через этот участок. Оператору не нужно повторно выбирать точки
для каждого провода. Для маршрута складываются измеренные участки всех его
пайпов; если хотя бы один участок не измерен, длина остаётся неизвестной.

Провод без пайпа по-прежнему поддерживает собственные размеры по его точкам.
Индивидуальные поправки начала и конца (`endCorrectionFromMm` и
`endCorrectionToMm`) сохраняются у провода и применяются после общей длины пайпа.
Ручное поле длины в таблице соединений блокируется для управляемого пайпом
провода и содержит пояснение в `title`, чтобы не перезаписать общую геометрию.

Размеры пайпов участвуют в общем индексе выбора: выбор размера подсвечивает все
провода, проходящие через участок, а выбор физического участка показывает те же
провода. Изменение геометрии сохраняет привязку только при совпадении топологии;
замена участка или количества перегибов снимает устаревший размер.
