Изменение от 15.10.2026
Для Нарезанных проводов необходимо поменять логику создания карточек.
Нужно создать вариант справочника на первом экране, куда я загружу я в таблицу загружу допустимые схемы заготовки провода. Будут колонки:
Название схемы = Название
Описание схемы = Описание
Выбор операции №1 = Операция №1
…
Выбора операции №n =
В одну строку я присваиваю для схемы порядок операций, чтобы ее изготовить. Их может быть от 1 до n. кнопкой добавить для каждой строки я добавлять столько столбцов, сколько нужно.
Далее в Справочнике Полуфабрикаты провода необходимо дополнить недостающие рисунки и включить возможность указать, по какой схеме он будет выполнять по дефолту из выпадающего списка
В Маршрут V3 Должна появиться кнопка - "Заготовка провода". Там появляется список аналогичный тому, что есть сейчас в карточке резки проводов. В каждой строчке в соответствии с дефолтным списоком Справочник Полуфабрикаты провода указывается преднастроенное значение.
В Маршрут V3 маршрут карточек для проводов создается автоматически. Они группируются в свои карточки по одинаковым схемам. Далее каждая схема создает столько карточек в цепочку, сколько последовательных операций было задано в Справочнике схем до получения конечного полуфабриката.
