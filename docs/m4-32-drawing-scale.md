# M4-32 — масштаб размещённых рисунков и приёмка M4-30–M4-32

Версия: `0.38.0-m4-32`. Дата: 20.09.2026.

## Результат

- M4-30 (`16a14f7`): независимый фон штриховки с палитрой, адаптивные
  угловые маркеры малых фигур, Ctrl+колесо, одинаковые графические кнопки.
  В M4-32 добавлены кнопки −/процент/+ для того же масштаба поля.
- M4-31 (`a9b3029`): массив повторяет выбранные фигуры и контактные точки.
  Количество берётся из артикула с учётом числа контактов в прототипе;
  номера и данные контактов привязаны к строкам таблицы Э4.
- M4-32: отдельный масштаб каждого сопутствующего рисунка Э4 и общий
  масштаб рисунка компонента на чертеже, от 5 до 2000 процентов.
  Изменение доступно числом и угловым маркером, сохраняется и отменяется.
  На чертеже вместе с графикой масштабируются точки подключения.
  Электрические ID, библиотечная привязка и данные проводов не меняются.

В приёмке исправлены две ошибки: выбор представления контакта независимой
таблицы по ID строки вместо ключа графического повтора; недоступное поле
процентов на чертеже из-за условия, рассчитанного только на Э4.

Основные файлы: `drawing-scale.ts`, `DrawingScaleControl.tsx`,
`DrawingResizeGrip.tsx`, `CanvasViewport.tsx`, `HarnessDesignEditor.tsx`,
`HarnessEditorWorkspace.tsx`, `component-template-view-renderer.ts`,
`materialized-contact-representation.ts`, `model.ts`, `commands.ts`,
`SqliteHarnessDesignDocumentStore.cs`; тесты и API-сценарий обновлены.

геометрическое растяжение само по себе не добавляет электрические контакты.
