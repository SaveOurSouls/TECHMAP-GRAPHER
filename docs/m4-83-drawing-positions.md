# M4-83 — чёткость чертежа, позиции и спецификация

Версия: `0.50.0-m4-83`. Запрос: C1 от 23.09.2026, шесть пунктов про
уменьшение рисунка, периметр привязки, групповые позиции и колонки спецификации.

На C1 при 45% тонкие линии теряли контраст, а позиционные якоря хранились как
свободные смещения от начала объекта. Векторная отрисовка теперь сохраняет
минимальную толщину 0,9 CSS-пикселя с учётом DPR, масштаба и поворота.
Растровые рисунки уменьшаются из исходного изображения с качественным сглаживанием,
без промежуточного уменьшенного кэша.

Для выносок используются контуры закреплённого рисунка, включая поворот и масштаб
экземпляра. Внутренние линии контактов не выбираются вместо наружного контура.
Кривые аппроксимируются отрезками; для растра границей служит рамка обрезанного
изображения. Пайпы, провода и покрытия используют свой маршрут и ширину.
Новые якоря соединителей сохраняются в локальных координатах; старые свободные
якоря при отображении проецируются на периметр того же объекта. Потерянная ссылка
по-прежнему обозначается «?» и не переносится к соседнему объекту.

«Добавить позиции» доступна в общей панели документов чертежа и в спецификации.
За одну отменяемую операцию создаются все выноски для представленных на поле
объектов. Повторное нажатие не дублирует пары объект/позиция. Дополнительные номера
располагаются справа от крайнего номера того же объекта с шагом 24 — диаметром
кружка — на одной горизонтали. Кнопка с глазом заменяет выбор отдельного экземпляра:
показ/скрытие действует сразу на все обозначения одной позиции и сохраняет их
координаты. Позиции вне поля не получают произвольных якорей.

Спецификация в окне и сцене имеет колонки «Поз.», «Индекс», «Обозначение»,
«Наименование», «Кол-во», «Примечание». XS1 и другие экземпляры входят в «Индекс»,
артикул — в «Обозначение». Для библиотечного соединителя «Наименование» строится
как «8 конт. — Розетка кабельная»: количество фактических контактов и поле
«Описание» закреплённой версии библиотеки (snapshot.name). Пользовательские
текстовые поправки сохраняются. Группировка по точной версии источника и расчёт
количества не изменены. Клиент и сервер проверяют новые поля index, anchorLocal,
hidden; старые документы открываются без обязательной миграции.

Проверки:

- TypeScript и production build.
- 947 клиентских тестов: привязка к повёрнутому контуру, движение/масштаб,
  групповые выноски, касательное размещение, повторное добавление, Undo,
  сериализация, новые колонки, DPR и толщина тонких линий.
- 787 серверных тестов, включая проверку новых и старых форматов полей.
- Браузер: три экземпляра одной позиции, общее добавление, скрытие/показ,
  переоткрытие, визуальная проверка 50%, перетаскивание якоря за пределы объекта.
- API итогового EXE с отдельным временным каталогом: сохранение трёх скрытых
  выносок с локальными привязками и индексом, отклонение некорректного hidden
  без смены ревизии, перезапуск и точное сравнение документа.
- Manifest/ZIP и git diff --check.

Ограничение: элементы исходного растра меньше физического пикселя дисплея нельзя
показать как отдельные детали. Исходная геометрия и изображения не меняются,
увеличение масштаба возвращает их исходную детализацию. Растровая привязка не
выполняет распознавание силуэта по пикселям.
