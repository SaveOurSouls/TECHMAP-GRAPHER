# М4-100 — общая оболочка нескольких пайпов

Статус: реализация начата, пользовательский сценарий ещё не готов.

Требования: ПКМ по оболочке → «Объединить» → выбрать пайпы/существующие группы
с подсветкой и кратким составом → сохранить. Общая оболочка перемещается вдоль
собранных пайпов. Плоская укладка размещает их рядом, объёмная — как проекцию
упакованных поперечных сечений. Общая оболочка не меняет электрические связи.

Порядок реализации:

1. Вычислитель поперечного сечения, ID и размеры независимо от Canvas.
2. Сохранённый состав группы, ссылки на пайпы/группы; защита от циклов,
   повторного включения одного пайпа, отсутствующих участников. Сервер и клиент.
3. Контекстное действие, режим выбора, краткий состав/подсветка, сохранение.
4. Раскладка пайпов и их проводов под общим контуром, перенос общей оболочки;
   спецификация без дублирования материалов, удаление/разделение участников.
5. API, браузер, повторное открытие и ZIP; аудит по исходному ТЗ.

## Первый исходный срез

`pipe-bundle-packing.ts` — чистый вычислитель плоской/объёмной укладки.
Плоский режим сохраняет порядок и даёт ширину, равную сумме диаметров.
Объёмный использует детерминированные касания окружностей и размещает крупные
сечения первыми; выход сохраняет порядок/ID и содержит смещение/глубину.
Это допустимая компактная укладка, не доказанный глобальный оптимум.

Девять новых тестов: точный плоский ряд, три касающихся одинаковых круга,
1/2/8/32 смешанных сечения без пересечений, границы общего контура,
детерминизм/неизменность входа, масштаб 0,001/1000, некорректные размеры/ID.
1180 клиентских тестов и TypeScript прошли. UI, API и пакет не менялись:
модуль пока не подключён. Последний пользовательский ZIP — М4-99-r7.
