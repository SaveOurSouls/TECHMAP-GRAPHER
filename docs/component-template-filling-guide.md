# Как заполнить библиотечный шаблон компонента

Инструкция относится к интерфейсу `0.5.1-m3-02-r1` и новее. В этой версии
сохранение кнопкой **«Создать новую версию»** публикует неизменяемую версию
шаблона. Отдельной кнопки «Опубликовать» пока нет.

## Сначала выберите тип шаблона

### Фиксированное количество контактов

Этот вариант подходит, когда у всех артикулов серии одинаковое число контактов.

1. Откройте вид **Э4**.
2. В панели **«Контакты вида»** нажмите **«Создать контакт»** для каждого
   контакта изделия.
3. Выделяйте созданные точки и заполняйте справа номер, название, цепь,
   группу контакта и направление подключения.
4. Перейдите в вид **«Чертёж»**. Для каждого логического контакта выберите его
   в списке **«Разместить контакт из другого вида»** и нажмите
   **«Разместить связанную точку»**.
5. В разделе **«Серия и артикулы»** создайте группу контактов и артикулы.
6. Для каждого артикула укажите **«Итоговое количество контактов»**, равное
   фактическому числу созданных контактов этой группы.

Без повторяемого сегмента другое итоговое количество сохранить нельзя.

### Разное количество контактов в артикулах серии

Например, для `PHR-2`, `PHR-3` и `PHR-4` удобнее нарисовать одну строку контакта
и повторять её.

1. В **«Серия и артикулы»** создайте группу, например **«Сигнальные»**.
2. В виде **Э4** нажмите **«Создать контакт»** один раз. Выделите его точку и
   справа назначьте группу **«Сигнальные»**, номер `1`, название и направление.
3. Нарисуйте один примитив, который будет геометрией-прототипом строки, и
   выделите его. Сейчас команда повтора принимает один свободный объект верхнего
   уровня; объединение нескольких примитивов в один прототип ещё не выведено в UI.
4. В панели **«Параметры»** появится форма
   **«Повторяемый сегмент»**. Выберите созданную точку контакта, задайте
   начальное количество и шаг: обычно `X = 0`, `Y` равен высоте строки.
5. Нажмите **«Сделать повторяемым»**.
6. Перейдите в вид **«Чертёж»**, выберите связанный логический контакт и нажмите
   **«Разместить связанную точку»**. Нарисуйте и выделите один примитив-прототип,
   затем в форме **«Разместить повтор в этом виде»** выберите созданный домен и
   задайте шаг для чертежа.
7. В **«Артикулы серии»** создайте каждый реальный артикул. В его группе укажите
   итоговое число контактов: `2`, `3`, `4` и так далее.
8. Вверху раздела выберите **«Артикул для предпросмотра»**. Проверьте число
   строк и геометрию обоих видов.

## Артикулы и терминалы

Поля идентификации состоят из трёх частей:

- **Источник** — имя опубликованного справочника, например `БД.СОЕД` или
  `БД.ТЕР`;
- **Тип** — тип записи, например `connector` или `terminal`;
- **Артикул** — точный ключ записи справочника.

Для совместимых терминалов используйте реальные опубликованные записи
`БД.ТЕР`. Кнопка **«+ Терминал»** пока создаёт временную строку `Новый-1`;
замените её точным артикулом до сохранения.

## Как читать ошибки

Ошибка **«Итоговое количество ... нельзя получить из шаблона»** означает, что
указанное число не складывается из фиксированных контактов и повторяемого
сегмента этой группы. Под полем количества новая версия показывает допустимое
правило. Исправьте число либо создайте один домен повтора для группы.

Пути вида `$.articleVariants[0].contactGroups` в верхнем сообщении относятся к
старому интерфейсу. Если они видны вместе со старой подписью
**«Количество контактов»**, запущен пакет до `0.5.1-m3-02-r1`. Закройте старый
сервер и вкладку, распакуйте новый ZIP в отдельную папку и запустите его оттуда.

## Проверка перед созданием версии

1. В каждом обязательном виде есть связанные точки всех логических контактов.
2. У каждого повторяемого контакта ровно один домен повтора его группы.
3. Выбран артикул для предпросмотра, число строк верное, геометрия не расползлась.
4. Все артикулы соединителей и терминалов заменены на реальные ключи справочников.
5. После проверки нажмите **«Создать новую версию»**.
