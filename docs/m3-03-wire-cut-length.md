# M3-03 — длина провода и первая карта резки

Дата: 2026-09-14.

## Что работает

- Новый провод создаётся с неизвестной длиной и остаётся допустимым незавершённым
  объектом проекта.
- Инспектор хранит исходную абсолютную длину, отдельную знаковую поправку каждого
  конца и шаг округления длины резки.
- Расчёт выполняется в целых микрометрах по тому же правилу, что доменный
  `CutLengthCalculator`: поправки суммируются отдельно, округляется вверх только
  итог; штатный шаг — 1 мм.
- Неизвестная длина даёт предупреждение и не создаёт расход материала.
- Read-only API одного жгута возвращает одну строку на провод, число заготовок по
  индивидуальному количеству жгута и общий метраж:
  `GET /api/v1/projects/{projectId}/harnesses/{harnessId}/cut-list`.
- Клиент показывает ограниченную карту резки выбранного жгута и позволяет
  перечитать её после сохранения редактора.

## Явное ограничение

Провод ещё не хранит закреплённый project-owned ключ записи `БД.ПР`. Поэтому в
карте материал показан как `not-pinned`, а вся выдача имеет статус `limited`.
Таблица пригодна для проверки длин и количества заготовок, но пока не является
полной спецификацией материалов.

Следующий срез M3-04 должен закрепить справочную позицию провода в экземпляре,
задать устойчивый ключ объединения полностью идентичных позиций и построить
агрегацию всех жгутов проекта. Позиции, отличающиеся по длине хотя бы на 1 мм,
объединяться не должны.
