# М4-99-r5 — парные переходы и проверка света

Версия `0.55.1-m4-99-r5`. Шесть типов покрытий используют общий профиль
ширины вдоль пайпа. На каждой границе нижнего покрытия появляются две явные
точки: плоский участок, короткое наклонное плечо, плоский участок. Переход
расположен на тонкой стороне и не уменьшает полный диаметр толстой основы.
Рампы ограничены соседними интервалами, сохраняются при переносе и обрезке
оболочки, горизонтальном/вертикальном направлении и изгибе пути.

Добавлены точные координатные регрессии, проверки типа `volumeShading`,
JSON/Undo и сохранения флага при копировании, импорте и перезапуске EXE.
Справка переключателя — в InfoHint.

Проверено 25 сентября 2026:

- 1164 клиентских теста, TypeScript и production Vite build;
- 864 серверных Release-теста, self-contained publish;
- API итогового пакета: `artifacts/channels-smoke/test-TfZ8AB`;
- 7 portable-режимов: `artifacts/m4-99-r5/portable-smoke-retry`;
- браузер: пять pixel-проверок настоящего renderer — горизонтальный и
  вертикальный пайп, путь после изгиба, покрытие, точный базовый цвет при
  выключении; контур парных переходов осмотрен визуально;
- portable UI на изолированном синтетическом импортированном проекте:
  выключенный свет → включение → автосохранение → reload → повторное открытие.
  API сравнение всего документа подтвердило изменение только флага света.

Первый запуск EXE внутри sandbox завершился UnauthorizedAccessException;
повтор вне sandbox прошёл. Пользовательские проекты не использовались.
