# Детализация материалов при масштабировании

Проблема C1 (`codex-clipboard-aac3327b-7c13-432d-97f4-0f4e4eecf197.png`):
при увеличении металлической оплётки видны размытые ромбы вместо нитей.
Сверено с `reference-assets/m4-110-c1-textures.png`: нужны пересечения пучков
и отдельные волокна, плоский рисунок без обязательного объёмного освещения.

Причина: исходные шесть образцов библиотеки имеют размер 64×64 пикселя;
увеличение растягивало этот растр. Дополнительно перекраска любых крупных
изображений уменьшала их до 512 пикселей.

Для неизменённых исходных образцов используется процедурная геометрия:
чередование пучков и тонкие нити оплёток, волокна бандажа и флиса,
мелкая матовая фактура ПВХ и термоусадки. Геометрия растеризуется под
произведение масштаба камеры, материала и плотности экрана. Повтор остаётся
32 единицы чертежа при масштабе материала 1. Разрешение выбирается ступенями
256–4096 пикселей; поэтому увеличение не растягивает исходный 64px образец.
Фон и рисунок по-прежнему окрашиваются независимо.

Образец узнаётся по размерам и хешу исходных RGBA-пикселей, включая закреплённые
копии в существующих проектах. Изображения, вложения и документы не переписываются.
Замена пользователем картинки не подменяется фактурой по типу оболочки.
Остальные PNG/JPG сохраняют исходное разрешение при перекраске; добавить
отсутствующие в пользовательском растре детали это не может.

Чертёж и библиотека используют общий рендер. Предпросмотр учитывает DPR.
Кеш ограничен 24 элементами и 16 мегапикселями (около 64 МиБ RGBA).

Проверки: 1352 клиентских теста, TypeScript, production Vite build,
`git diff --check`. Новые регрессии проверяют камеру/DPR/масштаб материала,
сохранение пропорций и разрешения пользовательского изображения, отделение
фона, исключение произвольного 64px изображения из встроенных образцов.

Визуальная проверка: установленный Playwright + Edge (Browser plugin not available),
изолированная страница `http://127.0.0.1:5193/texture-qa`, настоящий
`drawCoveringSurface`, шесть PNG из SQL начальных данных, viewport 1200×1020,
DPR 2, дополнительный viewport 390×844. Проверены распознавание всех шести
образцов, камеры 100%/400%, переключение масштаба материала 4 → 10 → 1,
отсутствие ошибок страницы и сохранение изображения после взаимодействия.
Снимки до/после показывают устранение размытия C1. Пользовательские проекты
не открывались. Полный интерфейс приложения и переносимая EXE-сборка
в этой проверке не тестировались; изменения относятся к клиентскому рендеру.
