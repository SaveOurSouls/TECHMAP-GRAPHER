# М4-99-r7 — свет кабеля и разделки

Версия `0.55.2-m4-99-r7` включает вложенные переходы r6 и распространяет
переключатель объёмного света на общую оболочку многожильного кабеля и все
видимые слои разделки. Полосы света следуют локальному поперечному сечению,
включая вертикальные и наклонные объекты. Контур выделения остаётся внешним.
Выключение сохраняет прежний ровный цвет/фон. В Э4 этот эффект не применяется.

Исправлен ранний выход renderer для провода с `paths`: теперь он также рисует
разделку, ранее пропускавшуюся этой веткой. Геометрия и производственные
параметры документа не изменяются.

Проверки 25 сентября 2026:

- 1171 клиентский тест (123 файла), TypeScript и production build;
- серверный код неизменён относительно r5 с 864 успешными Release-тестами;
  self-contained EXE пересобран;
- браузерный renderer: четыре проверки пикселей кабеля и разделки,
  включение/выключение; визуальный осмотр;
- API итогового EXE с перезапуском, копированием и импортом:
  `artifacts/channels-smoke/test-ZpFA0K`;
- все 7 portable-режимов: `artifacts/m4-99-r7/portable-smoke`;
- `verify-package`: 30 файлов, пользовательских данных нет.

NuGet при publish автоматически добавил ILLink в lock-файлы. Эти изменения
убраны; SBOM пересоздан по исходным lock-файлам. После portable-проверок
изменились только SBOM и PACKAGE-MANIFEST, EXE и клиент остались побайтно теми же.
Повторная проверка манифеста прошла.
