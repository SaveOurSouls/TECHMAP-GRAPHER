# Product Design QA — верхняя панель инструментов

**Source visual truth:** C1 (47 x 851 px) показывает дефект прежней вертикальной панели: обрезанные иконки разного масштаба. Это визуальное свидетельство, а не макет для пиксельного сравнения.

**Проверенная реализация:** packaged Windows x64 сборка `0.63.22-m5-11-review`, запущенная с чистым тестовым хранилищем из ASCII-пути. Снимки сделаны в браузере в ходе текущей проверки.

## Проверенные состояния

1. **Схема Э4, desktop:** toolbar находится в первой горизонтальной строке; доступны выбор, перемещение, соединитель, провод, текст, все графические примитивы, правка, угол, привязки и масштаб. Иконки не обрезаны; недоступные команды правки корректно disabled.
2. **Чертёж, desktop:** тот же набор графических команд отображается в верхней строке; боковые панели, canvas и inspector начинаются ниже toolbar.
3. **Маршрут, редактор фрагмента сборки:** независимая копия чертежа открывает тот же верхний toolbar, с Save/Cancel фрагмента; данные исходного жгута не изменялись.
4. **Narrow 390 x 844:** toolbar не возвращается в вертикальную колонку и прокручивается горизонтально. Команды остаются доступны через overflow без наложения на панель фрагмента.

## Результат

- Устранён наблюдаемый в C1 дефект вертикальной, обрезанной панели.
- Визуальная проверка подтвердила общие 24 px иконки, единые hit-area, active/disabled состояния и подписи/aria-label из DOM.
- Консоль packaged-приложения не содержит ошибок или предупреждений.
- Во время длительного сценария маршрута однажды появилась временная статусная надпись о связи с локальным сервером; журнал сервера в тот же период фиксировал успешные ответы API, поэтому это не блокировало проверку toolbar. Повторная диагностика сценария связи остаётся отдельным риском, не связанным с переносом панели.

**Final result: passed for toolbar QA.**
